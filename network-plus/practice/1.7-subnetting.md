# Subnetting Practice Scenarios

## Scenario 1: Choosing a Subnet Mask for a Branch Office

**Scenario:** A network administrator is designing a new branch office network using the 192.168.5.0/24 address space. The branch needs to support 40 workstations per subnet with as many subnets as possible.

**Question:** What is the optimal CIDR notation and subnet mask for this requirement? How many subnets and usable hosts per subnet does it provide?

**Answer:** /26 (255.255.255.192) — 4 subnets, 62 usable hosts per subnet.

**Explanation:** Using the formula hosts per subnet = 2^(host bits) - 2, we need at least 40 hosts. A /27 gives 2^5 - 2 = 30 hosts (not enough). A /26 gives 2^6 - 2 = 62 hosts (sufficient). Since 192.168.5.0 is Class C (default /24), subnet bits borrowed = 26 - 24 = 2, giving 2^2 = 4 subnets. This is the smallest mask that still supports 40+ hosts per subnet.

## Scenario 2: Finding the Subnet ID Using the Magic Number

**Scenario:** A technician is troubleshooting connectivity and needs to determine if two devices are on the same subnet. One device has the IP address 172.16.242.133 with a subnet mask of 255.255.255.224.

**Question:** What is the subnet ID, broadcast address, first usable host, and last usable host for this device?

**Answer:**
- Subnet ID: 172.16.242.128
- Broadcast: 172.16.242.159
- First usable host: 172.16.242.129
- Last usable host: 172.16.242.158

**Explanation:** The interesting octet is the 4th (mask = 224). Magic number = 256 - 224 = 32. The ranges in the 4th octet are 0-31, 32-63, 64-95, 96-127, 128-159, 160-191... The IP's 4th octet is 133, which falls in the 128-159 range. For the subnet ID: octets with mask 255 copy the IP down (172.16.242), and the interesting octet uses the range start (128). For broadcast: octets with mask 255 copy the subnet ID down, and the interesting octet = subnet ID + magic number - 1 = 128 + 32 - 1 = 159.

## Scenario 3: Identifying the Interesting Octet

**Scenario:** You are given the IP address 10.180.122.244 with a subnet mask of 255.248.0.0 and need to determine the network boundaries for a routing table entry.

**Question:** Which octet is the interesting octet? What is the subnet ID and broadcast address?

**Answer:**
- Interesting octet: 2nd (mask value = 248)
- Subnet ID: 10.176.0.0
- Broadcast: 10.183.255.255

**Explanation:** The interesting octet is the one that is neither 255 nor 0 — here it's the 2nd octet with mask value 248. Magic number = 256 - 248 = 8. Ranges for octet 2: 0-7, 8-15, ... 176-183, ... The IP's 2nd octet is 180, which falls in 176-183. For the subnet ID: octet 1 (mask=255) copies down as 10, octet 2 uses range start 176, octets 3-4 (mask=0) become 0. For broadcast: octet 1 copies subnet ID (10), octet 2 = 176 + 8 - 1 = 183, octets 3-4 (mask=0) become 255.

## Scenario 4: Determining IP Class and Default Mask

**Scenario:** A junior network technician encounters the following IP addresses during an audit and needs to classify them and identify their default subnet masks:

- 17.22.90.7
- 165.245.0.1
- 220.10.77.40

**Question:** For each address, what is the IP class and default subnet mask?

**Answer:**
- 17.22.90.7 — Class A, default mask 255.0.0.0 (/8)
- 165.245.0.1 — Class B, default mask 255.255.0.0 (/16)
- 220.10.77.40 — Class C, default mask 255.255.255.0 (/24)

**Explanation:** The class is determined by the first octet only. Class A = 0-127, Class B = 128-191, Class C = 192-223. First octet 17 falls in 0-127 (Class A, 8 network bits). First octet 165 falls in 128-191 (Class B, 16 network bits). First octet 220 falls in 192-223 (Class C, 24 network bits).

## Scenario 5: Subnetting a Class B Network

**Scenario:** A company uses the 172.16.0.0 network and needs to create 32 subnets with maximum hosts per subnet. The network engineer must determine the correct CIDR prefix.

**Question:** What CIDR prefix length is needed? How many host bits remain, and how many usable hosts per subnet does this provide?

**Answer:** /21 — 11 host bits remaining, 2,046 usable hosts per subnet.

**Explanation:** 172.16.0.0 is Class B with a default mask of /16. To get 32 subnets: 2^n = 32, so n = 5 subnet bits borrowed. New prefix = 16 + 5 = /21. Host bits remaining = 32 - 21 = 11. Usable hosts per subnet = 2^11 - 2 = 2,046. The 2 addresses subtracted are the network address (all host bits = 0) and broadcast address (all host bits = 1).

## Scenario 6: Seven Second Subnetting with a /20 Mask

**Scenario:** A network administrator receives a trouble ticket for host 165.245.12.88/20. They need to quickly determine what network this host belongs to in order to check the correct switch.

**Question:** Using the seven second subnetting chart, what is the subnet address, broadcast address, first usable IP, and last usable IP?

**Answer:**
- Subnet: 165.245.0.0
- Broadcast: 165.245.15.255
- First IP: 165.245.0.1
- Last IP: 165.245.15.254

**Explanation:** From the seven second chart, /20 is in the third octet column with 16 addresses per block and subnet mask 240. Full mask: 255.255.240.0. The interesting octet is the 3rd. The IP's 3rd octet is 12, which falls in the block 0-15 (from the 16-address boundary chart). Subnet: octets 1-2 (mask=255) copy down as 165.245, octet 3 uses block start 0, octet 4 (mask=0) is 0. Broadcast: octets 1-2 copy down, octet 3 = next block start minus 1 = 16 - 1 = 15, octet 4 (mask=0) = 255.

## Scenario 7: Converting CIDR to Decimal Subnet Mask

**Scenario:** A Windows server administrator needs to configure a network interface. The network team provided the address 10.50.100.200/19, but Windows requires the subnet mask in decimal notation.

**Question:** What is the decimal subnet mask for /19? How many network bits and host bits does this provide?

**Answer:** 255.255.224.0 — 19 network bits, 13 host bits.

**Explanation:** A /19 mask means 19 contiguous 1-bits followed by 13 zero-bits. Breaking into octets: first octet = 11111111 = 255, second octet = 11111111 = 255, third octet = 11100000 = 224 (3 bits into this octet: 128+64+32 = 224), fourth octet = 00000000 = 0. The subnet mask structure is always contiguous 1's on the left (network portion) and 0's on the right (host portion) — never mixed.

## Scenario 8: Multi-Step Problem — Network Design with VLSM

**Scenario:** A network administrator has the 10.1.1.0/24 address space (Class A address subnetted to /24). They need to verify the subnet calculations before deploying: how many subnets were created from the original Class A default, how many hosts each subnet supports, and what the network boundaries are for a host at 10.1.1.200.

**Question:**
1. How many subnets were created by going from /8 to /24?
2. How many usable hosts per subnet?
3. What are the network address, broadcast address, first host, and last host for 10.1.1.200/24?

**Answer:**
1. 65,536 subnets (2^16)
2. 254 usable hosts (2^8 - 2)
3. Network: 10.1.1.0, Broadcast: 10.1.1.255, First host: 10.1.1.1, Last host: 10.1.1.254

**Explanation:** 10.x.x.x is Class A with default /8. Subnet bits borrowed = 24 - 8 = 16, so subnets = 2^16 = 65,536. Host bits remaining = 32 - 24 = 8, so hosts per subnet = 2^8 - 2 = 254. For 10.1.1.200/24: the mask is 255.255.255.0. Octets 1-3 (mask=255) copy the IP down for the subnet ID (10.1.1), octet 4 (mask=0) becomes 0. For broadcast: octets 1-3 copy down, octet 4 (mask=0) becomes 255. VLSM allows this flexibility — the subnet mask is not limited to classful boundaries, so any number of bits can be used for the mask.
