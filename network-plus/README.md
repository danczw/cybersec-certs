## Interactive Game

> [!NOTE]
> The `game/` directory is entirely AI-generated — code, data, and styling were produced by Claude.

**NetOps Command** is a browser-based training game covering all 5 exam domains. Open `game/index.html` directly (no server required).

### Game Modes

| Mode             | Description                                                 |
|------------------|-------------------------------------------------------------|
| Rapid Fire       | SRS-driven quiz across all domains with streak multipliers  |
| Subnet Architect | Progressive subnetting practice (binary → VLSM)            |
| Abbreviations    | Match abbreviations ↔ full names (multiple choice + typed)  |

### Features

- Spaced repetition scheduling (correct = double interval, wrong = reset)
- XP / level / streak system with localStorage persistence
- Domain mastery tracking weighted by exam percentages
- 1455 concepts generated from course flashcards (domains 1-3)
