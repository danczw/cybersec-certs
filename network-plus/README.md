## Lesson Track

> [!NOTE]
> `claude-teach/` is generated by the AI study partner and kept separate from the
> hand-written study material.

Short, self-contained HTML lessons built on retrieval practice rather than
re-reading. Coverage in `notes/` is already complete, so the lesson track targets
retention and application instead of adding new material.

| Path                    | Contents                                         |
|-------------------------|--------------------------------------------------|
| `MISSION.md`            | Why this cert, and what success looks like       |
| `NOTES.md`              | Teaching preferences and workspace conventions   |
| `lessons/*.html`        | Numbered lessons; open directly in a browser     |
| `reference/`            | Quick-reference hub over the rest of the repo    |
| `learning-records/*.md` | What has been established, and what it changes   |
| `assets/`               | Design tokens, stylesheet and lesson components  |

Lessons auto-grade, cite the repo file each question came from, and report scores
per exam domain. Acronyms are click-to-reveal chips compiled from
`abbreviations/abbreviations.md`; expansions are logged so vocabulary gaps can be
told apart from concept gaps.

Regenerate the acronym data after editing the glossary:

```sh
node claude-teach/assets/abbr-generate.js
```

## Interactive Game

> [!NOTE]
> The `game/` directory is entirely AI-generated — code, data, and styling were
> produced by Claude.

**NetOps Command** is a browser-based training game covering all 5 exam domains.
Open `game/index.html` directly (no server required).

It shares the lesson track's visual design: palette, type scale and elevation all
come from `claude-teach/assets/tokens.css`, so the game and the lessons read as one
course. Domain accent colours are consistent across both — mastery bars in the game
use the same five colours as the lesson result meters.

### Game Modes

| Mode             | Domain | Description                                                                  |
|------------------|--------|------------------------------------------------------------------------------|
| Rapid Fire       | All    | Timed quiz across all domains; spaced repetition resurfaces weak concepts    |
| Abbreviations    | All    | Acronym recall both directions, with a recall-first delay before the options |
| Layer Drop       | 1.1    | Sort protocols, devices and concepts onto the correct OSI layer, under timer |
| Port Sprint      | 1.4    | Speed-typing recall of protocol ↔ port, with a streak combo multiplier       |
| Cable Lab        | 1.5    | Match requirements to cable, connector and standard; escalates to scenarios  |
| Subnet Architect | 1.7    | Progressive subnetting — binary math, CIDR, host counts, VLSM                |
| Route Selector   | 2.1    | Pick the winning route from a table: longest prefix, AD tiebreakers          |
| Attack Surface   | 4      | Identify an attack from symptoms, then choose the correct defense            |
| Triage Sim       | 5      | Step-by-step incident troubleshooting against a limited diagnostic budget    |

### Features

- Spaced repetition scheduling (correct = double interval, wrong = reset)
- Recall-first gate in Abbreviations mode: options stay hidden for a few seconds
  so each item is a free-recall attempt before it becomes a recognition task.
  Selectable at 2s / 4s / 6s / off, and the choice persists
- XP / level / streak system with localStorage persistence
- Domain mastery tracking, and question selection weighted by exam percentages
- 2365 concepts across all 5 domains, generated from the flashcard decks
- 234 abbreviations, generated from the canonical glossary

Regenerate game data after editing flashcards or the glossary:

```sh
node game/generate-data.js
```

Domain weights live in two places that must agree: `game/generate-data.js`
(baked into `js/data.js`) and `game/js/engine.js` (drives Rapid Fire question
selection).
