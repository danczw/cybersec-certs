The idea

An IPv4 address answers three separate questions, and 0002 only covered the first: what family is it (done), what class is it, will it need translating, and how will it be delivered.

Classes

Classful addressing stopped driving subnet masks in 1993. It is still examinable, and still the starting point of every subnetting calculation.

ClassFirst octetLeading bitsDefault mask
A0–1270255.0.0.0
B128–19110255.255.0.0
C192–223110255.255.255.0
D224–2391110— multicast
E240–2551111— reserved

Do not memorise five arbitrary numbers. Each boundary is where the next leading bit switches on: 128 is 10000000, 192 is 11000000, 224 is 11100000, 240 is 11110000. Recognising those four values is the same skill as reading a subnet mask — which is why this pays forward into subnetting.

Translation

Private addresses are not routable on the public internet, so a router has to translate them. Standard NAT swaps one private address for one public address, which means every internal host needs its own public address — solving nothing, given IPv4's 4.29 billion addresses are exhausted against 20–30 billion connected devices.

NAT overload, also called PAT (Port Address Translation), translates both the address and the port. Many hosts share one public address, each session distinguished by its port number: 10.10.20.50:3233 → 94.1.1.1:1055, then 10.10.20.70:5782 → 94.1.1.1:1056. The NAT table stores that private IP:port ↔ public IP:port mapping per session. This is what your home router does.

Delivery

TypeShapeExample
Unicastone-to-oneWeb browsing, file transfer, email
Multicastone-to-many-of-manyStreaming, stock feeds, routing updates
Anycastone-to-one-of-manyAnycast DNS — nearest responder wins
Broadcastone-to-allARP requests. Cannot cross a router

This is where Class D earns its place: 224–239 is the multicast range, and recipients must subscribe to the group. Multicast is why OSPF reaches its neighbours at 224.0.0.5 instead of broadcasting. Anycast is the one people confuse with it — same address on many machines, but traffic goes to exactly one of them, the closest by routing metric.
