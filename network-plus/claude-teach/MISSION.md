# Mission: CompTIA Network+ (N10-009)

## Why

Pass N10-009 as the forcing function to make networking fundamentals actually
stick — not just enough to recognise an answer on a test, but enough to reason
about a real network when something breaks. The cert is also the base layer for
a move toward security work (Security+ / CySA+ / blue-team), where almost every
attack and control is a networking fact wearing a different hat.

## Success looks like

- Score 720+ on N10-009 (90 min, up to 90 questions).
- Subnet by hand in under ~10 seconds per question, without a calculator.
- Given a broken-network symptom, name the likely layer and the next command to
  run — before reaching for a cheat sheet.
- Explain *why* an attack works (VLAN hopping, ARP poisoning, evil twin) in
  terms of the protocol it abuses, not just its name.
- Read a packet capture and a routing table without flinching.

## Constraints

- No exam date booked. Target: schedule once diagnostic scores hold above ~85%
  across all five domains. Depth before speed.
- Study material is already written: 86 note files and 82 flashcard decks from
  the Professor Messer N10-009 course live in `notes/` and `flashcards/`.
  Coverage is not the gap — **retention and application are**.
- Lessons must be short. Working memory is the bottleneck, not available time.
- Lesson content comes from this repo's notes first; external sources are cited,
  never paraphrased from memory.

## Out of scope

- Vendor-specific CLI mastery (Cisco IOS config beyond what N10-009 asks).
- IPv6 beyond the exam objectives (SLAAC, basic addressing).
- Security+ material that N10-009 does not cover — parked until this cert lands.
- Building out `game/` further. It is a drill resource, not the syllabus.
