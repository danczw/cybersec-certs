Magic Number Subnetting

1.0 Networking Concepts OBJ 1.7 CompTIA Network+ N10-009

The Subnetting Problem

Given 192.168.1.0/24, find optimal subnet mask for 40 devices per subnet:

MaskCIDRSubnetsHosts/Subnet
255.255.255.0/241254
255.255.255.128/252126
255.255.255.192/26462
255.255.255.224/27830

Answer: /26 — smallest mask that still supports 40+ hosts per subnet.

Four Values to Calculate

  1. Network address (subnet ID) — first address in the subnet
  2. Broadcast address — last address in the subnet
  3. First usable host — subnet ID + 1
  4. Last usable host — broadcast − 1

Magic Number Method Steps

No binary-to-decimal conversions needed — uses simple subtraction and multiples.

  1. Convert subnet mask to decimal (if not already)
  2. Identify the interesting octet — the octet that is neither 255 nor 0
  3. Calculate magic number: 256 − interesting octet value
  4. Determine host ranges (multiples of the magic number)
  5. Find which range the IP falls into
  6. Network address = first value in that range
  7. Broadcast address = subnet ID + magic number − 1

CIDR-to-Interesting-Octet Reference

CIDR for interesting octet 3/17/18/19/20/21/22/23/24
CIDR for interesting octet 4/25/26/27/28/29/30
Magic number1286432168421

/31 and /32 are not included — /31 leaves no room for hosts, /32 leaves 0 host bits.

Subnet ID Rules

  • If mask octet = 255 → copy IP address octet down
  • If mask octet = 0 → write 0
  • If mask octet = interesting → use magic number to find range start

Broadcast Address Rules

  • If mask octet = 255 → copy subnet ID octet down
  • If mask octet = 0 → write 255
  • If mask octet = interesting → subnet ID + magic number − 1
