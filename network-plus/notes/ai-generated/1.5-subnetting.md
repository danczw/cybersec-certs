# IP Addressing and Subnetting (Objective 1.5/1.7)

## IPv4 Address Classes

| Class | Range | Default Mask | Private Range |
|-------|-------|-------------|---------------|
| A | 1.0.0.0 – 126.255.255.255 | /8 (255.0.0.0) | 10.0.0.0/8 |
| B | 128.0.0.0 – 191.255.255.255 | /16 (255.255.0.0) | 172.16.0.0/12 |
| C | 192.0.0.0 – 223.255.255.255 | /24 (255.255.255.0) | 192.168.0.0/16 |

- 127.0.0.0/8 = loopback
- 169.254.0.0/16 = APIPA (link-local)
- 224.0.0.0 – 239.255.255.255 = multicast (Class D)

## Subnetting Formulas

- **Subnets** = 2^n (n = bits borrowed)
- **Usable hosts** = 2^h - 2 (h = remaining host bits)
- **Block size** = 256 - subnet mask octet value

## Subnetting Example

Network: 192.168.10.0/24, need 6 subnets:

1. Borrow 3 bits → 2³ = 8 subnets (≥6)
2. New prefix: /24 + 3 = **/27**
3. Subnet mask: **255.255.255.224**
4. Host bits: 8 - 3 = 5 → 2⁵ - 2 = **30 usable hosts**
5. Block size: 256 - 224 = **32**

Subnets: .0, .32, .64, .96, .128, .160, .192, .224

For subnet 192.168.10.32/27:
- Network: 192.168.10.32
- First host: 192.168.10.33
- Last host: 192.168.10.62
- Broadcast: 192.168.10.63

## IPv6 Basics

- 128-bit address, written in hex (8 groups of 4 hex digits)
- Shortening rules: drop leading zeros, replace longest consecutive all-zero groups with ::
- Link-local: fe80::/10
- Global unicast: 2000::/3
- Loopback: ::1
- No broadcast — uses multicast instead
