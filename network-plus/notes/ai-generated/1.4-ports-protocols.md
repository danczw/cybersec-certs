# Ports and Protocols (Objective 1.4)

## Port Ranges (IANA)

| Range | Classification |
|-------|---------------|
| 0-1023 | Well-known / System ports |
| 1024-49151 | Registered / User ports |
| 49152-65535 | Dynamic / Ephemeral ports |

Note: Professor Messer uses "non-ephemeral" for 0-1023. The exam may use simplified two-tier terminology, but IANA defines three tiers.

## Socket Definition

A **socket** = IP address + protocol (TCP/UDP) + port number

## TCP vs UDP

| Feature | TCP | UDP |
|---------|-----|-----|
| Connection | Connection-oriented (3-way handshake) | Connectionless |
| Reliability | Guaranteed delivery, ordering | Best-effort, no guarantee |
| Speed | Slower (overhead) | Faster (minimal overhead) |
| Use case | Web, email, file transfer | Streaming, DNS, VoIP, gaming |
| Flow control | Yes (windowing) | No |

## Other Protocols

- **ICMP** — ping, traceroute; error reporting (no port number)
- **GRE** — tunneling protocol, encapsulates packets
- **IPsec** — encryption/authentication for VPNs (AH + ESP)
