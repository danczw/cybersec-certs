# Network Security (Domain 4, 14%)

## Security Concepts (4.1)

### CIA Triad
- **Confidentiality** — only authorized users access data (encryption, ACLs)
- **Integrity** — data not altered in transit (hashing, digital signatures)
- **Availability** — systems accessible when needed (redundancy, backups)

### AAA Framework
- **Authentication** — prove identity (username/password, MFA, certificates)
- **Authorization** — what you're allowed to do (permissions, roles)
- **Accounting** — track what you did (logging, auditing)

### AAA Protocols
| Protocol | Port | Transport | Key Difference |
|----------|------|-----------|----------------|
| RADIUS | 1812/1813 | UDP | Encrypts password only; combines auth+authz |
| TACACS+ | 49 | TCP | Encrypts entire payload; separates AAA functions |

### Zero Trust
- Never trust, always verify
- Microsegmentation, least privilege, continuous verification
- No implicit trust based on network location

## Common Attacks (4.2)

| Attack | Description | Layer |
|--------|-------------|-------|
| DoS/DDoS | Overwhelm resources | L3-L7 |
| VLAN Hopping | Double-tagging to access other VLANs | L2 |
| MAC Flooding | Overflow switch CAM table → hub behavior | L2 |
| ARP Poisoning | Fake ARP replies → MITM | L2 |
| DNS Poisoning | Corrupt DNS cache → redirect traffic | L7 |
| Rogue DHCP | Unauthorized DHCP server → wrong gateway | L3 |
| Social Engineering | Manipulate humans (phishing, pretexting) | N/A |
| On-path (MITM) | Intercept between two parties | L2-L7 |

## Network Hardening (4.3)

- **Port security** — limit MACs per switch port
- **DHCP snooping** — filter untrusted DHCP messages
- **Dynamic ARP Inspection (DAI)** — validate ARP against DHCP snooping table
- **Network segmentation** — VLANs, firewalls between zones
- **ACLs** — permit/deny rules on routers/firewalls
- **Disable unused ports** — prevent physical access attacks
- **802.1X** — port-based NAC (Network Access Control)
