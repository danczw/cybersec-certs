# OSI Model (Objective 1.1)

## Seven Layers

| Layer | Name | Function | Protocols/Devices | PDU |
|-------|------|----------|-------------------|-----|
| 7 | Application | User interface, data creation | HTTP, HTTPS, FTP, DNS, SMTP, POP3, IMAP | Data |
| 6 | Presentation | Encryption, compression, formatting | SSL/TLS, JPEG, ASCII | Data |
| 5 | Session | Session management, dialog control | NetBIOS, RPC | Data |
| 4 | Transport | Reliable/unreliable delivery, segmentation | TCP, UDP | Segment/Datagram |
| 3 | Network | Logical addressing, routing | IP, ICMP, OSPF, BGP | Packet |
| 2 | Data Link | Physical addressing, frame delivery | Ethernet, Wi-Fi, switches | Frame |
| 1 | Physical | Bits on the wire, signaling | Cables, hubs, repeaters | Bits |

## Key Mappings

- **Switches** operate at Layer 2 (Data Link)
- **Routers** operate at Layer 3 (Network)
- **Firewalls** can operate at L3-L7 depending on type
- **MAC addresses** (EUI-48/EUI-64) = Layer 2
- **IP addresses** = Layer 3

## TCP/IP Model (4 layers)

| TCP/IP Layer | OSI Equivalent |
|--------------|----------------|
| Application | Layers 5, 6, 7 |
| Transport | Layer 4 |
| Internet | Layer 3 |
| Network Access | Layers 1, 2 |

## Encapsulation Order

Data → Segment → Packet → Frame → Bits (top-down)

Mnemonic: **All People Seem To Need Data Processing** (L7→L1)
Reverse: **Please Do Not Throw Sausage Pizza Away** (L1→L7)
