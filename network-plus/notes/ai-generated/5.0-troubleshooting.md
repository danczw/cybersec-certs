# Network Troubleshooting (Domain 5, 24%)

## Troubleshooting Methodology (5.1)

1. Identify the problem
2. Establish a theory of probable cause
3. Test the theory to determine cause
4. Establish a plan of action and implement the solution
5. Verify full system functionality
6. Document findings, actions, and outcomes

## Command-Line Tools (5.3)

| Command | Purpose | Key Options |
|---------|---------|-------------|
| `ping` | Test reachability (ICMP echo) | `-t` continuous, `-n` count |
| `traceroute`/`tracert` | Show hop-by-hop path | `-d` no DNS resolution |
| `nslookup`/`dig` | DNS queries | specify server, record type |
| `ipconfig`/`ifconfig`/`ip` | View/configure IP settings | `/all`, `/release`, `/renew`, `/flushdns` |
| `netstat` | Active connections, listening ports | `-a` all, `-n` numeric, `-b` process |
| `arp` | View/manage ARP cache | `-a` display, `-d` delete |
| `tcpdump` | Packet capture (CLI) | `-i` interface, `-w` write to file |
| `nmap` | Port scanning, host discovery | `-sS` SYN scan, `-O` OS detect |
| `pathping` | Combines ping + traceroute (Windows) | Shows packet loss per hop |

## Diagnostic Walkthrough

**Scenario:** User can reach local resources but not the internet.

```
1. ipconfig /all        → verify IP, mask, gateway, DNS
2. ping <gateway>       → test local connectivity
3. ping 8.8.8.8         → test internet (bypass DNS)
4. nslookup google.com  → test DNS resolution
5. tracert 8.8.8.8      → find where path breaks
```

- If ping gateway fails → L1/L2 issue (cable, switch port, VLAN)
- If ping 8.8.8.8 fails but gateway works → routing/firewall issue
- If ping 8.8.8.8 works but nslookup fails → DNS issue
- If tracert shows timeout at specific hop → problem at that router

## Cable Issues (5.2)

| Issue | Symptom | Tool |
|-------|---------|------|
| Attenuation | Signal weakens over distance | Cable tester, TDR |
| Crosstalk (NEXT) | Signal bleeds between wire pairs | Cable certifier |
| EMI | Interference from external sources | Move cable, use STP |
| Open/Short | No connectivity | Cable tester, TDR |
| Incorrect pinout | No/intermittent connectivity | Wire map tester |

- **TDR** (Time Domain Reflectometer) — copper cable length/break location
- **OTDR** (Optical TDR) — fiber cable testing

## Wireless Issues (5.4)

- Channel overlap (use 1, 6, 11 for 2.4 GHz)
- Interference (microwaves, Bluetooth on 2.4 GHz)
- Signal degradation (distance, walls, floors)
- Incorrect SSID/password/security type
- AP placement and antenna orientation

## Common Network Issues (5.5)

| Problem | Likely Cause | Fix |
|---------|-------------|-----|
| Duplicate IP | Static conflict or rogue DHCP | Check DHCP scope, use reservations |
| Wrong subnet mask | Misconfiguration | Verify against network design |
| No DHCP address | Server down or wrong VLAN | Check DHCP relay (ip helper-address) |
| DNS failure | Wrong DNS server or server down | Test with public DNS (8.8.8.8) |
| Routing loop | Misconfigured routes | Check routing tables, use TTL |
| Asymmetric routing | Different paths in/out | Verify routing protocols |
