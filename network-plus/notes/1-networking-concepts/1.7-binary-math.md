# Binary Math

## Fundamentals

- Binary uses two numbers: 0 and 1
- Each 0 or 1 is a **bit**
- 8 bits = 1 **byte** (also called an **octet**)

## Conversion Chart

- Start from right with 1, double each position moving left
- 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1
- Chart can extend left: 256, 512, 1024, etc.
- Each position is a power of 2 (2^0 = 1, 2^1 = 2, 2^2 = 4, ...)

## Binary to Decimal

1. Write binary value under the conversion chart
2. Where binary digit is 0 → value is 0
3. Where binary digit is 1 → take the chart number above it
4. Add all values together

> [!NOTE] Example
> | Binary   | Calculation           | Decimal |
> |----------|-----------------------|---------|
> | 00000010 | 2                     | 2       |
> | 10000010 | 128 + 2               | 130     |
> | 11111111 | 128+64+32+16+8+4+2+1  | 255     |

## Decimal to Binary

1. Write conversion chart above empty 8-bit placeholders
2. Starting from left (128): is the running total ≤ target?
   - Yes → place 1, add that value to running total
   - No → place 0, move to next column
3. Repeat for each column until all 8 bits are filled

> [!NOTE] Example
> **154 Decimal**
>
> | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
> |-----|----|----|----|---|---|---|---|
> | 1   | 0  | 0  | 1  | 1 | 0 | 1 | 0 |
>
> - 128 ≤ 154? Yes → 1 (running: 128)
> - 128+64=192 ≤ 154? No → 0
> - 128+32=160 ≤ 154? No → 0
> - 128+16=144 ≤ 154? Yes → 1 (running: 144)
> - 144+8=152 ≤ 154? Yes → 1 (running: 152)
> - 152+4=156 ≤ 154? No → 0
> - 152+2=154 ≤ 154? Yes → 1 (running: 154)
> - 154+1=155 ≤ 154? No → 0
>
> Result: 10011010

## Bit Count and Possible Values

- With 8 bits, any value 0–255 can be represented
- Total possible values = 2^n (where n = number of bits)

| Bits | Possible Values (2^n) |
|------|-----------------------|
| 2    | 4                     |
| 3    | 8                     |
| 4    | 16                    |
| 5    | 32                    |
| 6    | 64                    |
| 7    | 128                   |
| 8    | 256                   |
