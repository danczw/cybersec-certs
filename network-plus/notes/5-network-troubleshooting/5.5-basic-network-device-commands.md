# Basic Network Device Commands

## Command Similarity Across Manufacturers

- Commands at the command line are very similar between different manufacturers
- Learning one manufacturer's switch helps manage another manufacturer's switch
- Syntax is not exactly the same, but very close
- Output contains similar information across manufacturers
- Once you learn the technology behind the commands, moving between manufacturers becomes easy

## show mac-address-table

- Lists all MAC addresses the switch has learned and which ports they were learned on
- Switch references this table to decide where to send traffic
- Useful for troubleshooting:
  - Why traffic may be sent out every interface
  - Whether the maximum number of entries has been reached

## show route

- Lists all routes inside the routing table
- Used to see exactly where routes are for a particular router
- Use on each router along a path to build the full route from source to destination
- Process: find the route that applies to traffic, follow it out the specific interface, repeat on next router

### Routing Table Format

- Left side shows abbreviations for route types (e.g., R = RIP, C = connected/directly connected)
- Each route entry shows: destination network, next-hop address, and exit interface
- Evaluate each route to find the most specific match for your traffic

## show interface

- Shows status and statistics for a particular interface
- Information includes:
  - Interface status: up, down, connected, or administratively disabled
  - Speed, MTU, and encapsulation types
  - Errors: CRC errors, dropped frames, input/output errors
  - Performance: total number of frames, total broadcasts
  - Hardware configuration: duplex, speed (e.g., full duplex, 100 Mbps), media type (e.g., RJ45)
  - Input and output rates

## show config

- Shows the text-based configuration currently running inside a device
- May also view configurations stored on the storage drive
- Command example: `show running-config` (shows currently active configuration)
- Each manufacturer uses different syntax and format for configuration
- Configuration can be modified at the command line and then viewed again

## show arp

- Views the ARP (Address Resolution Protocol) cache inside switches and routers
- Similar to ARP cache in an operating system
- Shows: protocol, IP address, hardware/MAC address, and the interface used to identify that pair
- Useful to determine if a switch or router sees a particular MAC address associated with an IP address

## show vlan

- Lists all VLANs on the device and which interfaces are assigned to each VLAN
- Shows:
  - Assigned VLAN IDs
  - Default VLAN for the switch
  - Interfaces that are part of the default VLAN
  - Interfaces specifically assigned to a different VLAN

## show power

- Shows PoE power usage for the switch
- Lists all interfaces and whether PoE is on or off for each
- Shows how much power each device is using
- Indicates if additional devices can be added
- Example: switch supports 370W, using 40W, 330W remaining
