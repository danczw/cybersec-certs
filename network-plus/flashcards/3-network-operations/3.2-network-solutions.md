# Network Solutions Flashcards

**Q:** What is LLDP?
**A:** Link Layer Discovery Protocol — a standard (non-proprietary) protocol used on switches to discover devices on the network
**Difficulty:** Easy
**Tags:** network-discovery, lldp, domain-3, prof-messer

---

**Q:** What is CDP?
**A:** Cisco Discovery Protocol — Cisco's proprietary network discovery protocol
**Difficulty:** Easy
**Tags:** network-discovery, cdp, domain-3, prof-messer

---

**Q:** What is the difference between LLDP and CDP?
**A:** LLDP is a standard (non-proprietary) protocol; CDP is Cisco's proprietary version. Both are discovery protocols on switches.
**Difficulty:** Medium
**Tags:** network-discovery, lldp, cdp, domain-3, prof-messer

---

**Q:** Name five techniques for network discovery.
**A:** LLDP, CDP, ping/port scans, commercial network scanners, and SNMP
**Difficulty:** Medium
**Tags:** network-discovery, domain-3, prof-messer

---

**Q:** Why would an organization run network discovery scans nightly?
**A:** To track what's installed on the network
**Difficulty:** Medium
**Tags:** network-discovery, domain-3, prof-messer

---

**Q:** What can daily discovery scans combined with reporting reveal?
**A:** What traffic is on the network and which devices are sending it
**Difficulty:** Medium
**Tags:** network-discovery, domain-3, prof-messer

---

**Q:** What is traffic analysis?
**A:** A detailed frame-by-frame / packet-by-packet description of traffic flowing across the network, often summarized into simplified views
**Difficulty:** Easy
**Tags:** traffic-analysis, domain-3, prof-messer

---

**Q:** Name six types of data found in firewall log entries.
**A:** Timestamp, protocol (TCP/UDP), port numbers, client IP, server IP, host names (via DNS), and bytes transferred
**Difficulty:** Hard
**Tags:** traffic-analysis, firewall-logs, domain-3, prof-messer

---

**Q:** Why is firewall log data stored long-term?
**A:** For generating reports and performing forensic analysis
**Difficulty:** Easy
**Tags:** traffic-analysis, firewall-logs, domain-3, prof-messer

---

**Q:** How are host names determined in firewall log data?
**A:** Through DNS resolution of IP addresses
**Difficulty:** Medium
**Tags:** traffic-analysis, firewall-logs, dns, domain-3, prof-messer

---

**Q:** What is performance monitoring used for?
**A:** Gathering overall performance data from devices — network utilization statistics and error overviews — to determine if the network is highly utilized or experiencing errors
**Difficulty:** Easy
**Tags:** performance-monitoring, domain-3, prof-messer

---

**Q:** Name four methods used for performance monitoring.
**A:** SNMP, NetFlow statistics, protocol analysis (frame level), and software agents on devices
**Difficulty:** Hard
**Tags:** performance-monitoring, domain-3, prof-messer

---

**Q:** What two key metrics does performance monitoring track?
**A:** Network utilization statistics and error overview
**Difficulty:** Medium
**Tags:** performance-monitoring, domain-3, prof-messer

---

**Q:** What is availability monitoring?
**A:** A simple metric showing whether a device is up (green) or down (red), providing instant visibility into device status
**Difficulty:** Easy
**Tags:** availability-monitoring, domain-3, prof-messer

---

**Q:** What actions can availability monitoring trigger when a device goes down?
**A:** Email messages, helpdesk tickets, and notifications to responsible staff
**Difficulty:** Medium
**Tags:** availability-monitoring, domain-3, prof-messer

---

**Q:** What is the difference between availability monitoring's real-time view and historical data?
**A:** Real-time shows current device status (up/down); historical data is collected over time to produce availability reports
**Difficulty:** Medium
**Tags:** availability-monitoring, domain-3, prof-messer

---

**Q:** If you need deeper performance details beyond availability status, what should you drill down into?
**A:** NetFlow data or SNMP statistics
**Difficulty:** Medium
**Tags:** availability-monitoring, netflow, snmp, domain-3, prof-messer

---

**Q:** Why might a backed-up configuration file fail to load on a device?
**A:** Configuration files may be version-specific — an older config may not load on a newer software version
**Difficulty:** Medium
**Tags:** configuration-management, domain-3, prof-messer

---

**Q:** What must you store alongside configuration file backups and why?
**A:** Previous firmware/software versions — because you may need to downgrade to restore an older config that is incompatible with the current version
**Difficulty:** Hard
**Tags:** configuration-management, domain-3, prof-messer

---

**Q:** Why would you compare configuration files across multiple identical devices (e.g., 10 web servers)?
**A:** To verify consistency — ensure all devices share the same configuration
**Difficulty:** Medium
**Tags:** configuration-management, domain-3, prof-messer

---

**Q:** What should happen if an unauthorized change is detected in a device's configuration file?
**A:** An alert should be triggered — ongoing monitoring of config files detects unauthorized changes
**Difficulty:** Medium
**Tags:** configuration-management, domain-3, prof-messer

---

**Q:** How does configuration file management integrate with change control?
**A:** Through a standardized method for modifying configurations — all changes go through the change control process
**Difficulty:** Medium
**Tags:** configuration-management, change-control, domain-3, prof-messer

---

**Q:** What types of devices have configuration files that need management?
**A:** Switches, routers, and firewalls
**Difficulty:** Easy
**Tags:** configuration-management, domain-3, prof-messer
