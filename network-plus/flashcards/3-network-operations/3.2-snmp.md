# SNMP Flashcards

**Q:** What is SNMP and what is it used for?
**A:** Simple Network Management Protocol — used for monitoring and configuring network devices through a standard management interface
**Difficulty:** Easy
**Tags:** snmp, domain-3, prof-messer

---

**Q:** What is the role of the network management station in SNMP?
**A:** Central console that queries devices via SNMP and stores the response values
**Difficulty:** Easy
**Tags:** snmp, domain-3, prof-messer

---

**Q:** What is a MIB?
**A:** Management Information Base — a central database of parameters stored on each managed device that SNMP queries
**Difficulty:** Easy
**Tags:** snmp, mib, domain-3, prof-messer

---

**Q:** What is an OID in SNMP?
**A:** Object Identifier — a series of numbers representing a hierarchical path to a specific variable in the MIB (e.g., `1.3.6.1.2.1.11.28.0`)
**Difficulty:** Medium
**Tags:** snmp, oid, domain-3, prof-messer

---

**Q:** What does each number in an OID represent?
**A:** A level in the hierarchy — e.g., 1 = ISO, 3 = org, 6 = DoD, 1 = internet, 2 = management, continuing down to the specific variable
**Difficulty:** Hard
**Tags:** snmp, oid, domain-3, prof-messer

---

**Q:** What is MIB2 (SNMPV2-MIB)?
**A:** A standardized set of OIDs that are identical across devices from different manufacturers
**Difficulty:** Medium
**Tags:** snmp, mib, domain-3, prof-messer

---

**Q:** How are manufacturer-specific OIDs handled?
**A:** The manufacturer provides documentation or a MIB file that can be imported into the management station to interpret their unique OIDs
**Difficulty:** Medium
**Tags:** snmp, mib, oid, domain-3, prof-messer

---

**Q:** What is a MIB browser/walker?
**A:** Software that cycles through every possible MIB value on a device and retrieves all available data
**Difficulty:** Medium
**Tags:** snmp, mib, domain-3, prof-messer

---

**Q:** What port does SNMP polling use?
**A:** UDP 161
**Difficulty:** Easy
**Tags:** snmp, ports, domain-3, prof-messer

---

**Q:** What port do SNMP traps use?
**A:** UDP 162
**Difficulty:** Easy
**Tags:** snmp, traps, ports, domain-3, prof-messer

---

**Q:** What is the limitation of SNMP polling?
**A:** Problems are not detected until the next polling interval — there's a delay between the issue occurring and the management station discovering it
**Difficulty:** Medium
**Tags:** snmp, polling, domain-3, prof-messer

---

**Q:** What is an SNMP trap?
**A:** A proactive alarm sent from the device to the management station without the management station needing to poll first
**Difficulty:** Easy
**Tags:** snmp, traps, domain-3, prof-messer

---

**Q:** How are SNMP traps configured?
**A:** Threshold conditions are set on the device (e.g., CRC error count increases by 5), and when triggered, the device sends a trap to the management station
**Difficulty:** Medium
**Tags:** snmp, traps, domain-3, prof-messer

---

**Q:** What can the management station do when it receives a trap?
**A:** Alert staff or run remediation scripts automatically
**Difficulty:** Easy
**Tags:** snmp, traps, domain-3, prof-messer

---

**Q:** What are the three versions of SNMP?
**A:** v1 (original, no encryption), v2c (bulk queries, no encryption), v3 (encryption + authentication)
**Difficulty:** Easy
**Tags:** snmp, versions, domain-3, prof-messer

---

**Q:** What improvement does SNMP v2c offer over v1?
**A:** Ability to query large chunks of data at once (bulk queries) for more efficient communication
**Difficulty:** Medium
**Tags:** snmp, versions, domain-3, prof-messer

---

**Q:** What security weakness do SNMP v1 and v2c share?
**A:** All data is sent in the clear — no encryption
**Difficulty:** Easy
**Tags:** snmp, versions, security, domain-3, prof-messer

---

**Q:** What security features does SNMP v3 add?
**A:** Encryption, message integrity, and authentication (username + password hash)
**Difficulty:** Medium
**Tags:** snmp, versions, security, domain-3, prof-messer

---

**Q:** What is a community string in SNMP?
**A:** A simple password that allows access to SNMP data on a device — used in v1 and v2c
**Difficulty:** Easy
**Tags:** snmp, authentication, domain-3, prof-messer

---

**Q:** What are the three common community strings configured on a device?
**A:** Read-only (default: `public`), read-write (default: `private`), and a trap community string
**Difficulty:** Medium
**Tags:** snmp, authentication, domain-3, prof-messer

---

**Q:** What is the default read-only community string?
**A:** `public`
**Difficulty:** Easy
**Tags:** snmp, authentication, domain-3, prof-messer

---

**Q:** What is the default read-write community string?
**A:** `private`
**Difficulty:** Easy
**Tags:** snmp, authentication, domain-3, prof-messer

---

**Q:** How does SNMP v3 authentication differ from community strings?
**A:** Uses a username and password sent as a password hash instead of a plaintext community string
**Difficulty:** Medium
**Tags:** snmp, authentication, versions, domain-3, prof-messer

---

**Q:** Which SNMP version is recommended for production use?
**A:** SNMP v3 — most secure with encryption, message integrity, and hashed authentication
**Difficulty:** Easy
**Tags:** snmp, versions, security, domain-3, prof-messer

---

**Q:** What is the direction of communication for SNMP polling vs. traps?
**A:** Polling: management station → device (request/response on UDP 161). Traps: device → management station (proactive alert on UDP 162)
**Difficulty:** Medium
**Tags:** snmp, polling, traps, domain-3, prof-messer

---

**Q:** Which SNMP versions use community strings for authentication?
**A:** v1 and v2c only
**Difficulty:** Easy
**Tags:** snmp, authentication, versions, domain-3, prof-messer

---

**Q:** What type of data can be gathered by polling SNMP over time?
**A:** Performance graphs and visualizations built from MIB values (e.g., bytes into a particular interface)
**Difficulty:** Medium
**Tags:** snmp, polling, domain-3, prof-messer

---

**Q:** What transport protocol does SNMP use?
**A:** UDP (port 161 for polling, port 162 for traps)
**Difficulty:** Easy
**Tags:** snmp, ports, domain-3, prof-messer
