# Configuring DHCP Flashcards

**Q:** What is a DHCP scope?
**A:** A defined pool of addresses and settings on a DHCP server that includes the IP address range, excluded addresses, subnet mask, lease duration, and optional settings
**Difficulty:** Easy
**Tags:** dhcp, scope, configuration, domain-3, prof-messer

---

**Q:** What five things are commonly included in a DHCP scope?
**A:** IP address range, excluded addresses, subnet mask, lease duration, and optional settings (DNS servers, default gateway, VoIP server, etc.)
**Difficulty:** Medium
**Tags:** dhcp, scope, configuration, domain-3, prof-messer

---

**Q:** How are DHCP scopes organized relative to subnets?
**A:** One scope per subnet — each scope is responsible for providing that particular subnet's IP addresses
**Difficulty:** Medium
**Tags:** dhcp, scope, configuration, domain-3, prof-messer

---

**Q:** What is a contiguous pool in a DHCP scope?
**A:** A continuous range of IP addresses (e.g., .1 through .100) that the DHCP server can assign from
**Difficulty:** Easy
**Tags:** dhcp, scope, configuration, domain-3, prof-messer

---

**Q:** What are excluded addresses in a DHCP scope?
**A:** Addresses within the IP address range that should not be assigned to devices by the DHCP server
**Difficulty:** Easy
**Tags:** dhcp, scope, configuration, domain-3, prof-messer

---

**Q:** When a device requests an address, how does the DHCP server respond?
**A:** The server picks an address from the pool, assigns it to the device, and associates a lease period with it
**Difficulty:** Easy
**Tags:** dhcp, assignment, domain-3, prof-messer

---

**Q:** What happens to a DHCP address if the lease is not renewed?
**A:** The address returns to the pool and can be assigned to another device
**Difficulty:** Easy
**Tags:** dhcp, lease, assignment, domain-3, prof-messer

---

**Q:** What does the DHCP server track about previous assignments?
**A:** MAC-to-IP pairings — so it can recognize returning devices
**Difficulty:** Medium
**Tags:** dhcp, assignment, domain-3, prof-messer

---

**Q:** What happens if a device returns to the network and its previous DHCP-assigned IP is still available?
**A:** The DHCP server reassigns the same IP address the device had on its original visit
**Difficulty:** Medium
**Tags:** dhcp, assignment, domain-3, prof-messer

---

**Q:** What is a DHCP address reservation?
**A:** A configuration that assigns a fixed IP address to a specific MAC address via the DHCP server, ensuring the device always receives the same IP
**Difficulty:** Easy
**Tags:** dhcp, reservation, configuration, domain-3, prof-messer

---

**Q:** What are three other names for DHCP address reservation?
**A:** Static DHCP assignment, static DHCP, or IP reservation
**Difficulty:** Medium
**Tags:** dhcp, reservation, terminology, domain-3, prof-messer

---

**Q:** What is the use case for DHCP address reservations?
**A:** Printers, servers, or any device that needs a consistent IP address without manual static configuration
**Difficulty:** Easy
**Tags:** dhcp, reservation, domain-3, prof-messer

---

**Q:** Why use DHCP reservations instead of manually configuring static IPs on devices?
**A:** Central management — all address assignments are managed in one place, and changes don't require visiting each device individually (better scalability)
**Difficulty:** Medium
**Tags:** dhcp, reservation, domain-3, prof-messer

---

**Q:** What three pieces of information does a DHCP reservation table contain?
**A:** MAC address, reserved IP address, and device name
**Difficulty:** Medium
**Tags:** dhcp, reservation, configuration, domain-3, prof-messer

---

**Q:** What is the difference between a DHCP reservation (static DHCP) and a static IP configuration?
**A:** A reservation is configured on the DHCP server (device still uses DHCP); a static configuration is set manually on the device itself with no DHCP involvement
**Difficulty:** Hard
**Tags:** dhcp, reservation, static, domain-3, prof-messer

---

**Q:** Are DHCP-assigned IP addresses permanent?
**A:** No — they are leased for a configured duration and must be renewed or they return to the pool
**Difficulty:** Easy
**Tags:** dhcp, lease, domain-3, prof-messer

---

**Q:** What happens when a device shuts down regarding its DHCP lease?
**A:** It can release the IP address back into the pool so other devices can use it
**Difficulty:** Easy
**Tags:** dhcp, lease, domain-3, prof-messer

---

**Q:** What happens to a DHCP lease when a device restarts or reconnects to the network?
**A:** It reinitializes the DHCP process and may restart the lease
**Difficulty:** Medium
**Tags:** dhcp, lease, domain-3, prof-messer

---

**Q:** What is the T1 timer in DHCP leasing?
**A:** A renewal timer set at 50% of the lease time, at which point the device attempts to renew with the original DHCP server
**Difficulty:** Medium
**Tags:** dhcp, lease, timers, domain-3, prof-messer

---

**Q:** What is the T2 timer in DHCP leasing?
**A:** A rebinding timer set at 87.5% (7/8) of the lease time, at which point the device attempts to renew with any available DHCP server
**Difficulty:** Medium
**Tags:** dhcp, lease, timers, domain-3, prof-messer

---

**Q:** What is the key difference between T1 and T2 renewal behavior?
**A:** T1 contacts the original DHCP server only; T2 contacts any available DHCP server on the network
**Difficulty:** Hard
**Tags:** dhcp, lease, timers, domain-3, prof-messer

---

**Q:** What is the default T1 timer value as a percentage of lease time?
**A:** 50%
**Difficulty:** Medium
**Tags:** dhcp, lease, timers, domain-3, prof-messer

---

**Q:** What is the default T2 timer value as a percentage/fraction of lease time?
**A:** 87.5% or 7/8
**Difficulty:** Medium
**Tags:** dhcp, lease, timers, domain-3, prof-messer

---

**Q:** In an 8-day DHCP lease, when does the T1 timer fire?
**A:** Day 4 (50% of 8 days)
**Difficulty:** Medium
**Tags:** dhcp, lease, timers, domain-3, prof-messer

---

**Q:** In an 8-day DHCP lease, when does the T2 timer fire?
**A:** Day 7 (7/8 of 8 days)
**Difficulty:** Medium
**Tags:** dhcp, lease, timers, domain-3, prof-messer

---

**Q:** What happens if the original DHCP server successfully responds during the T1 renewal period?
**A:** The lease resets and the timer restarts from the beginning
**Difficulty:** Medium
**Tags:** dhcp, lease, timers, domain-3, prof-messer

---

**Q:** What triggers the T2 rebinding period?
**A:** The original DHCP server is unavailable and did not respond during the T1 renewal period
**Difficulty:** Hard
**Tags:** dhcp, lease, timers, domain-3, prof-messer

---

**Q:** During the T2 rebinding period, what does the device do?
**A:** Reaches out to any available DHCP server on the network to renew the lease
**Difficulty:** Medium
**Tags:** dhcp, lease, timers, domain-3, prof-messer

---

**Q:** What are DHCP options?
**A:** Additional TCP/IP settings (beyond IP/subnet/gateway) delivered to clients during the DHCP process, identified by numbered option fields
**Difficulty:** Medium
**Tags:** dhcp, options, configuration, domain-3, prof-messer

---

**Q:** How many usable DHCP options are available?
**A:** 254
**Difficulty:** Medium
**Tags:** dhcp, options, domain-3, prof-messer

---

**Q:** Where are DHCP options defined?
**A:** In the DHCP RFC (Request for Comments)
**Difficulty:** Medium
**Tags:** dhcp, options, domain-3, prof-messer

---

**Q:** What were DHCP options originally called in the BOOTP era?
**A:** Vendor extensions
**Difficulty:** Hard
**Tags:** dhcp, options, bootp, domain-3, prof-messer

---

**Q:** What is DHCP option 129?
**A:** Call server IP address (VoIP)
**Difficulty:** Hard
**Tags:** dhcp, options, voip, domain-3, prof-messer

---

**Q:** What is DHCP option 135?
**A:** HTTP proxy
**Difficulty:** Hard
**Tags:** dhcp, options, domain-3, prof-messer

---

**Q:** What should you verify before trying to use a specific DHCP option?
**A:** That the DHCP server supports that specific option — not all DHCP servers support all 254 options
**Difficulty:** Medium
**Tags:** dhcp, options, configuration, domain-3, prof-messer

**Difficulty:** Medium
**Tags:** dhcp, options, configuration, domain-3, prof-messer

**A:** The IP address, subnet mask, default gateway, DNS settings, plus any additional configurations defined under DHCP Options
**Difficulty:** Medium
