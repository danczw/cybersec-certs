# IPv6 and SLAAC Flashcards

**Q:** How does DHCPv6 compare to IPv4 DHCP?
**A:** It uses a similar process to IPv4 DHCP, with redundant DHCP servers for enterprise readiness, managed by the DHCP administrator
**Difficulty:** Easy
**Tags:** dhcpv6, ipv6, domain-3, prof-messer

---

**Q:** What is stateless addressing in IPv6?
**A:** IPv6 devices can assign an IP address to themselves and communicate on the network without a DHCP server managing the process
**Difficulty:** Easy
**Tags:** stateless, ipv6, slaac, domain-3, prof-messer

---

**Q:** What three things are eliminated with IPv6 stateless addressing compared to DHCP?
**A:** No DHCP server managing the process, no need to track IP/MAC addresses, and no lease time
**Difficulty:** Medium
**Tags:** stateless, ipv6, domain-3, prof-messer

---

**Q:** Why is there no lease time with IPv6 stateless addressing?
**A:** The address never needs to be given up — it is self-assigned and permanent as long as the device uses it
**Difficulty:** Medium
**Tags:** stateless, ipv6, domain-3, prof-messer

---

**Q:** What is the Neighbor Discovery Protocol (NDP)?
**A:** An IPv6 protocol that replaces ARP from IPv4, using multicast instead of broadcasts to find devices, identify routers, and detect duplicate addresses
**Difficulty:** Easy
**Tags:** ndp, ipv6, domain-3, prof-messer

---

**Q:** What IPv4 protocol does NDP replace?
**A:** ARP (Address Resolution Protocol)
**Difficulty:** Easy
**Tags:** ndp, arp, ipv6, domain-3, prof-messer

---

**Q:** Why is NDP more efficient than ARP?
**A:** ARP uses broadcasts (sent to all devices); NDP uses multicast (sent only to interested devices)
**Difficulty:** Medium
**Tags:** ndp, arp, ipv6, domain-3, prof-messer

---

**Q:** What are the three functions of NDP?
**A:** Find other devices on the network, identify routers (via RS/RA), and Duplicate Address Detection (DAD)
**Difficulty:** Medium
**Tags:** ndp, ipv6, domain-3, prof-messer

---

**Q:** What is a Router Solicitation (RS)?
**A:** A multicast message sent by a device asking any routers on the local subnet to respond
**Difficulty:** Easy
**Tags:** ndp, rs, ipv6, domain-3, prof-messer

---

**Q:** How does a router respond to a Router Solicitation?
**A:** It sends a Router Advertisement (RA) directly back to the device
**Difficulty:** Easy
**Tags:** ndp, rs, ra, ipv6, domain-3, prof-messer

---

**Q:** What is a Router Advertisement (RA)?
**A:** A message from a router providing local subnet information — sent in response to an RS, or unsolicited to all devices on the network
**Difficulty:** Medium
**Tags:** ndp, ra, ipv6, domain-3, prof-messer

---

**Q:** What is an unsolicited RA?
**A:** A Router Advertisement sent by a router without being queried, to a multicast address for all devices that might be interested in knowing where routers exist
**Difficulty:** Medium
**Tags:** ndp, ra, ipv6, domain-3, prof-messer

---

**Q:** How do unsolicited RAs differ from solicited RAs in terms of destination?
**A:** Unsolicited RAs are sent to a different multicast address than solicited ones
**Difficulty:** Hard
**Tags:** ndp, ra, ipv6, domain-3, prof-messer

---

**Q:** What four pieces of information can a Router Advertisement provide?
**A:** Prefix value, prefix length, DNS server configuration, and other IPv6 configuration parameters
**Difficulty:** Medium
**Tags:** ndp, ra, ipv6, domain-3, prof-messer

---

**Q:** What is SLAAC?
**A:** Stateless Address Autoconfiguration — allows an IPv6 device to create its own routable IP address without a DHCP server
**Difficulty:** Easy
**Tags:** slaac, ipv6, domain-3, prof-messer

---

**Q:** What is the first step of the SLAAC process?
**A:** The device sends a Router Solicitation via NDP to determine the local subnet
**Difficulty:** Medium
**Tags:** slaac, ndp, rs, ipv6, domain-3, prof-messer

---

**Q:** What does the router provide to a device during SLAAC?
**A:** A Router Advertisement containing the 64-bit subnet prefix
**Difficulty:** Medium
**Tags:** slaac, ra, ipv6, domain-3, prof-messer

---

**Q:** How many bits does the subnet prefix occupy in an IPv6 address during SLAAC?
**A:** 64 bits
**Difficulty:** Easy
**Tags:** slaac, ipv6, domain-3, prof-messer

---

**Q:** What is the interface ID in an IPv6 address?
**A:** The last 64 bits of the address, generated by the device itself during SLAAC
**Difficulty:** Medium
**Tags:** slaac, ipv6, domain-3, prof-messer

---

**Q:** What are the two methods a device can use to generate the 64-bit interface ID?
**A:** Modified MAC address (inserts ff:fe in the middle of the MAC) or a random 64-bit value
**Difficulty:** Medium
**Tags:** slaac, interface-id, ipv6, domain-3, prof-messer

---

**Q:** How does the modified MAC address method create a 64-bit interface ID?
**A:** It inserts ff:fe in the middle of the 48-bit MAC address to create 64 bits
**Difficulty:** Hard
**Tags:** slaac, interface-id, ipv6, domain-3, prof-messer

---

**Q:** What is the final step of SLAAC before the address is usable?
**A:** The device runs Duplicate Address Detection (DAD) via NDP to confirm no other device uses that address
**Difficulty:** Medium
**Tags:** slaac, dad, ndp, ipv6, domain-3, prof-messer

---

**Q:** What does the device have after SLAAC completes?
**A:** A fully routable, unique IPv6 address
**Difficulty:** Easy
**Tags:** slaac, ipv6, domain-3, prof-messer

---

**Q:** List the five steps of the SLAAC process in order.
**A:** 1) Send Router Solicitation via NDP, 2) Receive Router Advertisement with 64-bit prefix, 3) Generate 64-bit interface ID (modified MAC or random), 4) Run DAD to check for duplicates, 5) Address is now routable and unique
**Difficulty:** Hard
**Tags:** slaac, ipv6, domain-3, prof-messer

---

**Q:** What is Duplicate Address Detection (DAD)?
**A:** A feature of NDP that checks the network to ensure no other device is using the same IPv6 address
**Difficulty:** Easy
**Tags:** dad, ndp, ipv6, domain-3, prof-messer

---

**Q:** Why is DAD necessary in IPv6?
**A:** Because self-assigned addresses (via SLAAC) could potentially conflict with existing addresses on the network
**Difficulty:** Medium
**Tags:** dad, slaac, ipv6, domain-3, prof-messer

---

**Q:** What protocol is DAD a part of?
**A:** Neighbor Discovery Protocol (NDP)
**Difficulty:** Easy
**Tags:** dad, ndp, ipv6, domain-3, prof-messer

---

**Q:** What is the key difference between IPv4 and IPv6 regarding self-assigned addressing?
**A:** IPv4 requires DHCP or manual configuration; IPv6 can assign itself a routable address via SLAAC with no server involvement
**Difficulty:** Medium
**Tags:** ipv6, ipv4, slaac, stateless, domain-3, prof-messer
