# Remote Access Flashcards

**Q:** What is SSH and what does it provide?
**A:** Secure Shell — provides encrypted terminal/console access to remote devices (switches, routers, firewalls)
**Difficulty:** Easy
**Tags:** ssh, remote-access, domain-3, prof-messer

---

**Q:** What port and protocol does SSH use?
**A:** TCP port 22
**Difficulty:** Easy
**Tags:** ssh, ports, domain-3, prof-messer

---

**Q:** What protocol does SSH replace, and why?
**A:** Telnet (TCP port 23) — Telnet provides the same console-based view but no encryption
**Difficulty:** Easy
**Tags:** ssh, telnet, domain-3, prof-messer

---

**Q:** What port and protocol does Telnet use?
**A:** TCP port 23
**Difficulty:** Easy
**Tags:** telnet, ports, domain-3, prof-messer

---

**Q:** Why is SSH the best practice over Telnet?
**A:** SSH encrypts all traffic (username, password, all data) so no one can capture and read it; Telnet provides no encryption
**Difficulty:** Easy
**Tags:** ssh, telnet, security, domain-3, prof-messer

---

**Q:** What is RDP?
**A:** Microsoft Remote Desktop Protocol — allows graphical remote control of Windows machines as if sitting in front of the monitor and keyboard
**Difficulty:** Easy
**Tags:** rdp, remote-desktop, domain-3, prof-messer

---

**Q:** Can RDP clients run on non-Windows operating systems?
**A:** Yes — RDP clients are available for nearly any operating system
**Difficulty:** Easy
**Tags:** rdp, remote-desktop, domain-3, prof-messer

---

**Q:** What is VNC and what protocol does it use?
**A:** Virtual Network Computing — uses the RFB (Remote Frame Buffer) protocol
**Difficulty:** Medium
**Tags:** vnc, rfb, remote-desktop, domain-3, prof-messer

---

**Q:** How does VNC differ from RDP?
**A:** VNC provides similar remote desktop functionality but can run on many different operating systems (not Microsoft-specific)
**Difficulty:** Medium
**Tags:** vnc, rdp, comparison, domain-3, prof-messer

---

**Q:** What two protocols are commonly used by help desk/support teams for remote desktop control?
**A:** RDP and VNC
**Difficulty:** Easy
**Tags:** rdp, vnc, remote-desktop, domain-3, prof-messer

---

**Q:** Why use an API instead of command-line scripts for managing many devices?
**A:** APIs allow automation with error handling capabilities and more control when problems occur, versus scripts/batch files which offer limited control at the command line
**Difficulty:** Medium
**Tags:** api, automation, domain-3, prof-messer

---

**Q:** What does an API allow you to do with network devices?
**A:** Connect and control devices using the language the device expects, automate processes, and handle errors
**Difficulty:** Medium
**Tags:** api, automation, domain-3, prof-messer

---

**Q:** What is a console connection on a network device?
**A:** A direct physical connection via a separate console port using serial (RJ45, DB9) or USB
**Difficulty:** Medium
**Tags:** console, remote-access, domain-3, prof-messer

---

**Q:** What three serial connection types can be used for console access?
**A:** RJ45 serial, DB9 serial, or USB
**Difficulty:** Medium
**Tags:** console, serial, domain-3, prof-messer

---

**Q:** When is a console connection especially useful?
**A:** When network connectivity is lost — you cannot ping or SSH into the device, but can still directly connect via console cable
**Difficulty:** Medium
**Tags:** console, troubleshooting, domain-3, prof-messer

---

**Q:** What type of interface does a console connection provide?
**A:** Text-based interface requiring knowledge of the device's command line interface (CLI)
**Difficulty:** Easy
**Tags:** console, cli, domain-3, prof-messer

---

**Q:** What hardware is needed to use a console connection?
**A:** A laptop/desktop with a serial port, or a USB-to-serial adapter
**Difficulty:** Medium
**Tags:** console, serial, domain-3, prof-messer

---

**Q:** What is a jump server?
**A:** A single device you connect to first, then jump to other devices within the organization — eliminates needing separate connections to each device
**Difficulty:** Medium
**Tags:** jump-server, remote-access, domain-3, prof-messer

---

**Q:** How do you connect to a jump server from an external location?
**A:** Via VPN tunnel or SSH connection
**Difficulty:** Medium
**Tags:** jump-server, vpn, ssh, domain-3, prof-messer

---

**Q:** Why must a jump server be highly hardened?
**A:** It is externally facing — anyone on the internet could potentially connect to it
**Difficulty:** Medium
**Tags:** jump-server, security, domain-3, prof-messer

---

**Q:** What security measures are required for a jump server?
**A:** Multi-factor authentication, always up to date with security patches, high level of authentication to prevent brute force attacks
**Difficulty:** Hard
**Tags:** jump-server, security, domain-3, prof-messer

---

**Q:** What is in-band management?
**A:** Connecting to a device over the existing network using an assigned management IP address, via SSH or web-based front end
**Difficulty:** Medium
**Tags:** in-band, management, domain-3, prof-messer

---

**Q:** What details must be configured on a device for in-band management?
**A:** Management IP address, subnet mask, and other networking details
**Difficulty:** Medium
**Tags:** in-band, management, domain-3, prof-messer

---

**Q:** What two access methods does in-band management typically support?
**A:** SSH (via internal SSH server) or web-based front end (via internal web server)
**Difficulty:** Medium
**Tags:** in-band, management, domain-3, prof-messer

---

**Q:** Can the management interface be shared with other interfaces on a device?
**A:** Yes — it can be a separate dedicated interface or built into existing interfaces
**Difficulty:** Medium
**Tags:** in-band, management, domain-3, prof-messer

---

**Q:** What is out-of-band management?
**A:** Using a serial interface that does not use the existing network — separate management/console interface via serial or USB
**Difficulty:** Medium
**Tags:** out-of-band, management, domain-3, prof-messer

---

**Q:** How can out-of-band management provide remote access when the network is down?
**A:** Connect a modem to the console/COM port and dial in via a phone line
**Difficulty:** Hard
**Tags:** out-of-band, management, modem, domain-3, prof-messer

---

**Q:** What is a COM server in the context of out-of-band management?
**A:** A server you dial into, from which you can then jump to other devices through that COM server connection
**Difficulty:** Hard
**Tags:** out-of-band, com-server, domain-3, prof-messer

---

**Q:** What is the key difference between in-band and out-of-band management?
**A:** In-band uses the existing network (IP address, SSH/web). Out-of-band uses a serial interface that does not use the existing network.
**Difficulty:** Medium
**Tags:** in-band, out-of-band, comparison, domain-3, prof-messer

---

**Q:** Compare SSH, RDP, and VNC as remote access methods.
**A:** SSH: encrypted text-based terminal (TCP 22). RDP: Microsoft graphical remote desktop. VNC: cross-platform graphical remote desktop using RFB protocol.
**Difficulty:** Hard
**Tags:** ssh, rdp, vnc, comparison, domain-3, prof-messer
