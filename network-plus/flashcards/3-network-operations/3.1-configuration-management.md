# Configuration Management Flashcards

**Q:** Why do we need a formal configuration management process?
**A:** Changes are inevitable — need to know when they occur, plan for them, and inform everyone
**Difficulty:** Easy
**Tags:** config-management, domain-3, prof-messer

---

**Q:** Why is configuration documentation critical for disaster recovery?
**A:** It leads you from initial installation through all changes made — essential for rebuilding a system quickly
**Difficulty:** Medium
**Tags:** config-management, documentation, domain-3, prof-messer

---

**Q:** What is a production configuration?
**A:** The standard configuration used when a device (switch, router, firewall) is working perfectly after initial setup
**Difficulty:** Medium
**Tags:** config-management, production, domain-3, prof-messer

---

**Q:** What does a production configuration cover beyond device settings?
**A:** All aspects: hardware/firmware versions, device driver updates, and software versions
**Difficulty:** Medium
**Tags:** config-management, production, domain-3, prof-messer

---

**Q:** Why are software versions tracked in a production configuration?
**A:** Certain versions may work better or worse than others
**Difficulty:** Easy
**Tags:** config-management, production, domain-3, prof-messer

---

**Q:** Should new configurations be installed directly into production to test them?
**A:** No — extensive testing is done behind the scenes before deploying to production
**Difficulty:** Easy
**Tags:** config-management, production, domain-3, prof-messer

---

**Q:** What is the standard operating procedure before making any change?
**A:** Make a backup of the system before making any change
**Difficulty:** Easy
**Tags:** config-management, backup, domain-3, prof-messer

---

**Q:** Why are backup configurations necessary even after lab testing?
**A:** Not every possible scenario can be tested in the lab — need a plan to revert if something goes wrong in production
**Difficulty:** Medium
**Tags:** config-management, backup, domain-3, prof-messer

---

**Q:** What devices do backup configurations apply to?
**A:** Firewalls, switches, routers, operating systems, and anything else being changed
**Difficulty:** Easy
**Tags:** config-management, backup, domain-3, prof-messer

---

**Q:** What are two methods for backing up a configuration?
**A:** Copy files that will be updated (e.g., a config file), or take a VM snapshot
**Difficulty:** Medium
**Tags:** config-management, backup, domain-3, prof-messer

---

**Q:** What does a VM snapshot save?
**A:** Files, configuration, and everything associated with the VM at that point in time
**Difficulty:** Medium
**Tags:** config-management, backup, vm, domain-3, prof-messer

---

**Q:** When can you revert to a backup configuration?
**A:** Immediately if there's a problem, or later if you decide to go back to the previous configuration
**Difficulty:** Easy
**Tags:** config-management, backup, domain-3, prof-messer

---

**Q:** Why does deploying an application involve more than just a server?
**A:** It includes many components: workstation configurations, firewall changes, and the application server itself
**Difficulty:** Medium
**Tags:** config-management, golden-config, domain-3, prof-messer

---

**Q:** What is a golden configuration (baseline)?
**A:** A documented configuration that certifies an application will work properly if all configurations are in place
**Difficulty:** Medium
**Tags:** config-management, golden-config, domain-3, prof-messer

---

**Q:** How is a golden configuration created?
**A:** By documenting every aspect of the application installation
**Difficulty:** Medium
**Tags:** config-management, golden-config, domain-3, prof-messer

---

**Q:** What are integrity checks in configuration management?
**A:** Comparisons of the production configuration against the baseline/golden config to verify proper software and correct settings
**Difficulty:** Medium
**Tags:** config-management, golden-config, integrity, domain-3, prof-messer

---

**Q:** What are the two options when an integrity check finds differences between production and golden config?
**A:** Update production to match the golden config, OR update the baseline to match the new production configuration
**Difficulty:** Hard
**Tags:** config-management, golden-config, integrity, domain-3, prof-messer

---

**Q:** What happens after the baseline is updated to match production?
**A:** The new version becomes the baseline used for integrity checks going forward
**Difficulty:** Medium
**Tags:** config-management, golden-config, domain-3, prof-messer

---

**Q:** Name five types of changes that configuration management covers.
**A:** OS updates, device patches, application updates, firewall configurations, new application installations
**Difficulty:** Medium
**Tags:** config-management, domain-3, prof-messer
