# An Overview of DNS Flashcards

**Q:** What is the primary purpose of DNS?
**A:** Translates domain names (e.g., www.professormesser.com) into IP addresses
**Difficulty:** Easy
**Tags:** dns, domain-3, prof-messer

---

**Q:** How is the DNS database structured?
**A:** As a hierarchy — starting at the root, then TLDs, then domain names, then subdomains/hosts
**Difficulty:** Easy
**Tags:** dns, hierarchy, domain-3, prof-messer

---

**Q:** What is at the very top of the DNS hierarchy?
**A:** The root, represented by a single dot (`.`)
**Difficulty:** Medium
**Tags:** dns, hierarchy, domain-3, prof-messer

---

**Q:** What are Top Level Domains (TLDs)?
**A:** The first level below the root in the DNS hierarchy — includes generic TLDs (.com, .org, .net) and country code TLDs (.us, .ca, .uk)
**Difficulty:** Easy
**Tags:** dns, tld, hierarchy, domain-3, prof-messer

---

**Q:** What are examples of generic TLDs?
**A:** .com, .org, .net
**Difficulty:** Easy
**Tags:** dns, tld, domain-3, prof-messer

---

**Q:** What are examples of country code TLDs?
**A:** .us (United States), .ca (Canada), .uk (United Kingdom)
**Difficulty:** Easy
**Tags:** dns, tld, domain-3, prof-messer

---

**Q:** What is a Fully Qualified Domain Name (FQDN)?
**A:** The full path from host to root in the DNS hierarchy (e.g., www.professormesser.com)
**Difficulty:** Medium
**Tags:** dns, fqdn, hierarchy, domain-3, prof-messer

---

**Q:** What are the four levels of the DNS hierarchy from top to bottom?
**A:** Root → Top-Level Domains (TLDs) → Second-Level Domain → Subdomains/Hosts
**Difficulty:** Medium
**Tags:** dns, hierarchy, domain-3, prof-messer

---

**Q:** How many root DNS server clusters exist?
**A:** 13 server clusters, comprising over 1,000 actual servers
**Difficulty:** Medium
**Tags:** dns, infrastructure, domain-3, prof-messer

---

**Q:** What do root DNS servers manage?
**A:** The Top Level Domains (TLDs)
**Difficulty:** Medium
**Tags:** dns, infrastructure, domain-3, prof-messer

---

**Q:** What is the role of a primary DNS server?
**A:** Contains all zone information for the DNS domain; all configuration changes and updates happen here
**Difficulty:** Medium
**Tags:** dns, server-types, domain-3, prof-messer

---

**Q:** What is the role of a secondary DNS server?
**A:** Receives zone information from the primary server in read-only mode; provides redundancy
**Difficulty:** Medium
**Tags:** dns, server-types, domain-3, prof-messer

---

**Q:** How does a secondary DNS server get its zone information?
**A:** It receives it from the primary DNS server (read-only copy)
**Difficulty:** Medium
**Tags:** dns, server-types, domain-3, prof-messer

---

**Q:** Can end users tell whether a response came from a primary or secondary DNS server?
**A:** No — the same information exists in both and the end user has no idea which answered
**Difficulty:** Medium
**Tags:** dns, server-types, domain-3, prof-messer

---

**Q:** What is local name resolution?
**A:** Resolving names locally on the machine without querying a DNS server, using the hosts file
**Difficulty:** Easy
**Tags:** dns, hosts-file, domain-3, prof-messer

---

**Q:** What are two use cases for the hosts file?
**A:** Testing servers (pointing to a test IP instead of production) and overriding incorrect DNS information
**Difficulty:** Medium
**Tags:** dns, hosts-file, domain-3, prof-messer

---

**Q:** Where is the hosts file located on Windows?
**A:** windows/system32/drivers/etc/hosts
**Difficulty:** Medium
**Tags:** dns, hosts-file, domain-3, prof-messer

---

**Q:** What format is the hosts file?
**A:** A simple text file mapping IP addresses to names
**Difficulty:** Easy
**Tags:** dns, hosts-file, domain-3, prof-messer

---

**Q:** Why might you need to change permissions before editing the hosts file?
**A:** It is stored as read-only by default
**Difficulty:** Medium
**Tags:** dns, hosts-file, domain-3, prof-messer

---

**Q:** Do all applications use the hosts file for name resolution?
**A:** No — some applications ignore the hosts file and query DNS directly; check application documentation
**Difficulty:** Medium
**Tags:** dns, hosts-file, domain-3, prof-messer

---

**Q:** What is a forward DNS lookup?
**A:** Provide a name → DNS returns an IP address; the most common DNS operation
**Difficulty:** Easy
**Tags:** dns, forward-lookup, domain-3, prof-messer

---

**Q:** What is a reverse DNS lookup?
**A:** Provide an IP address → DNS returns a name
**Difficulty:** Easy
**Tags:** dns, reverse-lookup, domain-3, prof-messer

---

**Q:** Does a reverse lookup happen automatically if forward lookups are configured?
**A:** No — reverse lookups must be separately configured on the DNS server
**Difficulty:** Medium
**Tags:** dns, reverse-lookup, domain-3, prof-messer

---

**Q:** Can the forward lookup name and reverse lookup name differ for the same IP?
**A:** Yes — the forward name and reverse name may differ
**Difficulty:** Hard
**Tags:** dns, forward-lookup, reverse-lookup, domain-3, prof-messer

---

**Q:** What is an authoritative DNS server?
**A:** The primary DNS server for a DNS zone — the authority for all records in that domain
**Difficulty:** Medium
**Tags:** dns, authoritative, domain-3, prof-messer

---

**Q:** What is a nonauthoritative DNS server?
**A:** A secondary server or caching server that returns cached information, not directly from the zone owner
**Difficulty:** Medium
**Tags:** dns, nonauthoritative, domain-3, prof-messer

---

**Q:** What is the risk of relying on a nonauthoritative DNS server?
**A:** Cached information could be outdated if the authoritative server was recently changed
**Difficulty:** Medium
**Tags:** dns, nonauthoritative, domain-3, prof-messer

---

**Q:** What is TTL in DNS?
**A:** Time to Live — specifies how long (in seconds) a nonauthoritative server may cache a record
**Difficulty:** Medium
**Tags:** dns, ttl, domain-3, prof-messer

---

**Q:** Where is the TTL configured?
**A:** On the authoritative DNS server
**Difficulty:** Medium
**Tags:** dns, ttl, domain-3, prof-messer

---

**Q:** What happens after a DNS TTL expires?
**A:** Cached data is deleted and subsequent queries must go to the authoritative server to be cached again
**Difficulty:** Medium
**Tags:** dns, ttl, domain-3, prof-messer

---

**Q:** A DNS record has a TTL of 300. How long can it be cached?
**A:** 300 seconds (5 minutes)
**Difficulty:** Easy
**Tags:** dns, ttl, domain-3, prof-messer

---

**Q:** What is a recursive DNS query?
**A:** A process by which a local DNS server resolves a name on behalf of the client, doing all the work behind the scenes
**Difficulty:** Medium
**Tags:** dns, recursive, domain-3, prof-messer

---

**Q:** In a recursive DNS query, what does the client (resolver) do?
**A:** It only contacts its local DNS server — the local server handles everything else
**Difficulty:** Medium
**Tags:** dns, recursive, domain-3, prof-messer

---

**Q:** List the five steps of the recursive DNS query process.
**A:** 1) Resolver queries local DNS server, 2) Local server queries root → gets .com NS address, 3) Local server queries .com NS → gets professormesser.com NS address, 4) Local server queries professormesser.com NS → gets IP for www, 5) Local server returns answer to resolver and caches it
**Difficulty:** Hard
**Tags:** dns, recursive, domain-3, prof-messer

---

**Q:** What does the root server return during a recursive query?
**A:** The address of the appropriate TLD name server (e.g., the .com name server)
**Difficulty:** Medium
**Tags:** dns, recursive, domain-3, prof-messer

---

**Q:** After a recursive query completes, what happens with subsequent requests for the same name?
**A:** They are served from the local DNS server's cache
**Difficulty:** Easy
**Tags:** dns, recursive, domain-3, prof-messer

---

**Q:** What are the two security problems with traditional DNS?
**A:** Traffic is sent in the clear (anyone can see queried hostnames), and responses are not authenticated (could be spoofed)
**Difficulty:** Medium
**Tags:** dns, security, domain-3, prof-messer

---

**Q:** What is DNSSEC?
**A:** Domain Name Security Extensions — digitally signs DNS responses to verify they came from a trusted source and have not been modified in transit
**Difficulty:** Medium
**Tags:** dns, dnssec, security, domain-3, prof-messer

---

**Q:** Does DNSSEC encrypt DNS traffic?
**A:** No — it only signs responses for integrity/authenticity; queries are still visible in the clear
**Difficulty:** Hard
**Tags:** dns, dnssec, security, domain-3, prof-messer

---

**Q:** What is DNS over TLS (DoT)?
**A:** A method of encrypting DNS traffic using TLS over TCP port 853
**Difficulty:** Medium
**Tags:** dns, dot, security, domain-3, prof-messer

---

**Q:** What port does DNS over TLS (DoT) use?
**A:** TCP port 853
**Difficulty:** Medium
**Tags:** dns, dot, security, domain-3, prof-messer

---

**Q:** What is DNS over HTTPS (DoH)?
**A:** A method of sending DNS queries over standard HTTPS on TCP port 443, making DNS traffic look identical to normal encrypted web traffic
**Difficulty:** Medium
**Tags:** dns, doh, security, domain-3, prof-messer

---

**Q:** What port does DNS over HTTPS (DoH) use?
**A:** TCP port 443
**Difficulty:** Easy
**Tags:** dns, doh, security, domain-3, prof-messer

---

**Q:** How does DoH traffic appear in a packet capture?
**A:** Identical to normal encrypted web traffic — indistinguishable from regular HTTPS
**Difficulty:** Hard
**Tags:** dns, doh, security, domain-3, prof-messer

---

**Q:** Which modern applications may already use DoH by default?
**A:** Some modern browsers use DoH by default
**Difficulty:** Medium
**Tags:** dns, doh, security, domain-3, prof-messer

---

**Q:** What problem does DNSSEC solve that DoT/DoH do not?
**A:** DNSSEC verifies authenticity and integrity of responses (digitally signed); DoT/DoH only encrypt the transport without verifying the source
**Difficulty:** Hard
**Tags:** dns, dnssec, dot, doh, security, domain-3, prof-messer

---

**Q:** What problem do DoT and DoH solve that DNSSEC does not?
**A:** They encrypt DNS traffic so queries cannot be seen by anyone monitoring; DNSSEC leaves traffic in the clear
**Difficulty:** Hard
**Tags:** dns, dnssec, dot, doh, security, domain-3, prof-messer
