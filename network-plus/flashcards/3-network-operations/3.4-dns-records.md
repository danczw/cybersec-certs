# DNS Records Flashcards

**Q:** What are resource records in DNS?
**A:** Individual entries in a DNS configuration file that provide different types of information (name-to-IP resolution, certificates, aliases, mail server locations, etc.)
**Difficulty:** Easy
**Tags:** dns, resource-records, domain-3, prof-messer

---

**Q:** What is an SOA record?
**A:** Start of Authority — the first record at the top of a DNS configuration file that provides an overview of the DNS zone
**Difficulty:** Medium
**Tags:** dns, soa, domain-3, prof-messer

---

**Q:** What five pieces of information does an SOA record contain?
**A:** DNS zone details (which domain), serial number, retry information, expiration details, and how long information should be stored
**Difficulty:** Hard
**Tags:** dns, soa, domain-3, prof-messer

---

**Q:** Where is the SOA record located in a DNS configuration file?
**A:** At the very top — it is the first record
**Difficulty:** Easy
**Tags:** dns, soa, domain-3, prof-messer

---

**Q:** What does a DNS A record do?
**A:** Defines the IPv4 address of a host — the core record for name resolution
**Difficulty:** Easy
**Tags:** dns, a-record, domain-3, prof-messer

---

**Q:** What does a DNS AAAA record do?
**A:** Defines the IPv6 address of a host — same functionality as an A record but for IPv6
**Difficulty:** Easy
**Tags:** dns, aaaa-record, domain-3, prof-messer

---

**Q:** What is the difference between an A record and an AAAA record?
**A:** A record is for IPv4 addresses; AAAA record is for IPv6 addresses. Same functionality, different IP version.
**Difficulty:** Medium
**Tags:** dns, a-record, aaaa-record, domain-3, prof-messer

---

**Q:** How many A's are in an IPv4 DNS address record vs an IPv6 DNS address record?
**A:** IPv4 has one A (A record); IPv6 has four A's (AAAA record)
**Difficulty:** Easy
**Tags:** dns, a-record, aaaa-record, domain-3, prof-messer

---

**Q:** What does a CNAME record do?
**A:** Creates an alias that points to another name — allows a single server to be referenced by multiple names
**Difficulty:** Medium
**Tags:** dns, cname, domain-3, prof-messer

---

**Q:** What does CNAME stand for?
**A:** Canonical Name
**Difficulty:** Easy
**Tags:** dns, cname, domain-3, prof-messer

---

**Q:** What is the use case for CNAME records?
**A:** A single server with one IP address that needs to be referenced by multiple names (e.g., chat, ftp, and www all pointing to mail.example.com)
**Difficulty:** Medium
**Tags:** dns, cname, domain-3, prof-messer

---

**Q:** Why might querying a CNAME require two DNS lookups?
**A:** First lookup returns the canonical name (target); if the target's IP is not cached, a second query resolves the target's IP address
**Difficulty:** Hard
**Tags:** dns, cname, domain-3, prof-messer

---

**Q:** What is an MX record?
**A:** Mail Exchanger record — specifies the mail server responsible for receiving email for the domain
**Difficulty:** Easy
**Tags:** dns, mx, domain-3, prof-messer

---

**Q:** Does an MX record return an IP address directly?
**A:** No — it returns a name (e.g., mail.example.com); a separate A record lookup is needed to get the IP
**Difficulty:** Medium
**Tags:** dns, mx, domain-3, prof-messer

---

**Q:** What is a TXT record?
**A:** A DNS record that stores human-readable text information, used for multiple purposes including SPF and DKIM
**Difficulty:** Medium
**Tags:** dns, txt, domain-3, prof-messer

---

**Q:** What is SPF?
**A:** Sender Policy Framework — specifies which email servers are authorized to send mail on behalf of the domain, stored in a TXT record
**Difficulty:** Medium
**Tags:** dns, txt, spf, domain-3, prof-messer

---

**Q:** How does SPF prevent email spoofing?
**A:** Receiving mail servers check the SPF record in DNS to verify the sending server is authorized to send mail for that domain
**Difficulty:** Medium
**Tags:** dns, txt, spf, domain-3, prof-messer

---

**Q:** What is DKIM?
**A:** Domain Keys Identified Mail — digitally signs outgoing emails, with the public key stored in a DNS TXT record for verification
**Difficulty:** Medium
**Tags:** dns, txt, dkim, domain-3, prof-messer

---

**Q:** Where is the DKIM public key stored?
**A:** In a TXT record on the domain's DNS server
**Difficulty:** Medium
**Tags:** dns, txt, dkim, domain-3, prof-messer

---

**Q:** How do receiving servers verify a DKIM signature?
**A:** They retrieve the public key from the sender's DNS TXT record and use it to verify the digital signature on the email
**Difficulty:** Hard
**Tags:** dns, txt, dkim, domain-3, prof-messer

---

**Q:** What type of DNS record are both SPF and DKIM stored in?
**A:** TXT records
**Difficulty:** Medium
**Tags:** dns, txt, spf, dkim, domain-3, prof-messer

---

**Q:** What is an NS record?
**A:** Name Server record — specifies where the name servers for the domain are located
**Difficulty:** Easy
**Tags:** dns, ns, domain-3, prof-messer

---

**Q:** Why are NS records critical?
**A:** Without NS records, the domain cannot be found — they are essential for name resolution
**Difficulty:** Medium
**Tags:** dns, ns, domain-3, prof-messer

---

**Q:** Why might a domain have multiple NS records?
**A:** To provide redundancy (e.g., ns1.example.com and ns2.example.com)
**Difficulty:** Medium
**Tags:** dns, ns, domain-3, prof-messer

---

**Q:** What is a PTR record?
**A:** Pointer record — used for reverse DNS lookups, resolving an IP address to a name
**Difficulty:** Easy
**Tags:** dns, ptr, domain-3, prof-messer

---

**Q:** How are PTR records related to A records?
**A:** They are separate and independent — PTR records must be configured independently from forward A/AAAA records
**Difficulty:** Medium
**Tags:** dns, ptr, a-record, domain-3, prof-messer

---

**Q:** How are IP addresses stored in PTR records within the DNS configuration?
**A:** In reverse order
**Difficulty:** Hard
**Tags:** dns, ptr, domain-3, prof-messer

---

**Q:** Which DNS record type would you look at to find the mail server for a domain?
**A:** MX (Mail Exchanger) record
**Difficulty:** Easy
**Tags:** dns, mx, domain-3, prof-messer

---

**Q:** Which DNS record type would you use to create an alias for a hostname?

---

**Q:** Which DNS record type is used for reverse lookups?

**Q:** Which DNS record type identifies the name servers for a domain?

**Difficulty:** Easy
**Tags:** dns, ns, domain-3, prof-messer

---

**Difficulty:** Medium
**Tags:** dns, txt, spf, dkim, domain-3, prof-messer

---

**Q:** Which DNS record type provides zone overview information including serial number and expiration?
