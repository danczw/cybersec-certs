# Network Address Translation Flashcards

**Q:** What is the fundamental problem NAT solves?
**A:** IPv4 supports only 4.29 billion addresses (completely exhausted), but 20–30 billion devices are connected to the internet
**Difficulty:** Easy
**Tags:** nat, ipv4, domain-2, prof-messer

---

**Q:** What does NAT stand for?
**A:** Network Address Translation
**Difficulty:** Easy
**Tags:** nat, domain-2, prof-messer

---

**Q:** What does NAT do for IPv4?
**A:** Extends the functionality of IPv4 by translating private addresses to public addresses
**Difficulty:** Easy
**Tags:** nat, ipv4, domain-2, prof-messer

---

**Q:** What RFC defines private IP address ranges?
**A:** RFC 1918
**Difficulty:** Medium
**Tags:** nat, rfc, domain-2, prof-messer

---

**Q:** What are the three RFC 1918 private IP ranges?
**A:** 10.0.0.0 – 10.255.255.255, 172.16.0.0 – 172.31.255.255, 192.168.0.0 – 192.168.255.255
**Difficulty:** Medium
**Tags:** nat, rfc-1918, domain-2, prof-messer

---

**Q:** Which private IP range is typically used in large enterprises?
**A:** 10.0.0.0 – 10.255.255.255
**Difficulty:** Easy
**Tags:** nat, rfc-1918, domain-2, prof-messer

---

**Q:** Which private IP range is typically used in home networks?
**A:** 192.168.0.0 – 192.168.255.255
**Difficulty:** Easy
**Tags:** nat, rfc-1918, domain-2, prof-messer

---

**Q:** Which private IP range covers 172.16.0.0 – 172.31.255.255?
**A:** The mid-size network range from RFC 1918
**Difficulty:** Easy
**Tags:** nat, rfc-1918, domain-2, prof-messer

---

**Q:** Are RFC 1918 private addresses routable on the public internet?
**A:** No — they are not routable on the public internet; used internally in homes and businesses
**Difficulty:** Easy
**Tags:** nat, rfc-1918, domain-2, prof-messer

---

**Q:** How does standard NAT work (7 steps)?
**A:** 1) Internal device sends packet with private source IP 2) NAT router receives packet, recognizes private source 3) Router translates source to available public IP from its pool 4) Packet goes to destination with public source IP 5) Return traffic comes back to public IP 6) NAT router translates destination back to original private IP 7) Internal device receives response
**Difficulty:** Hard
**Tags:** nat, domain-2, prof-messer

---

**Q:** What is the limitation of standard NAT?
**A:** Each internal device requires its own public IP address
**Difficulty:** Medium
**Tags:** nat, domain-2, prof-messer

---

**Q:** What does standard NAT translate?
**A:** One IP address to a different IP address (private → public)
**Difficulty:** Easy
**Tags:** nat, domain-2, prof-messer

---

**Q:** What is NAT overload also called?
**A:** Port Address Translation (PAT)
**Difficulty:** Easy
**Tags:** nat, pat, domain-2, prof-messer

---

**Q:** What does PAT stand for?
**A:** Port Address Translation
**Difficulty:** Easy
**Tags:** nat, pat, domain-2, prof-messer

---

**Q:** What does NAT overload / PAT translate?
**A:** Both the IP address AND the port number
**Difficulty:** Medium
**Tags:** nat, pat, domain-2, prof-messer

---

**Q:** What advantage does PAT have over standard NAT?
**A:** Allows many devices to share one public IP address — differentiated by port number
**Difficulty:** Medium
**Tags:** nat, pat, domain-2, prof-messer

---

**Q:** How does PAT differentiate between multiple internal devices using the same public IP?
**A:** Each session gets a different port number on the public side
**Difficulty:** Medium
**Tags:** nat, pat, domain-2, prof-messer

---

**Q:** In PAT, what does the NAT table store?
**A:** Mapping of private IP:port to public IP:port for each session
**Difficulty:** Medium
**Tags:** nat, pat, domain-2, prof-messer

---

**Q:** In a PAT example, 10.10.20.50:3233 is translated to 94.1.1.1:1055 and 10.10.20.70:5782 is translated to what?
**A:** 94.1.1.1:1056 — same public IP, port number incremented
**Difficulty:** Hard
**Tags:** nat, pat, domain-2, prof-messer

---

**Q:** How do port numbers behave in PAT for new sessions?
**A:** Port numbers increment for each new session — same public IP, different port
**Difficulty:** Medium
**Tags:** nat, pat, domain-2, prof-messer

---

**Q:** In standard NAT, what does the router change in an outgoing packet?
**A:** The source IP address (from private to public)
**Difficulty:** Medium
**Tags:** nat, domain-2, prof-messer

---

**Q:** In standard NAT, what does the router change in a return packet?
**A:** The destination IP address (from public back to private)
**Difficulty:** Medium
**Tags:** nat, domain-2, prof-messer
