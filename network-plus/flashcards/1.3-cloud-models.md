# Cloud Models Flashcards

**Q:** What are the three cloud deployment types?
**A:** Public cloud (anyone on internet), private cloud (internal only, local data center), hybrid cloud (combination of both)
**Difficulty:** Easy
**Tags:** cloud-models, deployment, domain-1, prof-messer

---

**Q:** When would you use a public cloud?
**A:** When creating an application that anyone on the internet needs to access
**Difficulty:** Easy
**Tags:** cloud-models, public-cloud, domain-1, prof-messer

---

**Q:** When would you use a private cloud?
**A:** For internal-use-only applications deployed in your own virtualized local data center
**Difficulty:** Easy
**Tags:** cloud-models, private-cloud, domain-1, prof-messer

---

**Q:** What is a hybrid cloud?
**A:** A configuration combining both public and private clouds for different applications within the same organization
**Difficulty:** Easy
**Tags:** cloud-models, hybrid-cloud, domain-1, prof-messer

**Q:** What does SaaS stand for?
**A:** Software as a Service

---

**Q:** What is SaaS?
**A:** On-demand software accessed via browser — someone else writes, manages, and upgrades the application; your data is stored on their platform
**Difficulty:** Easy
**Tags:** saas, cloud-models, domain-1, prof-messer

---

**Q:** Give two examples of SaaS.
**A:** Google Mail, Office 365
**Difficulty:** Easy
**Tags:** saas, cloud-models, domain-1, prof-messer

---

**Q:** In SaaS, who is responsible for software upgrades?
**A:** The cloud provider — the customer just logs in and uses the app
**Difficulty:** Easy
**Tags:** saas, cloud-models, domain-1, prof-messer

**Q:** What does IaaS stand for?
**A:** Infrastructure as a Service
**Difficulty:** Easy
**Tags:** iaas, cloud-models, domain-1, prof-messer

---

**Q:** What is IaaS?
**A:** Cloud provides computing resources (hardware); you install, manage, and upgrade your own software and data on top
**Difficulty:** Medium
**Tags:** iaas, cloud-models, domain-1, prof-messer

---

**Q:** What is another name for IaaS?
**A:** Hardware as a Service (HaaS)
**Difficulty:** Medium
**Tags:** iaas, haas, cloud-models, domain-1, prof-messer

---

**Q:** In IaaS, who handles software upgrades?
**A:** The customer — you manage all software and data on the provided infrastructure
**Difficulty:** Easy
**Tags:** iaas, cloud-models, domain-1, prof-messer

---

**Q:** Give an example of IaaS.
**A:** Web hosting providers where you buy time on a server and they make it available on the internet

**Q:** What does PaaS stand for?

**Q:** What is PaaS?

**Q:** Where does PaaS sit relative to SaaS and IaaS?
**A:** Middle ground — more control than SaaS (you build the app) but less infrastructure responsibility than IaaS (provider manages the platform)
**Difficulty:** Medium
**Tags:** paas, saas, iaas, cloud-models, domain-1, prof-messer

---

**Q:** Give an example of PaaS.
**A:** Salesforce.com — provides tools to create customized applications on their platform
**Difficulty:** Easy

**Q:** In PaaS, what is the provider responsible for?
