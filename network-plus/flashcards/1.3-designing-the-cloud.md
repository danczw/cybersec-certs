# Designing the Cloud Flashcards

**Q:** What is elasticity in cloud computing?
**A:** The ability to scale resources up during high demand and scale down when demand drops
**Difficulty:** Easy
**Tags:** cloud, elasticity, domain-1, prof-messer

---

**Q:** What is multitenancy?
**A:** Many different customers sharing the same cloud infrastructure — provides efficiency in technology use and cost
**Difficulty:** Easy
**Tags:** cloud, multitenancy, domain-1, prof-messer

---

**Q:** What is Network Function Virtualization (NFV)?
**A:** Replacing physical routers, switches, firewalls, and other networking devices with virtual versions running in a virtualized environment
**Difficulty:** Medium
**Tags:** nfv, cloud, virtualization, domain-1, prof-messer

---

**Q:** What does NFV stand for?
**A:** Network Function Virtualization
**Difficulty:** Easy
**Tags:** nfv, cloud, domain-1, prof-messer

---

**Q:** What is a hypervisor?
**A:** Software that creates and runs VMs on physical hardware, allocating CPU, memory, storage, and networking to each VM
**Difficulty:** Easy
**Tags:** hypervisor, virtualization, cloud, domain-1, prof-messer

---

**Q:** You migrate 100 physical servers to one large cloud server. What happens to the networking infrastructure?
**A:** It virtualizes too — routers, switches, and firewalls become virtual appliances managed from the hypervisor (NFV)
**Difficulty:** Medium
**Tags:** nfv, cloud, virtualization, domain-1, prof-messer

---

**Q:** What is a VPC?
**A:** Virtual Private Cloud — an isolated virtual network containing application instances (web servers, databases, load balancers, virtual networking devices)
**Difficulty:** Easy
**Tags:** vpc, cloud, domain-1, prof-messer

---

**Q:** Why would a large organization use multiple VPCs?
**A:** To keep different application instances or departments separated while managing each as individual virtual appliances
**Difficulty:** Medium
**Tags:** vpc, cloud, domain-1, prof-messer

---

**Q:** What is a transit gateway?
**A:** A cloud router that connects multiple VPCs together and allows communication between them
**Difficulty:** Medium
**Tags:** transit-gateway, vpc, cloud, domain-1, prof-messer

---

**Q:** How do remote users access private VPCs?
**A:** Via a VPN connection — they bring up a VPN tunnel to the transit gateway, gaining access to the VPCs
**Difficulty:** Medium
**Tags:** vpn, vpc, transit-gateway, cloud, domain-1, prof-messer

---

**Q:** What is a VPC internet gateway?
**A:** A gateway that makes application instances available to anyone on the internet
**Difficulty:** Easy
**Tags:** internet-gateway, vpc, cloud, domain-1, prof-messer

---

**Q:** What does NAT stand for?
**A:** Network Address Translation
**Difficulty:** Easy
**Tags:** nat, cloud, domain-1, prof-messer

---

**Q:** What is a VPC NAT gateway?
**A:** A gateway that translates private IP addresses to public IPs, allowing VPC devices to communicate outbound over the internet
**Difficulty:** Medium
**Tags:** nat-gateway, vpc, cloud, domain-1, prof-messer

---

**Q:** A VPC NAT gateway allows outbound internet access. Does it also allow inbound access?
**A:** Not necessarily — security rules can allow outbound to internet resources while blocking inbound from external devices
**Difficulty:** Medium
**Tags:** nat-gateway, vpc, security, cloud, domain-1, prof-messer

---

**Q:** What is a VPC endpoint?
**A:** A direct connection from a VPC on one cloud provider to a VPC on another cloud provider, bypassing the public internet
**Difficulty:** Medium
**Tags:** vpc-endpoint, cloud, domain-1, prof-messer

---

**Q:** When would you use a VPC endpoint instead of an internet gateway?
**A:** When you need to connect to a private subnet that isn't accessible from the internet, especially across different cloud providers
**Difficulty:** Hard
**Tags:** vpc-endpoint, internet-gateway, cloud, domain-1, prof-messer

---

**Q:** What are network security lists?
**A:** Firewall rules applied at the VPC level that control inbound and outbound traffic based on port numbers, protocols, and IP addresses
**Difficulty:** Medium
**Tags:** security-list, firewall, cloud, domain-1, prof-messer

---

**Q:** What is the main limitation of network security lists?
**A:** No granularity — once defined, rules automatically apply to all virtual cloud networks, even where not needed
**Difficulty:** Medium
**Tags:** security-list, cloud, domain-1, prof-messer

---

**Q:** What are network security groups?
**A:** Firewall rules assigned to individual Virtual Network Interface Cards (VNICs), providing per-interface granularity
**Difficulty:** Medium
**Tags:** security-group, firewall, cloud, domain-1, prof-messer

---

**Q:** What does VNIC stand for?
**A:** Virtual Network Interface Card
**Difficulty:** Easy
**Tags:** vnic, cloud, domain-1, prof-messer

---

**Q:** How do network security groups differ from network security lists?
**A:** Security groups assign rules to individual VNICs (per-interface), while security lists apply broadly to all virtual cloud networks (per-subnet)
**Difficulty:** Hard
**Tags:** security-group, security-list, cloud, domain-1, prof-messer

---

**Q:** What is the trade-off of using network security groups over security lists?
**A:** More granularity but more administration overhead to manage different rules for individual interfaces
**Difficulty:** Medium
**Tags:** security-group, security-list, cloud, domain-1, prof-messer

---

**Q:** What should you consider if you need security beyond network security groups?
**A:** A virtual firewall or other virtualized security platform
**Difficulty:** Medium
**Tags:** security-group, firewall, cloud, domain-1, prof-messer

---

**Q:** What addressing formats can you use in security lists/groups?
**A:** Individual IP addresses, CIDR block notation, or IPv4/IPv6 ranges
**Difficulty:** Medium
**Tags:** security-list, security-group, cloud, domain-1, prof-messer

---

**Q:** A company uses AWS and Azure but needs private connectivity between them. What do they use?
**A:** A VPC endpoint — creates a direct connection between VPCs on different cloud providers without traversing the public internet
**Difficulty:** Hard
**Tags:** vpc-endpoint, cloud, domain-1, prof-messer

---

**Q:** What is the role of a transit gateway when combined with a VPN?
**A:** Remote users connect via VPN tunnel to the transit gateway, which then routes their traffic to any connected VPC
**Difficulty:** Hard
**Tags:** transit-gateway, vpn, vpc, cloud, domain-1, prof-messer

---

**Q:** You want internal VPC instances to download updates from the internet but not be reachable from outside. What do you use?
**A:** A NAT gateway — allows outbound internet access while blocking unsolicited inbound connections
**Difficulty:** Medium
**Tags:** nat-gateway, vpc, cloud, domain-1, prof-messer

---

**Q:** You have a public web app and a private database in the same VPC. How do you allow internet users to reach only the web app?
**A:** Place the web app in a public subnet with an internet gateway; place the database in a private subnet with no internet route
**Difficulty:** Hard
**Tags:** vpc, internet-gateway, subnet, cloud, domain-1, prof-messer

---

**Q:** What protocols and layers do security lists/groups typically filter on?
**A:** Layer 3 (IP addresses) and Layer 4 (TCP/UDP port numbers)
**Difficulty:** Medium
**Tags:** security-list, security-group, cloud, domain-1, prof-messer

---

**Q:** What is the difference between a VPC internet gateway and a VPC NAT gateway?
**A:** Internet gateway allows inbound access from the internet to public resources. NAT gateway only allows outbound from private resources to the internet — no unsolicited inbound.
**Difficulty:** Hard
**Tags:** internet-gateway, nat-gateway, vpc, cloud, domain-1, prof-messer
