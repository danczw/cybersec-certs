# Network Architectures Flashcards

**Q:** What are the three layers of a three-tier network architecture?
**A:** Core, Distribution, Access
**Difficulty:** Easy
**Tags:** architecture, three-tier, domain-1, prof-messer

---

**Q:** What is the purpose of the core layer in a three-tier architecture?
**A:** Central point for all resources — servers, applications, databases, and critical services
**Difficulty:** Easy
**Tags:** architecture, three-tier, core, domain-1, prof-messer

---

**Q:** What is the purpose of the distribution layer?
**A:** Midpoint between users and core resources — provides redundancy and connectivity via switches
**Difficulty:** Easy
**Tags:** architecture, three-tier, distribution, domain-1, prof-messer

---

**Q:** What is the purpose of the access layer?
**A:** Where users physically connect to the network — switches located close to users (e.g., same floor)
**Difficulty:** Easy
**Tags:** architecture, three-tier, access, domain-1, prof-messer

---

**Q:** In the city analogy for three-tier architecture, what does the core represent?
**A:** Downtown — where all major resources are concentrated in a small central area
**Difficulty:** Easy
**Tags:** architecture, three-tier, core, domain-1, prof-messer

---

**Q:** In the city analogy, what does the distribution layer represent?
**A:** Highways — connecting homes (access) to downtown (core)
**Difficulty:** Easy
**Tags:** architecture, three-tier, distribution, domain-1, prof-messer

---

**Q:** In the city analogy, what does the access layer represent?
**A:** Local access roads — used for daily activities but connecting to highways when needed
**Difficulty:** Easy
**Tags:** architecture, three-tier, access, domain-1, prof-messer

---

**Q:** What type of device is typically found at the core layer?
**A:** Core routers
**Difficulty:** Medium
**Tags:** architecture, three-tier, core, domain-1, prof-messer

---

**Q:** What type of device is typically found at the distribution layer?
**A:** Switches that connect core routers to access switches
**Difficulty:** Medium
**Tags:** architecture, three-tier, distribution, domain-1, prof-messer

---

**Q:** What type of device is typically found at the access layer?
**A:** Switches located on the same floor as users
**Difficulty:** Medium
**Tags:** architecture, three-tier, access, domain-1, prof-messer

---

**Q:** How does a three-tier architecture provide redundancy?
**A:** Multiple links between access and distribution, and often multiple links between distribution and core — if one component fails, alternate paths exist
**Difficulty:** Medium
**Tags:** architecture, three-tier, redundancy, domain-1, prof-messer

---

**Q:** In a multi-building campus using three-tier architecture, where is the core typically located?
**A:** In a central data center
**Difficulty:** Medium
**Tags:** architecture, three-tier, core, domain-1, prof-messer

---

**Q:** In a multi-building campus, how are buildings connected to the core?
**A:** Each building has access switches per floor, connected to distribution switches, which connect to the core in a central data center
**Difficulty:** Medium
**Tags:** architecture, three-tier, campus, domain-1, prof-messer

---

**Q:** What is a collapsed core architecture?
**A:** A two-tier design that combines the core and distribution layers into a single layer, with the access layer remaining separate
**Difficulty:** Medium
**Tags:** architecture, collapsed-core, domain-1, prof-messer

---

**Q:** How many tiers does a collapsed core architecture have?
**A:** Two — collapsed core (combined core + distribution) and access
**Difficulty:** Easy
**Tags:** architecture, collapsed-core, domain-1, prof-messer

---

**Q:** What type of organization would use a collapsed core architecture?
**A:** Smaller organizations that don't need the complexity of a full three-tier design
**Difficulty:** Medium
**Tags:** architecture, collapsed-core, domain-1, prof-messer

---

**Q:** What are the advantages of collapsed core over three-tier?
**A:** More simplified design, easier troubleshooting, less expensive (fewer devices to purchase and install)
**Difficulty:** Medium
**Tags:** architecture, collapsed-core, domain-1, prof-messer

---

**Q:** What is the main disadvantage of a collapsed core architecture?
**A:** Less redundancy — not as resilient if a component fails
**Difficulty:** Medium
**Tags:** architecture, collapsed-core, domain-1, prof-messer

---

**Q:** What does east-west traffic mean in a data center?
**A:** Traffic where both origination and destination are within the same data center
**Difficulty:** Medium
**Tags:** architecture, traffic-flow, east-west, domain-1, prof-messer

---

**Q:** What does north-south traffic mean in a data center?
**A:** Traffic entering or leaving the data center from/to an external source (e.g., the internet)
**Difficulty:** Medium
**Tags:** architecture, traffic-flow, north-south, domain-1, prof-messer

---

**Q:** Give an example of east-west traffic.
**A:** A file server sending data to an image server within the same data center
**Difficulty:** Easy
**Tags:** architecture, traffic-flow, east-west, domain-1, prof-messer

---

**Q:** Give an example of north-south traffic.
**A:** Traffic coming into the network from the internet or being sent out to the internet
**Difficulty:** Easy
**Tags:** architecture, traffic-flow, north-south, domain-1, prof-messer

---

**Q:** Which traffic flow type typically has better response times — east-west or north-south?
**A:** East-west — all devices are on the same local network
**Difficulty:** Medium
**Tags:** architecture, traffic-flow, domain-1, prof-messer

---

**Q:** Which traffic flow type requires a different (stricter) security posture?
**A:** North-south — external origins/destinations are unknown and potentially untrusted
**Difficulty:** Medium
**Tags:** architecture, traffic-flow, security, domain-1, prof-messer

---

**Q:** Why does north-south traffic have a different security posture than east-west?
**A:** We don't know where outbound traffic is going once it leaves the data center, and inbound traffic could come from potentially anywhere
**Difficulty:** Medium
**Tags:** architecture, traffic-flow, security, domain-1, prof-messer

**Q:** If a distribution switch fails in a three-tier architecture, can users still reach the core?
