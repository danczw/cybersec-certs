# Calculating IPv4 Subnets and Hosts Flashcards

**Q:** Why do we subnet networks?
**A:** Impossible for one device to know every other device — subnetting creates smaller networks that routers can forward traffic between
**Difficulty:** Easy
**Tags:** subnetting, vlsm, domain-1, prof-messer

---

**Q:** What does VLSM stand for?
**A:** Variable-Length Subnet Mask
**Difficulty:** Easy
**Tags:** subnetting, vlsm, domain-1, prof-messer

---

**Q:** What does VLSM allow compared to classful subnetting?
**A:** Subnet masks of any bit length — not limited to /8, /16, /24 — so the network admin can create subnets of any size
**Difficulty:** Easy
**Tags:** subnetting, vlsm, domain-1, prof-messer

---

**Q:** What are the three sections of an IP address when using VLSM?
**A:** Network bits (default class) | Subnet bits (borrowed) | Host bits (remaining)
**Difficulty:** Medium
**Tags:** subnetting, vlsm, domain-1, prof-messer

---

**Q:** What are "subnet bits"?
**A:** Bits borrowed from the host portion beyond the default class boundary to create additional subnets
**Difficulty:** Medium
**Tags:** subnetting, vlsm, domain-1, prof-messer

---

**Q:** What is the formula for number of subnets?
**A:** 2^(subnet bits)
**Difficulty:** Medium
**Tags:** subnetting, formula, domain-1, prof-messer

---

**Q:** What is the formula for hosts per subnet?
**A:** 2^(host bits) − 2
**Difficulty:** Medium
**Tags:** subnetting, formula, domain-1, prof-messer

---

**Q:** Why do you subtract 2 from the hosts-per-subnet calculation?
**A:** One address reserved for the network address, one for the broadcast address
**Difficulty:** Easy
**Tags:** subnetting, formula, domain-1, prof-messer

---

**Q:** How do you determine the number of subnet bits borrowed?
**A:** CIDR mask length minus the default class mask (e.g., /24 on a Class A: 24 − 8 = 16 subnet bits)
**Difficulty:** Medium
**Tags:** subnetting, formula, domain-1, prof-messer

---

**Q:** How do you determine the number of host bits?
**A:** 32 minus the CIDR mask length (e.g., /24: 32 − 24 = 8 host bits)
**Difficulty:** Easy
**Tags:** subnetting, formula, domain-1, prof-messer

---

**Q:** 10.1.1.0/24 — how many subnet bits were borrowed?
**A:** 16 (Class A default is /8, so 24 − 8 = 16)
**Difficulty:** Medium
**Tags:** subnetting, calculation, class-a, domain-1, prof-messer

**Q:** 10.1.1.0/24 — how many subnets?

**Q:** You have a /28 on a Class C network. How many subnets and hosts per subnet?
**A:** Subnet bits: 28 − 24 = 4 → 2^4 = 16 subnets | Host bits: 32 − 28 = 4 → 2^4 − 2 = 14 hosts
**Difficulty:** Hard
**Tags:** subnetting, calculation, class-c, domain-1, prof-messer

---

**Q:** You have a /20 on a Class B network. How many subnets and hosts per subnet?
**A:** Subnet bits: 20 − 16 = 4 → 2^4 = 16 subnets | Host bits: 32 − 20 = 12 → 2^12 − 2 = 4,094 hosts
**Difficulty:** Hard
**Tags:** subnetting, calculation, class-b, domain-1, prof-messer

---

**Q:** You have a /12 on a Class A network. How many subnets and hosts per subnet?
**A:** Subnet bits: 12 − 8 = 4 → 2^4 = 16 subnets | Host bits: 32 − 12 = 20 → 2^20 − 2 = 1,048,574 hosts
**Difficulty:** Hard
**Tags:** subnetting, calculation, class-a, domain-1, prof-messer

---

**Q:** You need 50 hosts per subnet on a Class C network. What is the minimum CIDR mask?
**A:** /26 — gives 6 host bits (2^6 − 2 = 62 usable hosts), next smaller (/27) only gives 30
**Difficulty:** Hard
**Tags:** subnetting, calculation, domain-1, prof-messer

---

**Q:** You need at least 500 hosts per subnet on a Class B network. What is the minimum number of host bits?
**A:** 10 bits (2^10 − 2 = 1,022) — 9 bits only gives 510, but you'd use /22 mask (32 − 10 = 22)
**Difficulty:** Hard
**Tags:** subnetting, calculation, domain-1, prof-messer

---

**Q:** What happens if you increase subnet bits?
**A:** More subnets but fewer hosts per subnet — borrowing from host bits shrinks each subnet
**Difficulty:** Medium
**Tags:** subnetting, vlsm, domain-1, prof-messer

---

**Q:** What happens if you decrease subnet bits?
**A:** Fewer subnets but more hosts per subnet — more bits available for host addresses
**Difficulty:** Medium
**Tags:** subnetting, vlsm, domain-1, prof-messer
