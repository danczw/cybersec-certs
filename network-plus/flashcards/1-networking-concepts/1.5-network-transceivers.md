# Network Transceivers Flashcards

**Q:** What does "transceiver" stand for?
**A:** Transmitter + receiver combined in one component
**Difficulty:** Easy
**Tags:** transceiver, domain-1, prof-messer

---

**Q:** What is a transceiver in networking?
**A:** A small module that plugs into a switch/router port, providing modularity — the cable then plugs into the transceiver
**Difficulty:** Easy
**Tags:** transceiver, domain-1, prof-messer

---

**Q:** What does a transceiver provide?
**A:** Modularity — you can slide in the appropriate transceiver for any media or network type
**Difficulty:** Easy
**Tags:** transceiver, domain-1, prof-messer

---

**Q:** Can each interface on a switch use a different media type?
**A:** Yes — each interface can have a different transceiver and therefore a different media type
**Difficulty:** Easy
**Tags:** transceiver, domain-1, prof-messer

---

**Q:** Can you use a Fibre Channel transceiver in an Ethernet switch?
**A:** No — the transceiver must match the network type (Ethernet for Ethernet, Fibre Channel for Fibre Channel)
**Difficulty:** Medium
**Tags:** transceiver, domain-1, prof-messer

---

**Q:** What is the trade-off of transceiver modularity?
**A:** Additional cost
**Difficulty:** Easy
**Tags:** transceiver, domain-1, prof-messer
