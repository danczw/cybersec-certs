# Ethernet Standards Flashcards

**Q:** What IEEE committee manages Ethernet standards?
**A:** IEEE 802.3
**Difficulty:** Easy
**Tags:** ethernet, ieee, domain-1, prof-messer

**Q:** What is the difference between IEEE 802.3 and IEEE 802.11?
**A:** 802.3 = Ethernet (wired), 802.11 = wireless networking

**Tags:** ethernet, ieee, domain-1, prof-messer

**Q:** What types of media do Ethernet standards support?

**Tags:** ethernet, media, domain-1, prof-messer

**Q:** Break down the name `1000BASE-T` — what does each part mean?
**A:** 1000 = speed in Mbps (1 Gbps), BASE = baseband signaling, T = twisted-pair copper
**Difficulty:** Medium
**Tags:** ethernet, naming, domain-1, prof-messer

**Q:** What does "BASE" mean in Ethernet standard names?
