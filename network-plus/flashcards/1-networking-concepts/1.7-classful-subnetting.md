**Q:** What are the four important subnet values you need to calculate?
**A:** Network address, first usable host, broadcast address, last usable host
**Difficulty:** Medium
**Tags:** subnetting, calculation, domain-1, prof-messer

---

**Q:** How do you calculate the network address?
**A:** Set all host bits to 0
**Difficulty:** Medium
**Tags:** subnetting, calculation, domain-1, prof-messer

---

**Q:** How do you calculate the first usable host address?
**A:** Network address + 1
**Difficulty:** Easy
**Tags:** subnetting, calculation, domain-1, prof-messer

---

**Q:** How do you calculate the broadcast address?
**A:** Set all host bits to 1
**Difficulty:** Medium
**Tags:** subnetting, calculation, domain-1, prof-messer

---

**Q:** How do you calculate the last usable host address?
**A:** Broadcast address − 1
**Difficulty:** Easy
**Tags:** subnetting, calculation, domain-1, prof-messer
