# Magic Number Subnetting Flashcards

**Q:** What four values does the magic number method calculate?
**A:** 1) Network address (subnet ID) 2) Broadcast address 3) First usable host 4) Last usable host
**Difficulty:** Easy
**Tags:** subnetting, magic-number, domain-1, prof-messer

---

**Q:** What is the "interesting octet"?
**A:** The subnet mask octet that is neither 255 nor 0
**Difficulty:** Easy
**Tags:** subnetting, magic-number, domain-1, prof-messer

---

**Q:** How do you calculate the magic number?
**A:** 256 minus the interesting octet's subnet mask value
**Difficulty:** Easy
**Tags:** subnetting, magic-number, domain-1, prof-messer

---

**Q:** What are the 7 steps of the magic number method?
**A:** 1) Convert mask to decimal 2) Identify interesting octet 3) Calculate magic number (256 − mask) 4) Determine host ranges (multiples of magic number) 5) Find which range the IP falls into 6) Network address = first value in range 7) Broadcast = subnet ID + magic number − 1
**Difficulty:** Hard
**Tags:** subnetting, magic-number, domain-1, prof-messer

---

**Q:** What is the network address (subnet ID)?
**A:** The first address in the subnet
**Difficulty:** Easy
**Tags:** subnetting, magic-number, domain-1, prof-messer

---

**Q:** What is the broadcast address?
**A:** The last address in the subnet
**Difficulty:** Easy
**Tags:** subnetting, magic-number, domain-1, prof-messer

---

**Q:** How do you find the first usable host address?
**A:** Subnet ID + 1
**Difficulty:** Easy
**Tags:** subnetting, magic-number, domain-1, prof-messer

---

**Q:** How do you find the last usable host address?
**A:** Broadcast address − 1
**Difficulty:** Easy

**Q:** Calculate the subnet ID for 165.245.77.14 with mask 255.255.240.0
**A:** 165.245.64.0 — interesting octet 3, magic number = 16, ranges: 0–15, 16–31, ... 64–79; IP 77 falls in 64–79
**Difficulty:** Hard
**Tags:** subnetting, magic-number, domain-1, prof-messer

---

**Q:** Calculate the broadcast address for 165.245.77.14 with mask 255.255.240.0 (subnet ID = 165.245.64.0)
**A:** 165.245.79.255 — interesting octet: 64 + 16 − 1 = 79; mask 0 octet → 255
**Difficulty:** Hard
**Tags:** subnetting, magic-number, domain-1, prof-messer
