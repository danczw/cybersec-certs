# IPv4 Subnet Masks Flashcards

**Q:** What replaced class-based subnetting in 1993?
**A:** Classless Inter-Domain Routing (CIDR) — allows subnet masks of any length
**Difficulty:** Easy
**Tags:** subnetting, cidr, domain-1, prof-messer

---

**Q:** What does the number in CIDR block notation represent?
**A:** The number of contiguous 1-bits in the subnet mask (e.g., /24 = twenty-four 1's)
**Difficulty:** Easy
**Tags:** subnetting, cidr, domain-1, prof-messer

**Q:** What is the key difference between classful and classless subnetting?
**A:** Classless (CIDR) allows any mask length, not just /8, /16, /24
**Difficulty:** Easy
**Tags:** subnetting, cidr, domain-1, prof-messer

**Q:** How do you convert CIDR notation to binary subnet mask?
**A:** Write that many 1's from the left, fill the rest with 0's to reach 32 bits total
**Difficulty:** Medium
**Tags:** subnetting, cidr, conversion, domain-1, prof-messer

**Q:** How do you convert a decimal subnet mask to CIDR notation?
**A:** Convert each octet to binary and count the total number of 1's
**Difficulty:** Medium
**Tags:** subnetting, cidr, conversion, domain-1, prof-messer

**Q:** Is 255.255.100.0 a valid subnet mask?
**A:** No — 100 in binary is 01100100, which has 0's between 1's (masks must be contiguous 1's then 0's)
**Difficulty:** Hard
**Tags:** subnetting, structure, domain-1, prof-messer

---

**Q:** A device has IP 10.50.3.7/20. How does it determine if 10.50.15.200 is local?
**A:** AND both IPs with the mask (255.255.240.0) — both yield 10.50.0.0, so they're on the same subnet (local)
**Difficulty:** Hard
**Tags:** subnetting, purpose, domain-1, prof-messer

---

**Q:** A device has IP 10.50.3.7/20. Is 10.50.17.1 on the same subnet?
**A:** No — 10.50.3.7 AND 255.255.240.0 = 10.50.0.0, but 10.50.17.1 AND 255.255.240.0 = 10.50.16.0 — different subnets, send to gateway
**Difficulty:** Hard
**Tags:** subnetting, purpose, domain-1, prof-messer
