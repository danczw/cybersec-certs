# Other Useful Protocols Flashcards

**Q:** What is ICMP used for?
**A:** Checking if devices are alive/reachable on the network and providing network feedback (unreachable destinations, TTL expired)
**Difficulty:** Easy
**Tags:** icmp, protocols, domain-1, prof-messer

---

**Q:** Does ICMP use TCP or UDP?
**A:** Neither — ICMP is carried by IP but is its own separate protocol
**Difficulty:** Medium
**Tags:** icmp, protocols, domain-1, prof-messer

---

**Q:** What command uses ICMP?
**A:** `ping` — sends an ICMP echo request and waits for an echo reply
**Difficulty:** Easy
**Tags:** icmp, ping, domain-1, prof-messer

---

**Q:** What are two common ICMP feedback messages?
**A:** Destination network unreachable; Time exceeded (TTL expired)
**Difficulty:** Medium
**Tags:** icmp, protocols, domain-1, prof-messer

---

**Q:** What is GRE (Generic Routing Encapsulation)?
**A:** A tunneling protocol that encapsulates data within IP packets to create point-to-point tunnels between two endpoints
**Difficulty:** Medium
**Tags:** gre, tunneling, vpn, domain-1, prof-messer

---

**Q:** Does GRE provide encryption?
**A:** No — GRE only provides encapsulation/tunneling. You need additional protocols (like IPSec) for encryption.
**Difficulty:** Medium
**Tags:** gre, tunneling, encryption, domain-1, prof-messer

---

**Q:** What is a VPN concentrator?
**A:** A purpose-built appliance that provides encryption/decryption at a central point for VPN connections
**Difficulty:** Easy
**Tags:** vpn, concentrator, domain-1, prof-messer

---

**Q:** Where is a VPN concentrator typically deployed?
**A:** As a standalone unit or integrated into an existing firewall; usually hardware-based with specialized encryption chips for throughput
**Difficulty:** Medium
**Tags:** vpn, concentrator, domain-1, prof-messer

---

**Q:** What is a site-to-site VPN?
**A:** A VPN that connects a corporate network to a remote site over the public internet using VPN concentrators (firewalls/routers) at each end
**Difficulty:** Easy
**Tags:** vpn, site-to-site, domain-1, prof-messer

---

**Q:** What three things does IPSec provide?
**A:** Encryption (confidentiality), digital signatures per packet (integrity), and anti-replay functionality
**Difficulty:** Medium
**Tags:** ipsec, vpn, encryption, domain-1, prof-messer

---

**Q:** What is the difference between IPSec AH and ESP?
**A:** AH (Authentication Header) provides integrity/authentication only — no encryption. ESP (Encapsulation Security Payload) provides both encryption AND authentication.
**Difficulty:** Hard
**Tags:** ipsec, ah, esp, domain-1, prof-messer

---

**Q:** What does AH stand for in IPSec and what does it do?
**A:** Authentication Header — provides integrity and authentication only (data is sent in the clear with a hash for verification)
**Difficulty:** Medium
**Tags:** ipsec, ah, domain-1, prof-messer

---

**Q:** What does ESP stand for in IPSec and what does it do?
**A:** Encapsulation Security Payload — encrypts data AND provides authentication
**Difficulty:** Medium
**Tags:** ipsec, esp, domain-1, prof-messer

---

**Q:** What fields does an AH header contain?
**A:** Next header, payload length, SPI (Security Parameters Index), sequence number, and ICV (Integrity Check Value) hash
**Difficulty:** Hard
**Tags:** ipsec, ah, domain-1, prof-messer

---

**Q:** What is IKE (Internet Key Exchange)?
**A:** A series of steps performed before sending data to establish an IPSec tunnel — both sides agree on encryption/decryption keys
**Difficulty:** Medium
**Tags:** ipsec, ike, domain-1, prof-messer

---

**Q:** What is a Security Association (SA)?
**A:** The agreement between two IPSec endpoints on encryption/decryption parameters, established during IKE negotiation
**Difficulty:** Medium
**Tags:** ipsec, ike, sa, domain-1, prof-messer

---

**Q:** What happens during IKE Phase 1?
**A:** Uses Diffie-Hellman to create a shared secret key; operates over UDP port 500; called ISAKMP
**Difficulty:** Hard
**Tags:** ipsec, ike, phase-1, domain-1, prof-messer

---

**Q:** What port does IKE Phase 1 (ISAKMP) use?
**A:** UDP port 500
**Difficulty:** Medium
**Tags:** ipsec, ike, ports, domain-1, prof-messer

---

**Q:** What does ISAKMP stand for?
**A:** Internet Security Association and Key Management Protocol — the Phase 1 process of IKE
**Difficulty:** Hard
**Tags:** ipsec, ike, isakmp, domain-1, prof-messer

---

**Q:** What happens during IKE Phase 2?
**A:** Negotiates ciphers and key sizes, negotiates inbound and outbound Security Associations, then encrypted data is sent over the ESP tunnel
**Difficulty:** Hard
**Tags:** ipsec, ike, phase-2, domain-1, prof-messer

---

**Q:** What is IPSec Transport Mode?
**A:** Inserts an IPSec header between the original IP header and data; encrypts only the data portion. Original IP header remains in the clear.
**Difficulty:** Hard
**Tags:** ipsec, transport-mode, domain-1, prof-messer

---

**Q:** What is IPSec Tunnel Mode?
**A:** Encrypts the original IP header AND data, then adds a new IP header with the VPN concentrator as destination. Attacker cannot see the original destination.
**Difficulty:** Hard
**Tags:** ipsec, tunnel-mode, domain-1, prof-messer

---

**Q:** What is the key difference between IPSec transport mode and tunnel mode?
**A:** Transport mode encrypts only the data (original IP header visible). Tunnel mode encrypts both the original IP header and data, hiding the true destination.
**Difficulty:** Hard
**Tags:** ipsec, transport-mode, tunnel-mode, domain-1, prof-messer

---

**Q:** Which IPSec mode is most commonly used and why?
**A:** Tunnel mode — it provides the highest security because the original destination IP is encrypted and hidden from attackers
**Difficulty:** Medium
**Tags:** ipsec, tunnel-mode, domain-1, prof-messer

---

**Q:** In IPSec tunnel mode, what does the new outer IP header contain as destination?
**A:** The VPN concentrator's address (not the final destination), so attackers only see traffic going to the VPN endpoint
**Difficulty:** Hard
**Tags:** ipsec, tunnel-mode, domain-1, prof-messer

---

**Q:** What key exchange algorithm does IKE Phase 1 use?
**A:** Diffie-Hellman
**Difficulty:** Medium
**Tags:** ipsec, ike, diffie-hellman, domain-1, prof-messer
