# Interface Issues Flashcards

**Q:** Why do network administrators monitor interfaces on important devices?
**A:** To detect developing problems (bad cable, bad interface) and resolve them before they become outages; also to identify congestion or overutilization that may require network design changes
**Difficulty:** Easy
**Tags:** interface-monitoring, domain-5, prof-messer

---

**Q:** What protocol do administrators use to automate interface monitoring?
**A:** SNMP (Simple Network Management Protocol)
**Difficulty:** Easy
**Tags:** interface-monitoring, snmp, domain-5, prof-messer

---

**Q:** What is MIB-II?
**A:** Management Information Base — a standard set of SNMP statistics common across many different devices
**Difficulty:** Medium
**Tags:** interface-monitoring, snmp, mib, domain-5, prof-messer

---

**Q:** What is the purpose of proprietary MIBs?
**A:** To provide device-specific statistics (firewalls, switches) beyond the standard MIB-II set
**Difficulty:** Medium
**Tags:** interface-monitoring, snmp, mib, domain-5, prof-messer

---

**Q:** What are the three key interface metrics to monitor?
**A:** Link status (up/down), utilization (throughput), and errors (CRC, runts, giants, drops)
**Difficulty:** Easy
**Tags:** interface-monitoring, domain-5, prof-messer

---

**Q:** What might a link status of "down" indicate?
**A:** Cable problem, interface issue, or device reboot
**Difficulty:** Easy
**Tags:** interface-monitoring, link-status, domain-5, prof-messer

---

**Q:** What is the purpose of the Preamble and SFD in an ethernet frame?
**A:** They identify the beginning of an ethernet frame; everything after the SFD (Start Frame Delimiter) is the normal frame. They are not visible in packet captures.
**Difficulty:** Medium
**Tags:** ethernet-frame, domain-5, prof-messer

---

**Q:** What are the six fields of an ethernet frame (in order)?
**A:** Preamble + SFD, Destination MAC, Source MAC, EtherType, Payload, Frame Check Sequence
**Difficulty:** Hard
**Tags:** ethernet-frame, domain-5, prof-messer

---

**Q:** What is the purpose of the EtherType field?
**A:** Describes what type of data is in the payload
**Difficulty:** Medium
**Tags:** ethernet-frame, domain-5, prof-messer

---

**Q:** What is the Frame Check Sequence (FCS)?
**A:** A CRC checksum at the end of an ethernet frame used to verify data integrity
**Difficulty:** Medium
**Tags:** ethernet-frame, crc, domain-5, prof-messer

---

**Q:** How does CRC error detection work?
**A:** The Frame Check Sequence contains a checksum calculated at transmission. The receiving adapter recalculates the CRC and compares it to the FCS value. If they match, the frame received without corruption. If mismatch, the CRC error counter is incremented.
**Difficulty:** Medium
**Tags:** crc, errors, domain-5, prof-messer

---

**Q:** What do CRC errors typically indicate?
**A:** Signal problems on the connection — possible cable or interface issue. CRC errors are often the first warning of developing problems.
**Difficulty:** Easy
**Tags:** crc, errors, domain-5, prof-messer

---

**Q:** What is a runt?
**A:** A frame received that is less than 64 bytes (the minimum ethernet frame size)
**Difficulty:** Easy
**Tags:** runts, errors, domain-5, prof-messer

---

**Q:** What is the minimum size of a valid ethernet frame?
**A:** 64 bytes
**Difficulty:** Easy
**Tags:** runts, ethernet-frame, domain-5, prof-messer

---

**Q:** Why are runts rare on modern networks?
**A:** Most switch networks are full duplex. Runts were common on half-duplex networks during collisions.
**Difficulty:** Medium
**Tags:** runts, errors, domain-5, prof-messer

---

**Q:** What is a giant?
**A:** A frame received that is larger than 1,518 bytes (the default maximum ethernet frame size), or larger than the configured maximum size for jumbo frames
**Difficulty:** Easy
**Tags:** giants, errors, domain-5, prof-messer

---

**Q:** What is the default maximum ethernet frame size?
**A:** 1,518 bytes
**Difficulty:** Easy
**Tags:** giants, ethernet-frame, domain-5, prof-messer

---

**Q:** How do jumbo frames relate to giants?
**A:** Jumbo frames can exceed 1,518 bytes but have their own configured maximum. If a frame exceeds that configured maximum, it is still classified as a giant.
**Difficulty:** Medium
**Tags:** giants, errors, domain-5, prof-messer

---

**Q:** What causes drops on a network interface?
**A:** Contention or buffering problems — no room in the buffer to hold the frame
**Difficulty:** Easy
**Tags:** drops, errors, domain-5, prof-messer

---

**Q:** What does an incrementing drop counter indicate?
**A:** Communication problems on the network
**Difficulty:** Easy
**Tags:** drops, errors, domain-5, prof-messer

---

**Q:** What Cisco command displays interface error counters (runts, giants, CRCs)?
**A:** `show interface`
**Difficulty:** Medium
**Tags:** cisco, errors, domain-5, prof-messer

---

**Q:** What does a slowly incrementing CRC error counter suggest?
**A:** A developing cable or interface problem
**Difficulty:** Medium
**Tags:** crc, errors, domain-5, prof-messer

---

**Q:** What is the error disabled state?
**A:** A state where the device has automatically disabled an interface without human intervention due to detected problems
**Difficulty:** Easy
**Tags:** error-disabled, port-status, domain-5, prof-messer

---

**Q:** What are four common triggers for error disabled state?
**A:** Interface flapping (link going up/down repeatedly, causing spanning tree issues), port security violation (unauthorized device), configuration problems, and increasing error counts
**Difficulty:** Hard
**Tags:** error-disabled, port-status, domain-5, prof-messer

---

**Q:** What is interface flapping?
**A:** The link going up/down repeatedly, causing spanning tree issues
**Difficulty:** Medium
**Tags:** error-disabled, flapping, domain-5, prof-messer

---

**Q:** What happens when a port security violation triggers error disabled?
**A:** An unauthorized device connected to a secured port causes the switch to put the interface into error disabled state
**Difficulty:** Medium
**Tags:** error-disabled, port-security, domain-5, prof-messer

---

**Q:** Once an interface is error disabled, will it automatically recover?
**A:** No — you must log into the switch and administratively re-enable the interface. If the same problem recurs, it may return to error disabled state.
**Difficulty:** Medium
**Tags:** error-disabled, port-status, domain-5, prof-messer

---

**Q:** What is the difference between error disabled and administratively down?
**A:** Error disabled is automatic (device disabled it due to detected problems). Administratively down is intentional — an administrator manually disabled the interface.
**Difficulty:** Medium
**Tags:** error-disabled, admin-down, port-status, domain-5, prof-messer

---

**Q:** What is a suspended port status?
**A:** An error that occurs the moment an interface is enabled because it is connected to an incompatible configuration
**Difficulty:** Medium
**Tags:** suspended, port-status, domain-5, prof-messer

---

**Q:** Give an example of what causes a suspended port status.
**A:** Configuring LACP on one switch but not the other — the interface immediately moves into a suspended state
**Difficulty:** Medium
**Tags:** suspended, lacp, port-status, domain-5, prof-messer

---

**Q:** What is the difference between error disabled and suspended port status?
**A:** Error disabled occurs after the interface has been running and problems are detected. Suspended occurs immediately when the interface is enabled due to incompatible configuration.
**Difficulty:** Hard
**Tags:** error-disabled, suspended, port-status, domain-5, prof-messer
