# Command Line Tools Flashcards

**Q:** What does the ping command tell you?
**A:** If a device on the network is reachable
**Difficulty:** Easy
**Tags:** ping, domain-5, prof-messer

---

**Q:** What protocol does ping use?
**A:** ICMP (Internet Control Message Protocol)
**Difficulty:** Easy
**Tags:** ping, icmp, domain-5, prof-messer

---

**Q:** What information does ping output show?
**A:** Bytes sent/received, sequence numbers, TTL, and round-trip time
**Difficulty:** Medium
**Tags:** ping, domain-5, prof-messer

---

**Q:** What does ping show when a device is unreachable?
**A:** Timeout messages
**Difficulty:** Easy
**Tags:** ping, domain-5, prof-messer

---

**Q:** How do you stop a continuous ping and get session statistics?
**A:** Ctrl+C
**Difficulty:** Easy
**Tags:** ping, domain-5, prof-messer

---

**Q:** On what operating systems does ping work?
**A:** macOS, Linux, and Windows (works the same on all)
**Difficulty:** Easy
**Tags:** ping, domain-5, prof-messer

---

**Q:** What does traceroute do?
**A:** Traces the route between your device and the destination, mapping the entire path and showing every router between source and destination
**Difficulty:** Easy
**Tags:** traceroute, domain-5, prof-messer

---

**Q:** What is the traceroute command name on Windows vs Linux/macOS?
**A:** `tracert` (Windows), `traceroute` (Linux/macOS)
**Difficulty:** Easy
**Tags:** traceroute, domain-5, prof-messer

---

**Q:** What ICMP mechanism does traceroute use?
**A:** ICMP time to live exceeded error messages
**Difficulty:** Medium
**Tags:** traceroute, icmp, domain-5, prof-messer

---

**Q:** How does traceroute work step by step?
**A:** 1) Sends packet with TTL=1 — first router decreases TTL to 0 and sends back TTL exceeded with its IP. 2) Sends TTL=2 — second router reports. 3) Continues incrementing TTL until destination is reached.
**Difficulty:** Hard
**Tags:** traceroute, domain-5, prof-messer

---

**Q:** How many times is each hop tested by default in traceroute?
**A:** Three times — output shows three response times per hop
**Difficulty:** Medium
**Tags:** traceroute, domain-5, prof-messer

---

**Q:** What does an asterisk in traceroute output indicate?
**A:** A filtered hop — a firewall or device is filtering ICMP messages so no response is returned
**Difficulty:** Medium
**Tags:** traceroute, domain-5, prof-messer

---

**Q:** Why is it useful to compare two traceroutes?
**A:** To find where a route is failing — compare a first traceroute with a second to see where a route may be missing or which router may be stopping the route
**Difficulty:** Medium
**Tags:** traceroute, domain-5, prof-messer

---

**Q:** What does Windows use to send traceroute packets?
**A:** ICMP echo requests; other OSes may allow changing the payload type
**Difficulty:** Medium
**Tags:** traceroute, domain-5, prof-messer

---

**Q:** What do nslookup and dig do?
**A:** Query DNS servers and receive responses — can look up canonical names, IP addresses, cache timers, text records, and other DNS records
**Difficulty:** Easy
**Tags:** nslookup, dig, dns, domain-5, prof-messer

---

**Q:** On what operating systems is nslookup available?
**A:** Windows, Linux, and macOS
**Difficulty:** Easy
**Tags:** nslookup, dns, domain-5, prof-messer

---

**Q:** What is the status of nslookup?
**A:** Deprecated — the goal is to use dig instead
**Difficulty:** Medium
**Tags:** nslookup, dns, domain-5, prof-messer

---

**Q:** On what operating systems is dig included?
**A:** Linux and macOS; Windows requires an older bind package from isc.org (newer versions no longer include it)
**Difficulty:** Medium
**Tags:** dig, dns, domain-5, prof-messer

---

**Q:** How do nslookup and dig compare in terms of results?
**A:** Same information, different output format
**Difficulty:** Easy
**Tags:** nslookup, dig, dns, domain-5, prof-messer

---

**Q:** What is tcpdump?
**A:** A command-line utility that captures packets — can view on screen or save to a file
**Difficulty:** Easy
**Tags:** tcpdump, domain-5, prof-messer

---

**Q:** On what operating systems is tcpdump available?
**A:** Included with Linux and macOS; Windows alternative is WinDump
**Difficulty:** Medium
**Tags:** tcpdump, domain-5, prof-messer

---

**Q:** What file format does tcpdump save captures in?
**A:** pcap (packet capture) format — readable by Wireshark and other utilities
**Difficulty:** Medium
**Tags:** tcpdump, pcap, domain-5, prof-messer

---

**Q:** Can tcpdump filter packets or only capture everything?
**A:** Both — can capture all packets or apply filters
**Difficulty:** Easy
**Tags:** tcpdump, domain-5, prof-messer

---

**Q:** What is netstat?
**A:** Network statistics — shows active network connections to and from your machine
**Difficulty:** Easy
**Tags:** netstat, domain-5, prof-messer

---

**Q:** What does `netstat -a` show?
**A:** All active connections (incoming and outgoing)
**Difficulty:** Easy
**Tags:** netstat, domain-5, prof-messer

---

**Q:** What does `netstat -b` show?
**A:** The Windows executable making each network connection
**Difficulty:** Medium
**Tags:** netstat, domain-5, prof-messer

---

**Q:** What does `netstat -n` show?
**A:** IP addresses only (no DNS name resolution)
**Difficulty:** Medium
**Tags:** netstat, domain-5, prof-messer

---

**Q:** What information does netstat output include?
**A:** Protocol, local IP address and port, remote IP address and port, connection state (established, closing, waiting)
**Difficulty:** Medium
**Tags:** netstat, domain-5, prof-messer

---

**Q:** What command shows IP address configuration on Windows?
**A:** `ipconfig` — shows IPv6, IPv4 address, subnet mask, default gateway
**Difficulty:** Easy
**Tags:** ipconfig, domain-5, prof-messer

---

**Q:** What additional information does `ipconfig /all` provide?
**A:** Device name, node type, MAC address, adapter card, DHCP details, DNS servers
**Difficulty:** Medium
**Tags:** ipconfig, domain-5, prof-messer

---

**Q:** What command shows IP address configuration on Linux/macOS?
**A:** `ifconfig` (specify adapter name, e.g., `ifconfig en0`) — shows MAC address, IPv6 address, IPv4 address, adapter configuration
**Difficulty:** Easy
**Tags:** ifconfig, domain-5, prof-messer

---

**Q:** What is the newer Linux command for viewing IP address configuration?
**A:** `ip address` — provides similar information to ifconfig
**Difficulty:** Medium
**Tags:** ifconfig, domain-5, prof-messer

---

**Q:** What does `arp -a` display?
**A:** The local ARP cache — IP addresses and their associated MAC addresses on the local subnet
**Difficulty:** Easy
**Tags:** arp, domain-5, prof-messer

---

**Q:** On what operating systems does `arp -a` work?
**A:** Linux, macOS, and Windows
**Difficulty:** Easy
**Tags:** arp, domain-5, prof-messer

---

**Q:** Why might an IP address not appear in the ARP cache?
**A:** You have not communicated with that device recently — only devices you've recently communicated with appear in the cache
**Difficulty:** Medium
**Tags:** arp, domain-5, prof-messer

---

**Q:** How can you add a device to your ARP cache?
**A:** Ping the device — it will then appear in the ARP cache with its MAC address
**Difficulty:** Easy
**Tags:** arp, domain-5, prof-messer

---

**Q:** Why is the ARP cache useful for troubleshooting?
**A:** Allows looking up a device's MAC address to find it in a switch's MAC address table
**Difficulty:** Medium
**Tags:** arp, domain-5, prof-messer
