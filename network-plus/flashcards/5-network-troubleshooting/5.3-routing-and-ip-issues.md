# Routing and IP Issues Flashcards

**Q:** What is the purpose of a routing table?
**A:** To determine the best next hop when forwarding traffic through a router — builds a map of where data will be forwarded
**Difficulty:** Easy
**Tags:** routing-tables, domain-5, prof-messer

---

**Q:** What three types of entries can a routing table contain?
**A:** Default gateway configurations, static routes, and dynamically learned routes
**Difficulty:** Easy
**Tags:** routing-tables, domain-5, prof-messer

---

**Q:** What happens when a router has no route for a destination?
**A:** The router drops the traffic; it may send back an ICMP host unreachable message to the sender
**Difficulty:** Medium
**Tags:** routing-tables, icmp, domain-5, prof-messer

---

**Q:** When troubleshooting routing problems, which routing tables should you check?
**A:** The routing table of every router along the path — must confirm routes in both directions (to the destination and back to the source)
**Difficulty:** Medium
**Tags:** routing-tables, troubleshooting, domain-5, prof-messer

---

**Q:** What is helpful to compare routing tables against when troubleshooting?
**A:** A network map
**Difficulty:** Easy
**Tags:** routing-tables, troubleshooting, domain-5, prof-messer

---

**Q:** What is the gateway of last resort?
**A:** A default route that summarizes all possible destinations into one entry, used when no other route in the routing table matches the destination
**Difficulty:** Easy
**Tags:** gateway-of-last-resort, domain-5, prof-messer

---

**Q:** How is the gateway of last resort typically added?
**A:** As a static route configured by the administrator
**Difficulty:** Medium
**Tags:** gateway-of-last-resort, domain-5, prof-messer

---

**Q:** What is the destination address for the gateway of last resort?
**A:** 0.0.0.0/0 — encompasses every host on every network
**Difficulty:** Medium
**Tags:** gateway-of-last-resort, domain-5, prof-messer

---

**Q:** In a routing table, what does a directly connected route mean?
**A:** A network that is directly attached to one of the router's interfaces
**Difficulty:** Easy
**Tags:** routing-tables, domain-5, prof-messer

---

**Q:** What happens when a DHCP address pool is exhausted?
**A:** Devices receive an APIPA address instead
**Difficulty:** Easy
**Tags:** address-pool-exhaustion, dhcp, apipa, domain-5, prof-messer

---

**Q:** What can a device do with an APIPA address?
**A:** Communicate with other devices on the local subnet only — APIPA is nonroutable and cannot communicate outside the local subnet
**Difficulty:** Medium
**Tags:** address-pool-exhaustion, apipa, domain-5, prof-messer

---

**Q:** What is IPAM?
**A:** IP Address Management — used to monitor and view available addresses, pools, and availability across DHCP servers
**Difficulty:** Medium
**Tags:** address-pool-exhaustion, ipam, domain-5, prof-messer

---

**Q:** How can you reduce address pool exhaustion for networks with short-term users?
**A:** Decrease the DHCP lease time — frees up addresses faster and minimizes exhaustion
**Difficulty:** Medium
**Tags:** address-pool-exhaustion, dhcp, domain-5, prof-messer

---

**Q:** What three values might be incorrect when a device receives wrong IP configuration?
**A:** IP address, subnet mask, or default gateway
**Difficulty:** Easy
**Tags:** incorrect-ip, domain-5, prof-messer

---

**Q:** How can you determine what IP configuration other devices on a subnet are using?
**A:** Perform a packet capture to see what other devices on the subnet are configured as, or check configuration of other devices already on the same network
**Difficulty:** Medium
**Tags:** incorrect-ip, troubleshooting, domain-5, prof-messer

---

**Q:** What is the correct troubleshooting order using ping to verify IP configuration?
**A:** Ping local address → ping default gateway → ping an address beyond the gateway
**Difficulty:** Medium
**Tags:** incorrect-ip, troubleshooting, domain-5, prof-messer

---

**Q:** What two tools can you use to map your position in the network and verify correct IP assignment?
**A:** ping and traceroute
**Difficulty:** Easy
**Tags:** incorrect-ip, troubleshooting, domain-5, prof-messer

---

**Q:** What are three common causes of duplicate IP addresses?
**A:** 1) Manually configured device using an address in a DHCP pool, 2) Multiple DHCP servers with overlapping pools, 3) Rogue device with DHCP enabled handing out unexpected addresses
**Difficulty:** Hard
**Tags:** duplicate-ip, domain-5, prof-messer

---

**Q:** How did older operating systems handle duplicate IP addresses?
**A:** Two devices fight over priority based on the switch MAC address table
**Difficulty:** Medium
**Tags:** duplicate-ip, domain-5, prof-messer

---

**Q:** How do modern operating systems handle duplicate IP addresses?
**A:** Duplicate IP is discovered when the device first connects to the network; prevented with an error message displayed on screen
**Difficulty:** Medium
**Tags:** duplicate-ip, domain-5, prof-messer

---

**Q:** What should you do before statically configuring an IP address on a device?
**A:** Ping the IP address first — a response means it is already in use and configuring it would cause a conflict
**Difficulty:** Medium
**Tags:** duplicate-ip, troubleshooting, domain-5, prof-messer

---

**Q:** How do you find the physical location of an unexpected device responding to a ping?
**A:** Check the ARP table to get its MAC address, then use the switch MAC address table to find which interface the device is plugged into
**Difficulty:** Hard
**Tags:** duplicate-ip, troubleshooting, domain-5, prof-messer

---

**Q:** How do you troubleshoot overlapping DHCP pools causing duplicate addresses?
**A:** Perform a packet capture to see exactly what the DHCP servers are offering
**Difficulty:** Medium
**Tags:** duplicate-ip, dhcp, troubleshooting, domain-5, prof-messer
