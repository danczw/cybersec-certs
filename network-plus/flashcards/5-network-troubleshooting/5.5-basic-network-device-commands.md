# Basic Network Device Commands Flashcards

**Q:** Are command-line commands the same across different network equipment manufacturers?
**A:** Very similar but not exactly the same — syntax is close and output contains similar information across manufacturers
**Difficulty:** Easy
**Tags:** device-commands, domain-5, prof-messer

---

**Q:** What does the `show mac-address-table` command display?
**A:** All MAC addresses the switch has learned and which ports they were learned on
**Difficulty:** Easy
**Tags:** show-mac-address-table, domain-5, prof-messer

---

**Q:** How does a switch use the MAC address table?
**A:** References it to decide where to send traffic
**Difficulty:** Easy
**Tags:** show-mac-address-table, domain-5, prof-messer

---

**Q:** What two troubleshooting scenarios is `show mac-address-table` useful for?
**A:** Determining why traffic is being sent out every interface, and whether the maximum number of entries has been reached
**Difficulty:** Medium
**Tags:** show-mac-address-table, domain-5, prof-messer

---

**Q:** What does the `show route` command display?
**A:** All routes inside the routing table
**Difficulty:** Easy
**Tags:** show-route, domain-5, prof-messer

---

**Q:** How do you use `show route` to trace a path across multiple routers?
**A:** Find the route that applies to traffic, follow it out the specific interface, then repeat the process on the next router along the path
**Difficulty:** Medium
**Tags:** show-route, domain-5, prof-messer

---

**Q:** What three pieces of information does each route entry in the routing table show?
**A:** Destination network, next-hop address, and exit interface
**Difficulty:** Medium
**Tags:** show-route, domain-5, prof-messer

---

**Q:** In a routing table, what do the abbreviations R and C mean?
**A:** R = RIP (learned via RIP protocol), C = connected/directly connected to the router
**Difficulty:** Medium
**Tags:** show-route, domain-5, prof-messer

---

**Q:** How do you determine which route applies to your traffic in a routing table?
**A:** Evaluate each route to find the most specific match for your traffic
**Difficulty:** Medium
**Tags:** show-route, domain-5, prof-messer

---

**Q:** What does the `show interface` command display?
**A:** Status and statistics for a particular interface
**Difficulty:** Easy
**Tags:** show-interface, domain-5, prof-messer

---

**Q:** What interface status values can `show interface` display?
**A:** Up, down, connected, or administratively disabled
**Difficulty:** Medium
**Tags:** show-interface, domain-5, prof-messer

---

**Q:** What error information can `show interface` reveal?
**A:** CRC errors, dropped frames, and input/output errors
**Difficulty:** Medium
**Tags:** show-interface, domain-5, prof-messer

---

**Q:** What performance information does `show interface` provide?
**A:** Total number of frames, total broadcasts, and input/output rates
**Difficulty:** Medium
**Tags:** show-interface, domain-5, prof-messer

---

**Q:** What hardware configuration details does `show interface` show?
**A:** Duplex, speed (e.g., full duplex, 100 Mbps), media type (e.g., RJ45), MTU, and encapsulation types
**Difficulty:** Hard
**Tags:** show-interface, domain-5, prof-messer

---

**Q:** What does the `show config` command display?
**A:** The text-based configuration currently running inside a device
**Difficulty:** Easy
**Tags:** show-config, domain-5, prof-messer

---

**Q:** What is the command to view the currently active configuration on a Cisco device?
**A:** `show running-config`
**Difficulty:** Medium
**Tags:** show-config, domain-5, prof-messer

---

**Q:** Can `show config` also view stored configurations?
**A:** Yes — may also view configurations stored on the storage drive of the device
**Difficulty:** Easy
**Tags:** show-config, domain-5, prof-messer

---

**Q:** Is configuration file format the same across manufacturers?
**A:** No — each manufacturer uses different syntax and format for configuration
**Difficulty:** Easy
**Tags:** show-config, domain-5, prof-messer

---

**Q:** What does the `show arp` command display on switches and routers?
**A:** The ARP cache — shows protocol, IP address, hardware/MAC address, and the interface used to identify that pair
**Difficulty:** Medium
**Tags:** show-arp, domain-5, prof-messer

---

**Q:** When is the `show arp` command useful?
**A:** To determine if a switch or router sees a particular MAC address associated with an IP address
**Difficulty:** Medium
**Tags:** show-arp, domain-5, prof-messer

---

**Q:** What does the `show vlan` command display?
**A:** All VLANs on the device and which interfaces are assigned to each VLAN
**Difficulty:** Easy
**Tags:** show-vlan, domain-5, prof-messer

---

**Q:** What specific VLAN information can `show vlan` provide?
**A:** Assigned VLAN IDs, default VLAN for the switch, interfaces in the default VLAN, and interfaces specifically assigned to a different VLAN
**Difficulty:** Medium
**Tags:** show-vlan, domain-5, prof-messer

---

**Q:** What does the `show power` command display?
**A:** PoE power usage for the switch — lists all interfaces, whether PoE is on or off for each, and how much power each device is using
**Difficulty:** Medium
**Tags:** show-power, poe, domain-5, prof-messer

---

**Q:** How does `show power` help with capacity planning?
**A:** Indicates if additional devices can be added by showing total supported wattage, current usage, and remaining power (e.g., 370W supported, 40W used, 330W remaining)
**Difficulty:** Medium
**Tags:** show-power, poe, domain-5, prof-messer
