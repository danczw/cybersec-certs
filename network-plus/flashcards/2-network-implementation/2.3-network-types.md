# Network Types Flashcards

**Q:** What is a wireless mesh network?
**A:** Multiple access points communicating with each other in a close area, with client devices connecting to one AP to reach the rest of the network
**Difficulty:** Medium
**Tags:** wireless, mesh, network-types, domain-2, prof-messer

---

**Q:** What happens when you add a new AP to a wireless mesh?
**A:** It is included in the mesh automatically
**Difficulty:** Easy
**Tags:** wireless, mesh, network-types, domain-2, prof-messer

---

**Q:** Can non-AP devices participate in a wireless mesh?
**A:** Yes — non-AP devices can also mesh amongst each other in an ad hoc form
**Difficulty:** Medium
**Tags:** wireless, mesh, network-types, domain-2, prof-messer

---

**Q:** What is self-healing in a wireless mesh?
**A:** If one device leaves the network, the mesh detects it and maintains connectivity for remaining devices
**Difficulty:** Medium
**Tags:** wireless, mesh, network-types, domain-2, prof-messer

---

**Q:** What is an ad hoc wireless connection?
**A:** Two devices connecting directly using 802.11 without an access point
**Difficulty:** Easy
**Tags:** wireless, ad-hoc, ibss, network-types, domain-2, prof-messer

---

**Q:** What is another name for an ad hoc wireless connection?
**A:** Independent Basic Service Set (IBSS)
**Difficulty:** Medium
**Tags:** wireless, ad-hoc, ibss, network-types, domain-2, prof-messer

---

**Q:** Can ad hoc connections be both long-term and temporary?
**A:** Yes — long-term when two devices are permanently connected, or temporary for tasks like IoT device configuration
**Difficulty:** Medium
**Tags:** wireless, ad-hoc, network-types, domain-2, prof-messer

---

**Q:** Describe the common temporary use of an ad hoc connection with IoT devices.
**A:** Connect to the IoT device via ad hoc, transfer configuration (SSID, security settings), then disable the ad hoc connection so the IoT device joins the main network
**Difficulty:** Hard
**Tags:** wireless, ad-hoc, iot, network-types, domain-2, prof-messer

---

**Q:** What is point to point wireless mode?
**A:** Connects two locations directly (e.g., building to building) using wireless APs
**Difficulty:** Easy
**Tags:** wireless, point-to-point, network-types, domain-2, prof-messer

---

**Q:** What does each side of a point to point wireless link typically have?
**A:** An AP connected to a switch and internal network
**Difficulty:** Medium
**Tags:** wireless, point-to-point, network-types, domain-2, prof-messer

---

**Q:** Do all access points support point to point mode?
**A:** No — requires both software support and hardware capable of extended distance
**Difficulty:** Medium
**Tags:** wireless, point-to-point, network-types, domain-2, prof-messer

---

**Q:** What three things may be required for point to point wireless over longer distances?
**A:** Additional antennas, power output changes, and appropriate frequencies
**Difficulty:** Hard
**Tags:** wireless, point-to-point, network-types, domain-2, prof-messer

---

**Q:** What is infrastructure mode?
**A:** The most common wireless connection type — a centralized access point that all wireless devices connect to
**Difficulty:** Easy
**Tags:** wireless, infrastructure, network-types, domain-2, prof-messer

---

**Q:** Where is infrastructure mode commonly used?
**A:** Home and office environments
**Difficulty:** Easy
**Tags:** wireless, infrastructure, network-types, domain-2, prof-messer

---

**Q:** In infrastructure mode, how do devices communicate with the wired network or other wireless devices?
**A:** Through the centralized access point
**Difficulty:** Easy
**Tags:** wireless, infrastructure, network-types, domain-2, prof-messer

---

**Q:** What are the two options APs may offer regarding device-to-device communication in infrastructure mode?
**A:** Allow wireless device-to-device communication, or isolate devices to only communicate with the AP and networks beyond it
**Difficulty:** Medium
**Tags:** wireless, infrastructure, network-types, domain-2, prof-messer

---

**Q:** Which wireless network type is self-healing?
**A:** Wireless mesh — it detects when a device leaves and maintains connectivity for remaining devices
**Difficulty:** Medium
**Tags:** wireless, mesh, network-types, domain-2, prof-messer

---

**Q:** Name the four wireless network types.
**A:** Wireless mesh, ad hoc (IBSS), point to point, and infrastructure mode
**Difficulty:** Medium
**Tags:** wireless, network-types, domain-2, prof-messer

---

**Q:** Which wireless network type requires no access point at all?
**A:** Ad hoc (IBSS) — two devices connect directly using 802.11
**Difficulty:** Easy
**Tags:** wireless, ad-hoc, network-types, domain-2, prof-messer

---

**Q:** Which wireless network type is used to connect buildings to each other?
**A:** Point to point
**Difficulty:** Easy
**Tags:** wireless, point-to-point, network-types, domain-2, prof-messer
