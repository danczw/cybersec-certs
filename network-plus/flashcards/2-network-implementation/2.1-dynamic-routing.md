# Dynamic Routing Flashcards

**Q:** What is dynamic routing?
**A:** Routers automatically discover routes and update each other — no manual configuration of individual routes needed
**Difficulty:** Easy
**Tags:** routing, dynamic-routing, domain-2, prof-messer

---

**Q:** What happens when a new router is added to a dynamically routed network?
**A:** All routers automatically learn the new routes
**Difficulty:** Easy
**Tags:** routing, dynamic-routing, domain-2, prof-messer

---

**Q:** What happens when a router is removed from a dynamically routed network?
**A:** All routers automatically remove those routes
**Difficulty:** Easy
**Tags:** routing, dynamic-routing, domain-2, prof-messer

---

**Q:** What overhead does dynamic routing require?
**A:** CPU and memory inside the router; may need additional monitoring to ensure the router can handle the load
**Difficulty:** Medium
**Tags:** routing, dynamic-routing, domain-2, prof-messer

---

**Q:** Besides overhead, what else does dynamic routing require?
**A:** Initial configuration of the dynamic routing protocol
**Difficulty:** Easy
**Tags:** routing, dynamic-routing, domain-2, prof-messer

---

**Q:** What are the five steps of how dynamic routing works?
**A:** 1) Router listens for routing updates on local subnet (sent directly or via multicast) 2) Builds its own routing table from received updates 3) Sends its own multicast to inform nearby routers of routes it knows 4) Receiving routers interpret updates — determine if better route or secondary route 5) If network changes occur, routers inform all others
**Difficulty:** Hard
**Tags:** routing, dynamic-routing, domain-2, prof-messer

---

**Q:** How are dynamic routing updates sent between routers?
**A:** Directly or via multicast
**Difficulty:** Medium
**Tags:** routing, dynamic-routing, domain-2, prof-messer

---

**Q:** When a router receives a routing update, what does it determine?
**A:** Whether the update represents a better route than what it already has, or if it should be used as a secondary route
**Difficulty:** Medium
**Tags:** routing, dynamic-routing, domain-2, prof-messer

---

**Q:** What three factors should you consider when choosing a dynamic routing protocol?
**A:** 1) Routing decisions — link state vs. hop count vs. link speed 2) Convergence time — seconds vs. minutes 3) Router compatibility — cross-manufacturer vs. vendor-specific
**Difficulty:** Medium
**Tags:** routing, dynamic-routing, domain-2, prof-messer

---

**Q:** What is convergence?
**A:** The time it takes for all routers to update their tables after a network change
**Difficulty:** Easy
**Tags:** routing, dynamic-routing, domain-2, prof-messer

---

**Q:** What does EIGRP stand for?
**A:** Enhanced Interior Gateway Routing Protocol
**Difficulty:** Easy
**Tags:** routing, eigrp, domain-2, prof-messer

---

**Q:** What vendor is EIGRP associated with?
**A:** Cisco — it has proprietary aspects, but may be available on other manufacturers' routers
**Difficulty:** Easy
**Tags:** routing, eigrp, domain-2, prof-messer

---

**Q:** What are the characteristics of EIGRP?
**A:** 1) Cisco-centric 2) Relatively easy to set up 3) Converges relatively quickly 4) Identifies and prevents routing loops 5) Efficiently discovers other EIGRP routers with minimum network traffic
**Difficulty:** Hard
**Tags:** routing, eigrp, domain-2, prof-messer

---

**Q:** What does OSPF stand for?
**A:** Open Shortest Path First
**Difficulty:** Easy
**Tags:** routing, ospf, domain-2, prof-messer

---

**Q:** What type of protocol is OSPF?
**A:** A link-state protocol — determines best route based on uptime and availability
**Difficulty:** Medium
**Tags:** routing, ospf, domain-2, prof-messer

---

**Q:** What is an Autonomous System (AS)?
**A:** A network under single administrative control
**Difficulty:** Easy
**Tags:** routing, ospf, domain-2, prof-messer

---

**Q:** Where is OSPF typically used?
**A:** Within an Autonomous System (AS) — a network you have complete control of
**Difficulty:** Medium
**Tags:** routing, ospf, domain-2, prof-messer

---

**Q:** How does OSPF determine the best route?
**A:** Assigns costs to individual links (based on throughput, link status, traversal time) — lowest cost and fastest path = best route
**Difficulty:** Medium
**Tags:** routing, ospf, domain-2, prof-messer

---

**Q:** What happens when two OSPF links have identical costs?
**A:** Can load balance across both links
**Difficulty:** Medium
**Tags:** routing, ospf, domain-2, prof-messer

---

**Q:** What is a key advantage of OSPF over EIGRP regarding compatibility?
**A:** OSPF is a generic/open standard — available on many different manufacturers' devices
**Difficulty:** Medium
**Tags:** routing, ospf, domain-2, prof-messer

---

**Q:** What does BGP stand for?
**A:** Border Gateway Protocol
**Difficulty:** Easy
**Tags:** routing, bgp, domain-2, prof-messer

---

**Q:** What type of protocol is BGP?
**A:** An external gateway protocol — routes traffic outside your AS to other organizations
**Difficulty:** Medium
**Tags:** routing, bgp, domain-2, prof-messer

---

**Q:** Where is BGP used?
**A:** On WANs and internet connections — designed to dynamically update routes across the entire internet
**Difficulty:** Medium
**Tags:** routing, bgp, domain-2, prof-messer

---

**Q:** What is BGP sometimes called and why?
**A:** The "three-napkins protocol" — originally sketched on napkins
**Difficulty:** Easy
**Tags:** routing, bgp, domain-2, prof-messer

---

**Q:** When would you use BGP?
**A:** When an organization has one or more internet connections and needs dynamic routing to internet sites
**Difficulty:** Medium
**Tags:** routing, bgp, domain-2, prof-messer

---

**Q:** What is a link-state protocol?
**A:** A routing protocol that makes routing decisions based on link uptime and availability
**Difficulty:** Easy
**Tags:** routing, ospf, domain-2, prof-messer

---

**Q:** What factors does OSPF use to assign costs to links?
**A:** Throughput, link status, and traversal time
**Difficulty:** Medium
**Tags:** routing, ospf, domain-2, prof-messer

---

**Q:** Compare EIGRP, OSPF, and BGP in terms of scope of use.
**A:** EIGRP — Cisco-centric environments; OSPF — within an Autonomous System (any manufacturer); BGP — between autonomous systems / across the internet
**Difficulty:** Hard
**Tags:** routing, eigrp, ospf, bgp, domain-2, prof-messer
