# VLAN Hopping Flashcards

**Q:** What is VLAN hopping?
**A:** Bypassing VLAN separation to communicate with a different VLAN without a router
**Difficulty:** Easy
**Tags:** vlan-hopping, attacks, domain-4, prof-messer

---

**Q:** What are the two methods of VLAN hopping?
**A:** Switch spoofing and double tagging
**Difficulty:** Easy
**Tags:** vlan-hopping, attacks, domain-4, prof-messer

---

**Q:** Why are VLANs used on switches?
**A:** To separate different parts of a network so devices on one VLAN cannot communicate with another VLAN without a router
**Difficulty:** Easy
**Tags:** vlan, segmentation, domain-4, prof-messer

---

**Q:** What is switch spoofing?
**A:** An attacker pretends to be a switch to trigger trunk negotiation, gaining trunk access and the ability to send traffic to any VLAN on that port
**Difficulty:** Medium
**Tags:** vlan-hopping, switch-spoofing, attacks, domain-4, prof-messer

---

**Q:** What switch feature does switch spoofing exploit?
**A:** Trunk autonegotiation — the switch autoconfigures an interface as a trunk when it detects another switch
**Difficulty:** Medium
**Tags:** vlan-hopping, switch-spoofing, attacks, domain-4, prof-messer

---

**Q:** Why does gaining a trunk connection allow VLAN hopping?
**A:** A trunk carries traffic for multiple VLANs simultaneously, so an attacker with trunk access can send traffic to any VLAN configured on that port
**Difficulty:** Medium
**Tags:** vlan-hopping, switch-spoofing, attacks, domain-4, prof-messer

---

**Q:** Name three mitigations for switch spoofing.
**A:** Disable trunk autonegotiation, manually configure trunk interfaces, configure which specific VLANs are allowed on each trunk
**Difficulty:** Medium
**Tags:** vlan-hopping, switch-spoofing, mitigation, domain-4, prof-messer

---

**Q:** What is double tagging?
**A:** A VLAN hopping attack where a frame is crafted with two 802.1Q VLAN tags to send traffic to a VLAN the attacker doesn't belong to
**Difficulty:** Medium
**Tags:** vlan-hopping, double-tagging, attacks, domain-4, prof-messer

---

**Q:** What switch configuration does double tagging exploit?
**A:** The native VLAN configuration — the attacker must be on the same VLAN as the trunk's native VLAN
**Difficulty:** Hard
**Tags:** vlan-hopping, double-tagging, attacks, domain-4, prof-messer

---

**Q:** Is double tagging a one-way or two-way attack?
**A:** One-way only — no response can be received, making it useful for DoS but not normal communication
**Difficulty:** Medium
**Tags:** vlan-hopping, double-tagging, attacks, domain-4, prof-messer

---

**Q:** Describe the four steps of a double tagging attack.
**A:** 1) Attacker creates frame with two tags (outer=native VLAN, inner=target VLAN), 2) First switch reads outer tag, removes it, forwards on native VLAN, 3) Frame arrives at second switch with only inner tag, 4) Second switch delivers frame to target VLAN
**Difficulty:** Hard
**Tags:** vlan-hopping, double-tagging, attacks, domain-4, prof-messer

---

**Q:** In a double tagging attack, what happens to the outer VLAN tag?
**A:** The first switch reads it, removes it, and forwards the frame onto the native VLAN
**Difficulty:** Hard
**Tags:** vlan-hopping, double-tagging, attacks, domain-4, prof-messer

---

**Q:** In a double tagging attack, what does the second switch see?
**A:** A frame with only the inner VLAN tag remaining — it interprets it as a trunked frame for that VLAN and delivers accordingly
**Difficulty:** Hard
**Tags:** vlan-hopping, double-tagging, attacks, domain-4, prof-messer

---

**Q:** What is the default native VLAN ID on most switches?
**A:** VLAN 1
**Difficulty:** Easy
**Tags:** vlan, native-vlan, domain-4, prof-messer

---

**Q:** Name three mitigations for double tagging.
**A:** Don't place users on the native VLAN, change the native VLAN ID from default (VLAN 1) to another value, force tagging of the native VLAN for all trunk traffic
**Difficulty:** Medium
**Tags:** vlan-hopping, double-tagging, mitigation, domain-4, prof-messer

---

**Q:** Why must the attacker be on the native VLAN for double tagging to work?
**A:** The first switch strips the outer tag because it matches the native VLAN (native VLAN traffic is sent untagged on the trunk), leaving only the inner tag for the second switch to interpret
**Difficulty:** Hard
**Tags:** vlan-hopping, double-tagging, attacks, domain-4, prof-messer

---

**Q:** Why does changing the native VLAN ID mitigate double tagging?
**A:** If users aren't on the native VLAN, the first switch won't strip the outer tag as untagged native traffic, breaking the attack
**Difficulty:** Hard
**Tags:** vlan-hopping, double-tagging, mitigation, domain-4, prof-messer
