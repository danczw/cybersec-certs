# Segmentation Enforcement Flashcards

**Q:** What are the two types of network segmentation?
**A:** Physical separation of devices, or logical/virtual segmentation (e.g., VLANs)
**Difficulty:** Easy
**Tags:** segmentation, domain-4, prof-messer

---

**Q:** Name three purposes of network segmentation.
**A:** Performance (isolate high-bandwidth apps), security (limit device communication), compliance (e.g., PCI DSS requires it for credit card data)
**Difficulty:** Medium
**Tags:** segmentation, domain-4, prof-messer

---

**Q:** How does segmentation improve network performance?
**A:** High-bandwidth applications can be placed on their own network to transfer data more efficiently
**Difficulty:** Medium
**Tags:** segmentation, performance, domain-4, prof-messer

---

**Q:** Which compliance standard requires network segmentation for storing credit card data?
**A:** PCI DSS (Payment Card Industry Data Security Standard)
**Difficulty:** Medium
**Tags:** segmentation, pci-dss, compliance, domain-4, prof-messer
