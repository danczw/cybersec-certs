# Security Rules Flashcards

**Q:** What is an Access Control List (ACL)?
**A:** A list of traffic that is allowed and traffic that is disallowed
**Difficulty:** Easy
**Tags:** acl, security-rules, domain-4, prof-messer

---

**Q:** Name five criteria that can be used in an ACL rule.
**A:** Source IP address, destination IP address, port number, time of day, application
**Difficulty:** Medium
**Tags:** acl, security-rules, domain-4, prof-messer

---

**Q:** Where can ACLs be found?
**A:** Routers, firewalls, operating systems, and anything that needs to make access decisions
**Difficulty:** Medium
**Tags:** acl, security-rules, domain-4, prof-messer

---

**Q:** What is a firewall rule set in relation to an ACL?
**A:** A complex form of an ACL with components like rule name, source/destination zone, source/destination address, destination port, and username
**Difficulty:** Medium
**Tags:** firewall, acl, security-rules, domain-4, prof-messer

---

**Q:** In what order are firewall rules processed?
**A:** Top-to-bottom — first match wins
**Difficulty:** Easy
**Tags:** firewall, security-rules, domain-4, prof-messer

---

**Q:** Where should more specific firewall rules be placed?
**A:** At the top of the rule set, so they match first before reaching more general rules lower down
**Difficulty:** Medium
**Tags:** firewall, security-rules, domain-4, prof-messer

---

**Q:** What is an implicit deny in a firewall?
**A:** If traffic reaches the end of the rule set without matching any rule, it is automatically denied — no explicit deny rule is needed
**Difficulty:** Medium
**Tags:** firewall, implicit-deny, security-rules, domain-4, prof-messer

---

**Q:** What is URL filtering?
**A:** Filtering traffic based on specific URLs or categories of URLs (auction, hacking, travel, recreation, etc.) using Allow lists and Block lists
**Difficulty:** Medium
**Tags:** url-filtering, content-filtering, security-rules, domain-4, prof-messer

---

**Q:** Why are URL categories easier to manage than individual URLs?
**A:** You can allow/block an entire category instead of listing hundreds or thousands of individual URLs
**Difficulty:** Easy
**Tags:** url-filtering, content-filtering, security-rules, domain-4, prof-messer

---

**Q:** Why is URL filtering often combined with firewall rules?
**A:** Users try to circumvent URL filtering — combining with firewall rules prevents circumvention
**Difficulty:** Medium
**Tags:** url-filtering, firewall, security-rules, domain-4, prof-messer

---

**Q:** Where is URL filtering built in on modern networks?
**A:** Most next-generation firewalls have URL filtering built into the software
**Difficulty:** Medium
**Tags:** url-filtering, ngfw, security-rules, domain-4, prof-messer

---

**Q:** Name four types of content filtering beyond URL filtering.
**A:** Filtering internal documents/financial details, preventing non-safe-for-work content, parental controls, antivirus/antimalware filtering
**Difficulty:** Medium
**Tags:** content-filtering, security-rules, domain-4, prof-messer

---

**Q:** What is a screened subnet?
**A:** A separate area of the network specifically designed for services made available to the public (web servers, email servers), keeping visitors away from internal services
**Difficulty:** Medium
**Tags:** screened-subnet, security-rules, domain-4, prof-messer

---

**Q:** What types of servers are typically placed in a screened subnet?
**A:** Public web servers and public email servers
**Difficulty:** Easy
**Tags:** screened-subnet, security-rules, domain-4, prof-messer

---

**Q:** Can internal users still reach the internet when a screened subnet is in use?
**A:** Yes — the internal network remains isolated but internal users can still communicate out to the internet
**Difficulty:** Easy
**Tags:** screened-subnet, security-rules, domain-4, prof-messer

---

**Q:** What are security zones in a firewall?
**A:** Broad labels used in firewall rules instead of IP address ranges — simplify security policies by referencing zone names
**Difficulty:** Medium
**Tags:** security-zones, firewall, security-rules, domain-4, prof-messer

---

**Q:** Name three examples of security zone pairs.
**A:** Trusted/Untrusted, Internal/External, Inside/Internet/Server/Databases/Screened subnet
**Difficulty:** Medium
**Tags:** security-zones, firewall, security-rules, domain-4, prof-messer

---

**Q:** How do zone-based firewall rules simplify security policies?
**A:** Rules reference zone names instead of specific IP addresses or ports — e.g., "trusted zone can communicate to untrusted zone" with no additional details needed
**Difficulty:** Medium
**Tags:** security-zones, firewall, security-rules, domain-4, prof-messer

---

**Q:** How do you get more granularity in a zone-based firewall?
**A:** Add more security zones — more zones equals more granularity in firewall rules
**Difficulty:** Easy
**Tags:** security-zones, firewall, security-rules, domain-4, prof-messer
