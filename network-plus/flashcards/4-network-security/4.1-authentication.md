# Authentication Flashcards

**Q:** What does AAA stand for in the AAA framework?
**A:** Authentication, Authorization, and Accounting
**Difficulty:** Easy
**Tags:** aaa, authentication, domain-4, prof-messer

---

**Q:** What is the difference between identification and authentication?
**A:** Identification is public information (username, email) that doesn't grant access; authentication is proving identity with private information (password, biometric, etc.)
**Difficulty:** Easy
**Tags:** aaa, authentication, domain-4, prof-messer

---

**Q:** What is the role of Authorization in the AAA framework?
**A:** Providing appropriate access to files, directories, or network areas based on the authenticated identity
**Difficulty:** Easy
**Tags:** aaa, authorization, domain-4, prof-messer

---

**Q:** What is the role of Accounting in the AAA framework?
**A:** Tracking login/logout events, failed authentication attempts, and other session details
**Difficulty:** Easy
**Tags:** aaa, accounting, domain-4, prof-messer

---

**Q:** In a typical AAA authentication flow, what happens after a VPN concentrator receives user credentials?
**A:** It forwards the credentials to a AAA server for validation
**Difficulty:** Medium
**Tags:** aaa, vpn, authentication, domain-4, prof-messer

---

**Q:** What is Single Sign-On (SSO)?
**A:** Authenticating once and gaining access to all authorized resources for the session without re-entering credentials
**Difficulty:** Easy
**Tags:** sso, authentication, domain-4, prof-messer

---

**Q:** What is the typical time limit for an SSO session?
**A:** 24 hours
**Difficulty:** Medium
**Tags:** sso, authentication, domain-4, prof-messer

---

**Q:** Do all authentication methods support SSO?
**A:** No — SSO support varies by authentication method
**Difficulty:** Easy
**Tags:** sso, authentication, domain-4, prof-messer

**Q:** What does LDAP stand for?
**A:** Lightweight Directory Access Protocol
**Difficulty:** Easy
**Tags:** ldap, authentication, domain-4, prof-messer

---

**Q:** What advantage does LDAP provide over a simple username/password list?
**A:** It provides additional context about users and devices — departments, locations, organizational structure — via a centralized directory
**Difficulty:** Medium
**Tags:** ldap, authentication, domain-4, prof-messer

---

**Q:** What standard is LDAP based on, and who created it?
**A:** X.500, created by the International Telecommunications Union (ITU)
**Difficulty:** Medium
**Tags:** ldap, x500, authentication, domain-4, prof-messer

---

**Q:** Name three directory services that use LDAP.
**A:** Windows Active Directory, Apple OpenDirectory, Novell eDirectory
**Difficulty:** Medium
**Tags:** ldap, authentication, domain-4, prof-messer

---

**Q:** In X.500, what does CN stand for and what does it identify?
**A:** Common Name — identifies the person or object
**Difficulty:** Easy
**Tags:** ldap, x500, domain-4, prof-messer

---

**Q:** In X.500, what does OU stand for?
**A:** Organizational Unit — a unit or department within the organization
**Difficulty:** Easy
**Tags:** ldap, x500, domain-4, prof-messer

---

**Q:** In X.500, what does DC stand for?
**A:** Domain Component — components of the object's domain
**Difficulty:** Easy
**Tags:** ldap, x500, domain-4, prof-messer

---

**Q:** In X.500, what does the C attribute represent?
**A:** Country — the country's 2-character ISO code (e.g., c=US or c=GB)
**Difficulty:** Medium
**Tags:** ldap, x500, domain-4, prof-messer

---

**Q:** In X.500, what does the L attribute represent?
**A:** Locality — usually a city or area
**Difficulty:** Medium
**Tags:** ldap, x500, domain-4, prof-messer

---

**Q:** In X.500, what does the ST attribute represent?
**A:** State — a state, province, or county within a country
**Difficulty:** Medium
**Tags:** ldap, x500, domain-4, prof-messer

---

**Q:** What is the difference between containers and leaf objects in an LDAP directory tree?
**A:** Containers are higher-level grouping objects (countries, departments); leaf objects are individual users or devices at the bottom of the tree
**Difficulty:** Medium
**Tags:** ldap, x500, domain-4, prof-messer

**Q:** What does SAML stand for?
**A:** Security Assertion Markup Language
**Difficulty:** Easy
**Tags:** saml, authentication, domain-4, prof-messer

---

**Q:** What is SAML's primary purpose?
**A:** An open standard for authentication and authorization that can be applied to many different types of applications
**Difficulty:** Medium
**Tags:** saml, authentication, domain-4, prof-messer

---

**Q:** What is a key limitation of SAML?
**A:** It was not designed for mobile devices, making multi-device authentication challenging
**Difficulty:** Medium
**Tags:** saml, authentication, domain-4, prof-messer

---

**Q:** Name the three components in a SAML authentication flow.
**A:** Resource server (holds protected resource), Client (user's browser), Authorization server (validates credentials)
**Difficulty:** Medium
**Tags:** saml, authentication, domain-4, prof-messer

---

**Q:** In SAML, what happens when a user tries to access a resource without authentication?
**A:** The resource server redirects the client to the authorization server via a signed/encrypted SAML request
**Difficulty:** Hard
**Tags:** saml, authentication, domain-4, prof-messer

---

**Q:** In SAML, what does the authorization server provide to the client after successful authentication?
**A:** A SAML token
**Difficulty:** Medium
**Tags:** saml, authentication, domain-4, prof-messer

---

**Q:** In SAML, how does the resource server confirm a client is authenticated?
**A:** The client presents the SAML token, and the resource server verifies its cryptographic signatures
**Difficulty:** Hard
**Tags:** saml, authentication, domain-4, prof-messer

**A:** Something you are

**Q:** What does TOTP stand for?
**A:** Time-based One-Time Password
**Difficulty:** Easy
**Tags:** totp, mfa, authentication, domain-4, prof-messer

---

**Q:** What two inputs does TOTP use to generate codes?
**A:** A pre-shared secret key and the current time
**Difficulty:** Medium
**Tags:** totp, mfa, authentication, domain-4, prof-messer

---

**Q:** How often do TOTP codes typically change?
**A:** Every 30 seconds
**Difficulty:** Medium
**Tags:** totp, mfa, authentication, domain-4, prof-messer

---

**Q:** Why must client and server be time-synchronized for TOTP to work?
**A:** TOTP uses the current time as an input to generate codes — if clocks are out of sync, the codes won't match
**Difficulty:** Hard
**Tags:** totp, mfa, authentication, domain-4, prof-messer

---

**Q:** What protocol is commonly used to synchronize time between TOTP client and server?
**A:** NTP (Network Time Protocol)
**Difficulty:** Medium
**Tags:** totp, ntp, mfa, authentication, domain-4, prof-messer

---

**Q:** Which MFA factor category does a TOTP authenticator app fall under?
**A:** Something you have
**Difficulty:** Medium
**Tags:** totp, mfa, authentication, domain-4, prof-messer

---

**Q:** Are TOTP codes truly random?
**A:** No — they are pseudorandom; they only appear random but are predictable by both sides using the shared secret key and synchronized time
**Difficulty:** Hard
**Tags:** totp, mfa, authentication, domain-4, prof-messer
