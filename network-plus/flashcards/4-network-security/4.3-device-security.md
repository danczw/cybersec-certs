# Device Security Flashcards

**Q:** Why are open port numbers a security concern?
**A:** Each open port is an entry point into a service running on the system — visible to others on the network
**Difficulty:** Easy
**Tags:** ports, device-security, domain-4, prof-messer

---

**Q:** What is the valid range of port numbers on a system?
**A:** 0–65,535
**Difficulty:** Easy
**Tags:** ports, device-security, domain-4, prof-messer

---

**Q:** What should you do with a port for a service that is no longer in use?
**A:** Close the service and ensure the port is not externally accessible
**Difficulty:** Easy
**Tags:** ports, device-security, domain-4, prof-messer

---

**Q:** How can a firewall help with open ports?
**A:** It controls which devices are able to connect to open ports on your system
**Difficulty:** Easy
**Tags:** ports, firewall, device-security, domain-4, prof-messer

---

**Q:** What tool can be used to scan a system for open ports?
**A:** Nmap — scans the system to show what port numbers are advertised to the network
**Difficulty:** Medium
**Tags:** ports, nmap, device-security, domain-4, prof-messer

---

**Q:** Why are default credentials a security risk?
**A:** They often provide full administrative access and are publicly known — anyone who knows them has complete control of the system
**Difficulty:** Easy
**Tags:** default-credentials, device-security, domain-4, prof-messer

---

**Q:** What types of devices commonly ship with default credentials?
**A:** Switches, routers, firewalls, and other networking devices
**Difficulty:** Easy
**Tags:** default-credentials, device-security, domain-4, prof-messer

---

**Q:** What is port security on a switch?
**A:** A feature that prevents unauthorized devices from connecting to a switch interface, based on MAC address
**Difficulty:** Medium
**Tags:** port-security, switch, device-security, domain-4, prof-messer

---

**Q:** What are the configuration options for port security?
**A:** Set how many MAC addresses are allowed per interface, specify exact MAC addresses allowed, switch monitors and records MACs of connected devices
**Difficulty:** Medium
**Tags:** port-security, switch, device-security, domain-4, prof-messer

---

**Q:** What is the default action on many switches when port security detects an unexpected device?
**A:** Immediately disable the interface and send a notification to the network administrator
**Difficulty:** Medium
**Tags:** port-security, switch, device-security, domain-4, prof-messer

---

**Q:** Why should unused switch interfaces be disabled?
**A:** To prevent unauthorized devices from connecting — makes the network much more secure
**Difficulty:** Easy
**Tags:** switch, device-security, domain-4, prof-messer

---

**Q:** What is the trade-off of disabling unused switch interfaces?
**A:** Requires additional administration to track which interfaces are enabled/disabled and enable them when needed
**Difficulty:** Medium
**Tags:** switch, device-security, domain-4, prof-messer

---

**Q:** What does NAC stand for?
**A:** Network Access Control
**Difficulty:** Easy
**Tags:** nac, 802.1x, device-security, domain-4, prof-messer

---

**Q:** What does NAC / 802.1X require before a device can communicate on the network?
**A:** Authentication — user must provide username and password before gaining access
**Difficulty:** Medium
**Tags:** nac, 802.1x, device-security, domain-4, prof-messer

---

**Q:** Does 802.1X apply to wired connections, wireless connections, or both?
**A:** Both wired and wireless connections
**Difficulty:** Medium
**Tags:** nac, 802.1x, device-security, domain-4, prof-messer

---

**Q:** What is MAC address filtering?
**A:** Limiting network access based on the hardware (MAC) address of devices
**Difficulty:** Easy
**Tags:** mac-filtering, device-security, domain-4, prof-messer

---

**Q:** Why is MAC address filtering considered security through obscurity?
**A:** MAC addresses can be administratively changed — an attacker can capture valid MACs from the network, wait for one to leave, then spoof that MAC to bypass the filter
**Difficulty:** Hard
**Tags:** mac-filtering, device-security, domain-4, prof-messer

---

**Q:** What does "security through obscurity" mean?
**A:** If you know the method being used for security, it becomes very easy to circumvent it
**Difficulty:** Medium
**Tags:** mac-filtering, device-security, domain-4, prof-messer

---

**Q:** What is a key management system?
**A:** Third-party software to manage authentication details, certificates, encryption keys, and SSH keys from a single console
**Difficulty:** Medium
**Tags:** key-management, device-security, domain-4, prof-messer

---

**Q:** Name five capabilities of a key management system.
**A:** Create keys for specific services/providers, associate keys with users/services, track expiration dates, renew or revoke keys, monitor key usage and access
**Difficulty:** Hard
**Tags:** key-management, device-security, domain-4, prof-messer

---

**Q:** What types of items does a key management system manage?
**A:** SSL certificates, SSH keys, license details, certificate authorities
**Difficulty:** Medium
**Tags:** key-management, device-security, domain-4, prof-messer

---

**Q:** What types of reports can a key management system generate?
**A:** SSH reports, landing server reports, private key reports
**Difficulty:** Medium
**Tags:** key-management, device-security, domain-4, prof-messer
