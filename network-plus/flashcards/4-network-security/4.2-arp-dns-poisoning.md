# ARP and DNS Poisoning Flashcards

**Q:** What is spoofing?
**A:** Pretending to be another person or device
**Difficulty:** Easy
**Tags:** spoofing, attacks, domain-4, prof-messer

---

**Q:** Name four examples of spoofing.
**A:** Fake web server, fake DNS server, email address spoofing, caller ID spoofing
**Difficulty:** Medium
**Tags:** spoofing, attacks, domain-4, prof-messer

---

**Q:** What type of attack is spoofing commonly used for?
**A:** On-path attacks — sitting in the middle of a conversation to monitor or change its contents
**Difficulty:** Medium
**Tags:** spoofing, on-path, attacks, domain-4, prof-messer

---

**Q:** What is ARP poisoning?
**A:** An attack where the attacker pretends to be an IP address they are not by sending spoofed ARP responses, also called IP spoofing
**Difficulty:** Medium
**Tags:** arp-poisoning, attacks, domain-4, prof-messer

---

**Q:** What does ARP resolve?
**A:** IP addresses to MAC addresses on a local network
**Difficulty:** Easy
**Tags:** arp, fundamentals, domain-4, prof-messer

---

**Q:** Describe how ARP normally works in four steps.
**A:** 1) Device needs MAC address of another device (only has IP), 2) ARP broadcasts "Who has this IP?", 3) Device with that IP responds with its MAC, 4) Requester caches the response in local ARP cache
**Difficulty:** Medium
**Tags:** arp, fundamentals, domain-4, prof-messer

---

**Q:** What are the two security weaknesses of ARP that make poisoning possible?
**A:** No authentication or security in the ARP process, and ARP accepts any response — even unsolicited ones
**Difficulty:** Medium
**Tags:** arp-poisoning, vulnerability, domain-4, prof-messer

---

**Q:** In an ARP poisoning attack, does the attacker need to wait for the victim to send an ARP request?
**A:** No — ARP accepts unsolicited responses, so the attacker can send a spoofed response at any time
**Difficulty:** Medium
**Tags:** arp-poisoning, attacks, domain-4, prof-messer

---

**Q:** Describe the five steps of an ARP poisoning attack.
**A:** 1) Attacker sends unsolicited ARP response to victim, 2) Response spoofs the router's IP with attacker's MAC, 3) Victim's ARP cache updates with attacker's MAC for the router's IP, 4) All victim-to-router traffic goes to attacker first, 5) Attacker forwards to legitimate router — neither side knows
**Difficulty:** Hard
**Tags:** arp-poisoning, attacks, domain-4, prof-messer

---

**Q:** What is the result of a successful ARP poisoning attack?
**A:** An on-path attack — attacker intercepts and forwards all traffic between victim and router, with neither side realizing there's an attacker in the middle
**Difficulty:** Medium
**Tags:** arp-poisoning, on-path, attacks, domain-4, prof-messer

---

**Q:** What is DNS poisoning?
**A:** Modifying information on the DNS server itself, or modifying DNS responses in transit — also called DNS spoofing
**Difficulty:** Easy
**Tags:** dns-poisoning, attacks, domain-4, prof-messer

---

**Q:** Name three methods of DNS poisoning.
**A:** Modify the host file on the client, send fake responses to legitimate DNS requests (on-path), or hack into the DNS server and change its configuration
**Difficulty:** Hard
**Tags:** dns-poisoning, attacks, domain-4, prof-messer

---

**Q:** Why does modifying a client's host file effectively poison DNS?
**A:** The host file has higher priority than DNS responses — entries always take precedence over anything from a DNS server
**Difficulty:** Medium
**Tags:** dns-poisoning, attacks, domain-4, prof-messer

---

**Q:** What type of attack is required to send fake responses to legitimate DNS requests in transit?
**A:** An on-path attack — the attacker must intercept and modify information on the fly in real time
**Difficulty:** Medium
**Tags:** dns-poisoning, on-path, attacks, domain-4, prof-messer

---

**Q:** Describe the DNS poisoning attack flow in six steps.
**A:** 1) DNS server has legitimate IP for a domain, 2) Attacker uses ARP poisoning or hacks DNS server, 3) Changes stored IP to attacker's IP, 4) Subsequent queries return poisoned address, 5) Victim's cache stores spoofed IP, 6) Victim communicates with attacker's server instead of legitimate one
**Difficulty:** Hard
**Tags:** dns-poisoning, attacks, domain-4, prof-messer

---

**Q:** How can ARP poisoning enable DNS poisoning?
**A:** ARP poisoning lets the attacker sit between the victim and DNS server, allowing them to intercept and modify DNS responses in transit
**Difficulty:** Hard
**Tags:** arp-poisoning, dns-poisoning, on-path, attacks, domain-4, prof-messer

---

**Q:** What happens to a victim's DNS cache after a successful DNS poisoning attack?
**A:** It stores the spoofed IP address, so the victim communicates with the attacker's server instead of the legitimate one
**Difficulty:** Medium
**Tags:** dns-poisoning, attacks, domain-4, prof-messer

---

**Q:** What is an on-path attack?
**A:** An attacker sits in the middle of a conversation between two devices to monitor or change the contents of that conversation
**Difficulty:** Easy
**Tags:** on-path, spoofing, attacks, domain-4, prof-messer
