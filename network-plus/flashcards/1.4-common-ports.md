# Common Ports Flashcards

**Q:** What port(s) does FTP use?
**A:** TCP 20 (data transfer) and TCP 21 (control/commands)
**Difficulty:** Medium
**Tags:** ftp, ports, domain-1, prof-messer

---

**Q:** What is the difference between FTP port 20 and port 21?
**A:** Port 20 carries the actual file data; port 21 carries control information (commands, authentication)
**Difficulty:** Medium
**Tags:** ftp, ports, domain-1, prof-messer

---

**Q:** What port does SSH use?
**A:** TCP 22
**Difficulty:** Easy
**Tags:** ssh, ports, domain-1, prof-messer

---

**Q:** What port does SFTP use?
**A:** TCP 22 — same as SSH, because SFTP uses SSH as its underlying protocol
**Difficulty:** Medium
**Tags:** sftp, ssh, ports, domain-1, prof-messer

---

**Q:** What is the difference between FTP and SFTP?
**A:** FTP sends everything in plain text (including credentials). SFTP encrypts the entire session via SSH. Both support authentication and file management.
**Difficulty:** Medium
**Tags:** ftp, sftp, domain-1, prof-messer

---

**Q:** What port does Telnet use?
**A:** TCP 23
**Difficulty:** Easy
**Tags:** telnet, ports, domain-1, prof-messer

---

**Q:** Why is Telnet rarely used today?
**A:** All data (including login credentials) is sent in the clear — no encryption. SSH replaced it.
**Difficulty:** Easy
**Tags:** telnet, ssh, domain-1, prof-messer

---

**Q:** What is the relationship between Telnet and SSH?
**A:** Both provide remote terminal access; Telnet is unencrypted (TCP 23), SSH is encrypted (TCP 22)
**Difficulty:** Medium
**Tags:** telnet, ssh, domain-1, prof-messer

---

**Q:** What port(s) does SMTP use?
**A:** TCP 25 (plain text) and TCP 587 (with TLS encryption)
**Difficulty:** Medium
**Tags:** smtp, ports, domain-1, prof-messer

---

**Q:** What is SMTP used for?
**A:** Sending email from clients to mail servers and transferring email between mail servers
**Difficulty:** Easy
**Tags:** smtp, domain-1, prof-messer

---

**Q:** What protocols are used for receiving/managing email?
**A:** IMAP or POP3 (not SMTP — SMTP is for sending)
**Difficulty:** Medium
**Tags:** smtp, imap, pop3, domain-1, prof-messer

---

**Q:** What port(s) does DNS use?
**A:** UDP 53 (standard queries) and TCP 53 (large transfers like zone transfers)
**Difficulty:** Medium
**Tags:** dns, ports, domain-1, prof-messer

---

**Q:** Why does DNS use both UDP and TCP?
**A:** UDP 53 for quick name queries; TCP 53 for large data transfers (zone transfers, oversized responses)
**Difficulty:** Hard
**Tags:** dns, ports, domain-1, prof-messer

---

**Q:** What port(s) does DHCP use?
**A:** UDP 67 (server) and UDP 68 (client)
**Difficulty:** Medium
**Tags:** dhcp, ports, domain-1, prof-messer

---

**Q:** What does DHCP do?
**A:** Automatically configures IP address settings for devices connecting to the network
**Difficulty:** Easy
**Tags:** dhcp, domain-1, prof-messer

---

**Q:** What is a DHCP lease?
**A:** A temporary assignment of an IP address — the device must renew it before the lease time expires or lose the address
**Difficulty:** Medium
**Tags:** dhcp, domain-1, prof-messer

---

**Q:** What is a DHCP reservation?
**A:** A permanent IP assignment tied to a device's MAC address — that device always gets the same IP
**Difficulty:** Medium
**Tags:** dhcp, domain-1, prof-messer

---

**Q:** What port does TFTP use?
**A:** UDP 69
**Difficulty:** Easy
**Tags:** tftp, ports, domain-1, prof-messer

---

**Q:** What is the difference between FTP and TFTP?
**A:** FTP: full-featured (authentication, directory listing, file management) over TCP 20/21. TFTP: bare minimum (no auth, no file management, just transfer) over UDP 69.
**Difficulty:** Hard
**Tags:** ftp, tftp, domain-1, prof-messer

---

**Q:** Give a typical use case for TFTP.
**A:** VoIP phone boots via PoE → gets IP via DHCP → downloads config file via TFTP. Fast, simple, no authentication needed.
**Difficulty:** Medium
**Tags:** tftp, domain-1, prof-messer

**Q:** What port(s) does SNMP use?
**A:** UDP 161 (queries) and UDP 162 (traps)
**Difficulty:** Medium
**Tags:** snmp, ports, domain-1, prof-messer

---

**Q:** What is the difference between SNMP port 161 and 162?
**A:** Port 161: management station queries a device. Port 162: device proactively sends alerts (traps) to the management station.
**Difficulty:** Hard
**Tags:** snmp, ports, domain-1, prof-messer

---

**Q:** What is an SNMP trap?
**A:** A proactive notification sent from a device to the management station (UDP 162) when a problem is identified — no query needed
**Difficulty:** Medium
**Tags:** snmp, domain-1, prof-messer

---

**Q:** What are the key differences between SNMP v1, v2, and v3?
**A:** v1: single query/response, no encryption. v2: bulk transfers, no encryption. v3: message integrity, authentication, and encryption.
**Difficulty:** Hard
**Tags:** snmp, domain-1, prof-messer

**Q:** What does FQDN stand for?
**A:** Fully Qualified Domain Name — the complete domain name (e.g., www.professormesser.com) that DNS translates to an IP address

**Q:** What is a SIEM?
**A:** Security Information and Event Manager — consolidation point for log files from all network devices, often fed by Syslog (UDP 514)
**Difficulty:** Medium
**Tags:** siem, syslog, domain-1, prof-messer

---

**Q:** Which version of SNMP should you use for security?
**A:** Version 3 — it adds message integrity, authentication, and encryption (v1 and v2 have no encryption)
**Difficulty:** Medium
**Tags:** snmp, domain-1, prof-messer

**Q:** What transport protocol does TFTP use and why?
**A:** UDP — minimal overhead for fast, simple transfers without the complexity of TCP's connection setup and acknowledgments
**Difficulty:** Medium
