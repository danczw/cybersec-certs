# Static Routing Flashcards

**Q:** What are the steps a router performs when forwarding traffic?
**A:** 1) Identify destination IP in packet 2) Examine routing table for best route 3) If directly connected, send to local subnet 4) If not, forward to next hop 5) Next router repeats until destination reached 6) If no route found, discard packet
**Difficulty:** Medium
**Tags:** routing, static-routing, domain-2, prof-messer

---

**Q:** What happens when a router cannot find a matching route in its routing table?
**A:** The packet is discarded
**Difficulty:** Easy
**Tags:** routing, static-routing, domain-2, prof-messer

---

**Q:** What is a "next hop"?
**A:** The IP address of the next router that should receive the packet
**Difficulty:** Easy
**Tags:** routing, static-routing, domain-2, prof-messer

---

**Q:** What types of routes are automatically in a router's routing table?
**A:** Directly connected subnets
**Difficulty:** Easy
**Tags:** routing, static-routing, domain-2, prof-messer

---

**Q:** What is static routing?
**A:** Manually configuring routes in every router's routing table
**Difficulty:** Easy
**Tags:** routing, static-routing, domain-2, prof-messer

---

**Q:** What are the advantages of static routing?
**A:** 1) Quick to configure on small networks 2) No overhead (no CPU cycles, no memory usage from dynamic protocols) 3) Common for stub networks 4) Relatively secure — no dynamic routing updates to manipulate
**Difficulty:** Medium
**Tags:** routing, static-routing, domain-2, prof-messer

---

**Q:** What are the disadvantages of static routing?
**A:** 1) Challenging on larger networks (hundreds/thousands of routers) 2) Misconfiguration can create routing loops 3) Routes don't change automatically with network changes 4) No automatic rerouting if a link goes down
**Difficulty:** Medium
**Tags:** routing, static-routing, domain-2, prof-messer

---

**Q:** Why is there no overhead with static routing?
**A:** No dynamic routing protocol running — no CPU cycles or memory usage for route calculations or updates
**Difficulty:** Easy
**Tags:** routing, static-routing, domain-2, prof-messer

---

**Q:** What is a stub network?
**A:** A remote site with a single connection — all traffic uses one path
**Difficulty:** Easy

**Q:** Why is static routing common for stub networks?
**A:** A stub network has a single connection — all traffic uses one path, so a static route is sufficient

**Q:** What is a routing loop?

**Difficulty:** Easy

**Q:** Why is static routing considered relatively secure?
**A:** No dynamic routing updates that could be manipulated
**Difficulty:** Medium

**Q:** What must an administrator do when a network change occurs with static routing?

**Difficulty:** Easy
