**Q:** What is the binary-to-decimal conversion chart for 8 bits (left to right)?
**A:** 128, 64, 32, 16, 8, 4, 2, 1
**Difficulty:** Easy
**Tags:** binary, conversion-chart, domain-1, prof-messer

---

**Q:** How do you build the binary conversion chart?
**A:** Start with 1 on the right, double each position moving left (1, 2, 4, 8, 16, 32, 64, 128)
**Difficulty:** Easy
**Tags:** binary, conversion-chart, domain-1, prof-messer

---

**Q:** Each position in the binary conversion chart represents what mathematical concept?
**A:** A power of 2 — from right: 2^0, 2^1, 2^2, 2^3, 2^4, 2^5, 2^6, 2^7
**Difficulty:** Medium
**Tags:** binary, conversion-chart, domain-1, prof-messer

---

**Q:** How do you convert binary to decimal?
**A:** Place binary digits under the conversion chart; where there's a 1, take the chart value above it; where there's a 0, take 0; add all values together
**Difficulty:** Medium
**Tags:** binary, binary-to-decimal, domain-1, prof-messer

**Q:** What is the process for converting decimal to binary?
**A:** Starting from the leftmost (largest) chart value, ask: is running total + this value ≤ target? Yes → place 1 and add to running total. No → place 0. Repeat for each column.
**Difficulty:** Medium
**Tags:** binary, decimal-to-binary, domain-1, prof-messer
