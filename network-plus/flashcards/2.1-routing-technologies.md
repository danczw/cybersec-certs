# Routing Technologies Flashcards

**Q:** What devices have routing tables?
**A:** Workstations, servers, and routers
**Difficulty:** Easy
**Tags:** routing, routing-table, domain-2, prof-messer

---

**Q:** What does a router do when it receives incoming traffic?
**A:** Evaluates the destination and refers to its routing table to determine the best route
**Difficulty:** Easy
**Tags:** routing, routing-table, domain-2, prof-messer

---

**Q:** What are the seven components of a routing table entry?
**A:** 1) Route code 2) Subnet ID with prefix length 3) Administrative distance 4) Metric 5) Next hop 6) Route timestamp 7) Outgoing interface
**Difficulty:** Hard
**Tags:** routing, routing-table, domain-2, prof-messer

---

**Q:** In a routing table entry, what does the route code indicate?
**A:** How the route was learned (C = directly connected, R = RIP, D = EIGRP, etc.)
**Difficulty:** Medium
**Tags:** routing, routing-table, domain-2, prof-messer

---

**Q:** In a routing table, what does route code "C" mean?
**A:** Directly connected
**Difficulty:** Easy
**Tags:** routing, routing-table, domain-2, prof-messer

---

**Q:** In a routing table, what does route code "R" mean?
**A:** Route learned via RIP
**Difficulty:** Easy

---

**Q:** In a routing table, what does route code "D" mean?
**A:** Route learned via EIGRP

**Q:** What does the administrative distance represent in a routing table entry?

**Q:** What does the metric represent in a routing table entry?

**Q:** What does the route timestamp in a routing table entry indicate?

**Q:** In the entry `R 10.10.30.0/24 [120/1] via 10.10.50.2, 00:00:14, Serial0/3/1`, what is 120?
**A:** Administrative distance (RIP = 120)
**Difficulty:** Medium
**Tags:** routing, routing-table, administrative-distance, domain-2, prof-messer

---

**Q:** In the entry `R 10.10.30.0/24 [120/1] via 10.10.50.2, 00:00:14, Serial0/3/1`, what is 1?
**A:** Metric — RIP uses hop count, so the destination is 1 hop away
**Difficulty:** Medium
**Tags:** routing, routing-table, domain-2, prof-messer

---

**Q:** In the entry `R 10.10.30.0/24 [120/1] via 10.10.50.2, 00:00:14, Serial0/3/1`, what is Serial0/3/1?
**A:** Outgoing interface — physical interface used to reach the next hop (sometimes optional)
**Difficulty:** Medium
**Tags:** routing, routing-table, domain-2, prof-messer

---

**Q:** When multiple routes match a destination, which route is chosen?
**A:** The most specific prefix wins (longest prefix match)
**Difficulty:** Medium
**Tags:** routing, routing-table, domain-2, prof-messer

---

**Q:** Given routes 192.168.0.0/16, 192.168.1.0/24, and 192.168.1.6/32, which is chosen for destination 192.168.1.6?
**A:** 192.168.1.6/32 — most specific; /32 = single host
**Difficulty:** Medium
**Tags:** routing, routing-table, domain-2, prof-messer

**Q:** What does FHRP stand for?
**A:** First Hop Redundancy Protocol
**Difficulty:** Easy
**Tags:** routing, fhrp, domain-2, prof-messer

---

**Q:** What problem does FHRP solve?
**A:** Devices can only configure one default gateway IP address, but redundancy requires multiple routers
**Difficulty:** Medium
**Tags:** routing, fhrp, domain-2, prof-messer

---

**Q:** What is the FHRP solution to single default gateway limitation?
**A:** Create a virtual IP address (VIP) shared between routers
**Difficulty:** Medium
**Tags:** routing, fhrp, domain-2, prof-messer

---

**Q:** How does FHRP failover work?
**A:** 1) Active router holds VIP 2) Standby router always communicates with active 3) If standby detects failure → becomes active and takes over VIP 4) Failover is seamless to end users
**Difficulty:** Hard
**Tags:** routing, fhrp, domain-2, prof-messer

---

**Q:** In FHRP, what happens from the end user's perspective during failover?
**A:** Nothing — they continue using the same default gateway; failover is seamless
**Difficulty:** Easy
**Tags:** routing, fhrp, domain-2, prof-messer

---

**Q:** What are subinterfaces?
**A:** Multiple virtual interfaces assigned to a single physical interface
**Difficulty:** Easy
**Tags:** routing, subinterfaces, domain-2, prof-messer

---

**Q:** When are subinterfaces used?
**A:** When a trunk connection carries multiple VLANs to a router on one physical link
**Difficulty:** Medium
**Tags:** routing, subinterfaces, domain-2, prof-messer

---

**Q:** What does each subinterface get assigned?
**A:** Its own IP address, subnet mask, and routing configuration
**Difficulty:** Medium
**Tags:** routing, subinterfaces, domain-2, prof-messer

---

**Q:** If the physical interface is ethernet1/1, how are subinterfaces named?
**A:** ethernet1/1.10, ethernet1/1.20, ethernet1/1.100 (physical interface + dot + number)
**Difficulty:** Medium
**Tags:** routing, subinterfaces, domain-2, prof-messer

---

**Q:** In the subinterface example, how are three VLANs connected to a router?
**A:** Single trunk cable from switch to router; router has subinterfaces g0/0.1, g0/0.2, g0/0.3 — each assigned a different IP/subnet for its VLAN
**Difficulty:** Hard
**Tags:** routing, subinterfaces, domain-2, prof-messer

---

**Q:** What is the order of route selection when a router has multiple matching routes?
**A:** 1) Most specific prefix length 2) Lowest administrative distance 3) Lowest routing metric
**Difficulty:** Hard
**Tags:** routing, routing-table, domain-2, prof-messer
