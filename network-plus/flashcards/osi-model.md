# OSI Model Flashcards

**Q:** Name the 7 OSI layers from bottom to top.
**A:** Physical, Data Link, Network, Transport, Session, Presentation, Application (Layers 1-7)
**Difficulty:** Easy
**Tags:** osi, fundamentals, domain-1

---

**Q:** At which OSI layer do switches operate?
**A:** Layer 2 (Data Link) — they use MAC addresses to forward frames
**Difficulty:** Easy
**Tags:** osi, switches, domain-1

---

**Q:** At which OSI layer do routers operate?
**A:** Layer 3 (Network) — they use IP addresses to route packets
**Difficulty:** Easy
**Tags:** osi, routers, domain-1

---

**Q:** Which OSI layer handles encryption/decryption (SSL/TLS)?
**A:** Layer 6 (Presentation)
**Difficulty:** Medium
**Tags:** osi, encryption, domain-1

---

**Q:** What is the PDU at each OSI layer (L4-L1)?
**A:** L4: Segment (TCP) / Datagram (UDP), L3: Packet, L2: Frame, L1: Bits
**Difficulty:** Medium
**Tags:** osi, pdu, domain-1

---

**Q:** Which OSI layer uses MAC addresses?
**A:** Layer 2 (Data Link) — MAC addresses are in EUI-48 or EUI-64 format
**Difficulty:** Easy
**Tags:** osi, mac, domain-1

---

**Q:** Which OSI layer uses IP addresses?
**A:** Layer 3 (Network)
**Difficulty:** Easy
**Tags:** osi, ip, domain-1

---

**Q:** Name 3 protocols at OSI Layer 7.
**A:** HTTP, HTTPS, FTP, DNS, SMTP, POP3, IMAP, SSH (any 3)
**Difficulty:** Easy
**Tags:** osi, protocols, domain-1

---

**Q:** What are the 4 layers of the TCP/IP model?
**A:** Application, Transport, Internet, Network Access
**Difficulty:** Easy
**Tags:** osi, tcp-ip, domain-1

---

**Q:** How does the TCP/IP model map to OSI?
**A:** Application = OSI L5-7, Transport = OSI L4, Internet = OSI L3, Network Access = OSI L1-2
**Difficulty:** Medium
**Tags:** osi, tcp-ip, domain-1

---

**Q:** What is encapsulation in networking?
**A:** The process of adding headers (and sometimes trailers) to data as it moves down the OSI layers: Data → Segment → Packet → Frame → Bits
**Difficulty:** Medium
**Tags:** osi, encapsulation, domain-1
