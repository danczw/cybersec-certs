# Interface Configurations Flashcards

**Q:** What are the two most important ethernet settings to configure on an interface?
**A:** Speed and duplex
**Difficulty:** Easy
**Tags:** interface, ethernet, domain-2, prof-messer

---

**Q:** What speeds might an ethernet interface support?
**A:** 10 Mbps, 100 Mbps, 1000 Mbps (1 Gbps), 10 Gbps, or faster
**Difficulty:** Easy
**Tags:** interface, ethernet, speed, domain-2, prof-messer

---

**Q:** What happens when speed is mismatched on both sides of a connection?
**A:** Connection will not work at all — no link light
**Difficulty:** Medium
**Tags:** interface, ethernet, speed, domain-2, prof-messer

---

**Q:** What are the two duplex options?
**A:** Half duplex or full duplex
**Difficulty:** Easy
**Tags:** interface, ethernet, duplex, domain-2, prof-messer

---

**Q:** What happens when duplex is mismatched on both sides of a connection?
**A:** Connection operates but with very poor performance under load
**Difficulty:** Medium
**Tags:** interface, ethernet, duplex, domain-2, prof-messer

---

**Q:** How is ethernet speed often configured?
**A:** Set to auto-negotiate
**Difficulty:** Easy
**Tags:** interface, ethernet, speed, domain-2, prof-messer

---

**Q:** What is the first thing to check when troubleshooting ethernet connectivity?
**A:** Speed and duplex match on both sides, then move to IP configuration
**Difficulty:** Medium
**Tags:** interface, ethernet, troubleshooting, domain-2, prof-messer

---

**Q:** What four IP configuration values does an interface need?
**A:** IP address, subnet mask, default gateway, DNS settings
**Difficulty:** Easy
**Tags:** interface, ip, domain-2, prof-messer

---

**Q:** What types of interfaces need IP configuration?
**A:** Ethernet connections, VLAN configs, management interfaces
**Difficulty:** Easy
**Tags:** interface, ip, domain-2, prof-messer

---

**Q:** What happens if you configure the wrong default gateway or subnet mask?
**A:** Cannot connect to other IP devices on the network
**Difficulty:** Easy
**Tags:** interface, ip, domain-2, prof-messer

---

**Q:** What is link aggregation (LAG)?
**A:** Connecting multiple interfaces together between two devices; the switch interprets them as one large connection (not a loop)
**Difficulty:** Medium
**Tags:** interface, lag, domain-2, prof-messer

---

**Q:** What is another name for link aggregation?
**A:** Port bonding
**Difficulty:** Easy
**Tags:** interface, lag, domain-2, prof-messer

---

**Q:** In link aggregation, what throughput do four 1 Gbps links provide?
**A:** 4 Gbps throughput between devices
**Difficulty:** Easy
**Tags:** interface, lag, domain-2, prof-messer

---

**Q:** What does LACP stand for?
**A:** Link Aggregation Control Protocol
**Difficulty:** Easy
**Tags:** interface, lag, lacp, domain-2, prof-messer

---

**Q:** What does LACP do?
**A:** Automatic configuration of link aggregation — configure interface as LACP, plug in cables, underlying config happens automatically
**Difficulty:** Medium
**Tags:** interface, lag, lacp, domain-2, prof-messer

---

**Q:** How can you verify LACP is working between switches?
**A:** LACP traffic is visible between switches in packet captures
**Difficulty:** Medium
**Tags:** interface, lag, lacp, domain-2, prof-messer

---

**Q:** What does MTU stand for?
**A:** Maximum Transmission Unit
**Difficulty:** Easy
**Tags:** interface, mtu, domain-2, prof-messer

---

**Q:** Why is avoiding fragmentation important?
**A:** Fragmentation slows communication; losing one fragment requires resending the entire frame
**Difficulty:** Medium
**Tags:** interface, mtu, domain-2, prof-messer

---

**Q:** How is MTU usually determined?
**A:** Automatically on first connection
**Difficulty:** Easy
**Tags:** interface, mtu, domain-2, prof-messer

---

**Q:** When might you need to manually configure MTU?
**A:** When filtering and firewalls prevent auto-discovery
**Difficulty:** Medium
**Tags:** interface, mtu, domain-2, prof-messer

---

**Q:** What is the standard ethernet frame size?
**A:** 1,500 bytes
**Difficulty:** Easy
**Tags:** interface, mtu, jumbo-frames, domain-2, prof-messer

---

**Q:** What is a jumbo frame?
**A:** An ethernet frame with up to 9,216 bytes MTU (many devices use 9,000 as accepted high end)
**Difficulty:** Medium
**Tags:** interface, mtu, jumbo-frames, domain-2, prof-messer

---

**Q:** How much data does one jumbo frame carry compared to normal frames?
**A:** Approximately the same as six normal frames
**Difficulty:** Medium
**Tags:** interface, mtu, jumbo-frames, domain-2, prof-messer

---

**Q:** What is the advantage of jumbo frames?
**A:** Fewer packets to switch/route → transfers more data in shorter time
**Difficulty:** Medium
**Tags:** interface, mtu, jumbo-frames, domain-2, prof-messer

---

**Q:** What is the requirement for using jumbo frames on a network?
**A:** ALL devices in the communication path must understand jumbo frames (switches, routers, endpoints)
**Difficulty:** Medium
**Tags:** interface, mtu, jumbo-frames, domain-2, prof-messer

---

**Q:** What happens if any device in the path doesn't support jumbo frames?
**A:** It will drop the frames — communication fails
**Difficulty:** Medium
**Tags:** interface, mtu, jumbo-frames, domain-2, prof-messer
