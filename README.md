## Structure

Each cert gets its own directory (copy from `_template/`):

```
cert-name/
├── README.md        # exam details, study plan, status
├── objectives.md    # exam objectives by domain
├── resources.md     # books, courses, labs, practice exams
├── notes/           # topic notes per domain/objective
├── flashcards/      # Q&A pairs for AI-driven drilling
└── practice/        # scenarios, questions, troubleshooting
```
